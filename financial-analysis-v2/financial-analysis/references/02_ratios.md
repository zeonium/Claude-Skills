# 02. 재무비율 공식집 · 업종별 벤치마크 매트릭스

> **언제 이 파일을 읽을까?**
> - 비율을 계산하기 직전
> - 사용자가 특정 지표(예: ROIC, CCC, DSCR)의 정의를 물어볼 때
> - 업종별 등급 판정을 해야 할 때

## 0. 빠른 참조 — 최우선 지표 10선

```
① 매출성장률(YoY)  = (당기 매출 − 전기 매출) / 전기 매출
② 영업이익률       = 영업이익 / 매출액
③ ROE             = 당기순이익 / 평균자기자본
④ ROIC            = NOPAT / 투하자본
⑤ 총자산회전율    = 매출액 / 평균총자산
⑥ 현금전환주기    = 재고일수(DIO) + 매출채권회수일수(DSO) − 매입채무지급일수(DPO)
⑦ 부채비율        = 총부채 / 자기자본
⑧ 이자보상배율    = 영업이익 / 이자비용
⑨ 영업현금흐름    = CFO (현금흐름표 직접 확인)
⑩ 잉여현금흐름    = CFO − CAPEX
```

## 1. 성장성 비율 (Growth)

```
매출액 성장률(YoY)  = (당기 매출 − 전기 매출) / 전기 매출 × 100
영업이익 성장률(YoY) = (당기 영업이익 − 전기 영업이익) / |전기 영업이익| × 100
순이익 성장률(YoY)  = (당기 순이익 − 전기 순이익) / |전기 순이익| × 100

매출 CAGR(n년)     = (최종연도 매출 / 기준연도 매출)^(1/n) − 1
영업이익 CAGR(n년) = (최종연도 영업이익 / 기준연도 영업이익)^(1/n) − 1

유기적 성장률 = 총매출 성장률 − M&A 기여 성장률 − 환율 효과 성장률
```

**해석 원칙:**
- 매출 성장률 > 업종 평균 → 시장점유율 확대 중
- 영업이익 성장률 > 매출 성장률 → 수익성 확대(질 좋은 성장)
- 매출 성장률 > 영업이익 성장률 → 비용 효율 저하(주의)

## 2. 수익성 비율 (Profitability)

```
매출총이익률(Gross Margin)    = 매출총이익 / 매출액 × 100
영업이익률(Operating Margin)  = 영업이익 / 매출액 × 100
EBITDA 마진                  = EBITDA / 매출액 × 100
    └ EBITDA = 영업이익 + 감가상각비(D&A)
세전이익률(Pretax Margin)     = 세전이익 / 매출액 × 100
순이익률(Net Margin)          = 당기순이익 / 매출액 × 100

ROA (총자산이익률)            = 당기순이익 / 평균총자산 × 100
    └ 평균총자산 = (기초 + 기말) / 2
ROE (자기자본이익률)          = 당기순이익 / 평균자기자본 × 100
ROIC (투하자본수익률)         = NOPAT / 투하자본 × 100
    └ NOPAT      = 영업이익 × (1 − 유효세율)
    └ 투하자본   = 자기자본 + 이자부부채 − 현금성자산
                = (또는) 비유동자산 + 순운전자본
```

**ROIC vs WACC 판정:**
- ROIC > WACC: 주주가치 창출 (Value-creating)
- ROIC ≈ WACC: 가치 중립
- ROIC < WACC: 주주가치 파괴 (Value-destroying)

## 3. 자본효율성 비율 (Capital Efficiency, DuPont)

### 3분해 (기본)
```
ROE = 순이익률 × 총자산회전율 × 재무레버리지
    = (순이익/매출) × (매출/총자산) × (총자산/자기자본)
```

### 5분해 (심화 — 세금·이자 효과 분리)
```
ROE = 세전이익률 × 세금부담율 × 이자부담율 × 총자산회전율 × 재무레버리지

  ① 세전이익률   = 세전이익 / 매출
  ② 세금부담율   = 순이익 / 세전이익  (= 1 − 유효세율)
  ③ 이자부담율   = 세전이익 / EBIT
  ④ 총자산회전율 = 매출 / 총자산
  ⑤ 재무레버리지 = 총자산 / 자기자본
```

> 상세 해석 매트릭스는 `03_dupont_cashflow.md` 참조.

## 4. 활동성/효율성 비율 (Activity / Efficiency)

```
총자산회전율         = 매출액 / 평균총자산
고정자산회전율       = 매출액 / 평균고정자산
순운전자본회전율     = 매출액 / 평균순운전자본
    └ 순운전자본 = 유동자산 − 유동부채

재고자산회전율       = 매출원가 / 평균재고자산
재고회전일수(DIO)    = 365 / 재고자산회전율
                   = (평균재고 / 매출원가) × 365

매출채권회전율       = 매출액 / 평균매출채권
매출채권회수일수(DSO)= 365 / 매출채권회전율
                   = (평균매출채권 / 매출액) × 365

매입채무회전율       = 매출원가 / 평균매입채무
매입채무지급일수(DPO)= 365 / 매입채무회전율

현금전환주기(CCC)    = DIO + DSO − DPO
```

**CCC 해석:**
- CCC < 0: 구매자 우위(선수금 수취·공급업체 후불) → 최우량 신호
- 0~30일: 우수
- 30~60일: 정상
- 60일 이상: 운전자본 압박 증가
- 3년 연속 증가 → 영업 효율 저하 경고

## 5. 안정성/레버리지 비율 (Solvency / Leverage)

```
부채비율(D/E Ratio)   = 총부채 / 자기자본 × 100
총부채비율            = 총부채 / 총자산 × 100
순부채                = 이자부부채 − 현금 및 현금성자산
순부채비율(Net D/E)   = 순부채 / 자기자본 × 100
순부채/EBITDA         = 순부채 / EBITDA  (배수)

이자보상배율(ICR)      = 영업이익 / 이자비용  (배수)
    └ < 1배  : 영업으로 이자도 못 냄 (심각)
    └ 1.5~2배: 위험 수준
    └ 3배 이상: 양호

고정비보상배율(FCCR)   = (영업이익 + 임차료) / (이자비용 + 임차료 + 원금상환)
    └ 리스/임차 비중 높은 업종(항공·소매)에서 중요

자기자본비율           = 자기자본 / 총자산 × 100
유형자산/장기부채      = 유형자산 / 장기부채  (담보력 지표)

DSCR (부채상환보상비율) = 영업이익 / (이자비용 + 단기장기부채상환분)
```

## 6. 유동성 비율 (Liquidity)

```
유동비율(Current Ratio) = 유동자산 / 유동부채
    └ 1.0 이상: 기본 안전
    └ 1.5 이상: 보통
    └ 2.0 이상: 양호 (업종별 차이 큼)
    └ 1.0 미만: 단기 유동성 위기 가능

당좌비율(Quick Ratio)   = (유동자산 − 재고자산) / 유동부채
    └ 0.7~1.0 이상: 일반적 안전 기준

현금비율(Cash Ratio)    = (현금 + 단기금융자산) / 유동부채
    └ 가장 보수적인 유동성 지표

영업현금흐름비율        = 영업활동현금흐름(CFO) / 유동부채
    └ 0.4 이상: 양호
    └ 0.2 미만: 주의
```

## 7. 현금흐름 비율 (Cash Flow)

```
현금전환비율(CFC)  = CFO / 당기순이익
    └ ≥ 1.0 : 이익의 질 우량
    └ 0.8~1.0: 보통
    └ < 0.8 : 이익의 질 저하 경고
    └ < 0.5 : 심각 (회계 조작 또는 운전자본 함정)

잉여현금흐름(FCF)  = CFO − CAPEX
FCF 마진           = FCF / 매출액
FCF 수익률(Yield)  = FCF / 평균시가총액

CFO 대비 이자커버 = CFO / 이자비용
투자 자기조달력   = CFO / (설비투자 + 인수금액)
    └ ≥ 1.0: 투자를 본업 현금으로 충당 가능

총발생액(Accruals) = 당기순이익 − CFO
발생액/총자산     = 총발생액 / 평균총자산
    └ 업계 평균 대비 현저히 높으면 회계 조작 위험
```

> 심층 현금흐름 분석은 `anthropic-skills:cash-flow-analysis` 스킬로 위임 권장.
> 본 스킬은 요약 수준(패턴 A~E 판정, CFO/NI 비율)까지 담당.

## 8. 시장가치 비율 (Market Valuation) — 참고용

```
EPS (주당순이익)       = 순이익 / 발행주식수
PER (주가수익비율)     = 주가 / EPS
PBR (주가순자산비율)   = 주가 / BPS     (BPS = 자기자본 / 발행주식수)
PSR (주가매출비율)     = 시가총액 / 매출액
EV/EBITDA             = (시가총액 + 순부채) / EBITDA
EV/Sales              = (시가총액 + 순부채) / 매출액
PEG                   = PER / (이익성장률 × 100)
    └ < 1.0: 저평가 가능성

배당수익률  = DPS / 주가
배당성향    = DPS / EPS × 100
```

> ⚠️ 밸류에이션 비율은 본 스킬의 보조 참고 지표.
> 적정주가 산출은 `anthropic-skills:intrinsic-value-analyzer` 스킬 사용.

## 10. 빠른 계산 체크리스트 (Mode B 실무 순서)

```
Phase 1 — 규모·성장 파악 (5분)
  □ 매출 YoY, 5년 CAGR
  □ 영업이익 YoY
  □ 시가총액 / 매출 (PSR)

Phase 2 — 수익성 진단 (10분)
  □ 매출총이익률 5년 추세
  □ 영업이익률 5년 추세
  □ ROE, ROA, ROIC

Phase 3 — DuPont 분해 (10분)
  □ 3분해 검증: 순이익률 × 회전율 × 레버리지 = ROE
  □ 변화 원인 특정 (마진/효율/레버리지)
```
