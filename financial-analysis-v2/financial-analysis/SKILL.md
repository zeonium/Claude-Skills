# Financial Analysis — 기업 재무진단 통합 스킬 (v2: 11대 산업 맞춤형)

본 스킬은 **재무제표 분석의 4계층(계산→해석→진단→통찰)**을 하나의 워크플로우로 엮어
사용자에게 **행동 가능한 재무 진단(Actionable Diagnosis)**을 제공합니다.

**v2 핵심 보강:** 11대 한국 주요 산업(반도체·2차전지·석유화학·건설·조선·식품제조·생활용품화장품·도소매·제약바이오·렌탈·해운)에
대해 산업별 비즈니스 모델 특성·핵심 KPI·Red Flag 시그널·점검 주석을 자동 적용하는
**산업 특화 분석 프로토콜(§9)**과 reference `08_industry_specific_11.md`를 추가했습니다.

---

## 0. 작동 원칙 & 언어 정책

1. **Data-First** — 모든 판단은 재무제표 원본 수치를 근거로 합니다. 인상평가·추측 금지.
2. **Trend > Point** — 단일 연도 수치보다 3~5년 **추세와 속도 변화**를 우선합니다.
3. **Context Matters** — 동일 비율도 업종에 따라 해석이 달라집니다. 업종 벤치마크 필수 병기.
4. **Cash Doesn't Lie** — 이익과 현금흐름의 괴리를 항상 추적합니다.
5. **Notes Over Numbers** — 주석에 숨은 리스크(우발부채·특수관계자 거래·수익인식 정책)를 점검합니다.
6. **Industry Lens First** — 일반 재무비율로 진단하기 **전에** 해당 기업의 산업군을 식별하고
   산업 특화 KPI를 우선 적용합니다. (→ §9 / `references/08_industry_specific_11.md`)

**언어 정책:**
- 사용자 언어에 맞추어 출력 (한국어 요청 → 한국어, 영어 요청 → 영어)
- 한국어 출력 시 전문용어는 **`한국어명 (영문약어)`** 표기 — 예: 자기자본이익률 (ROE)
- 영어 출력 시 약어 그대로 사용 — 예: ROE, EBITDA, FCF

## 1. 모드 자동 분기 (Mode A / Mode B)

사용자가 모드를 명시하지 않아도 아래 규칙으로 자동 판정합니다.

```
┌───────────────────────────────────────┐
│  사용자 요청                           │
└───────────────────────────────────────┘
              ↓
    ┌──────────────────┐
    │ 기업명/티커 있음? │
    └──────────────────┘
       │            │
      No            Yes
       │            │
       ↓            ↓
 ┌──────────┐  ┌──────────────┐
 │ 숫자 있음? │  │ 데이터 제공?  │
 └──────────┘  └──────────────┘
   │      │     │          │
  Yes    No    Yes         No
   ↓      ↓     ↓          ↓
Mode A  [요청] Mode B    MCP 수집
               (수집생략)   →
                          Mode B
```

### Mode A · Quick Scan 트리거 (아래 모두 충족)
- 사용자가 재무 숫자를 직접 제공 (NL 문장 / 표 / CSV / JSON)
- 기업명·티커가 언급되지 않았거나 추가 데이터 수집 불필요
- "심층 / Deep / Peer / 투자등급 / Red Flag / 3년 / 시계열" 키워드 없음

**산출물:** 1페이지 ⭐ 등급 대시보드 (→ `references/06_report_templates.md` §1)
+ 산업이 11대 분류 중 하나로 식별되면 산업 특화 KPI 박스 1개 추가.

### Mode B · Deep Diagnosis 트리거 (하나라도 충족)
- 기업명·티커가 명시되고 실데이터 수집 필요
- 3~5년 시계열 분석 요청
- "심층 / Deep / Peer / 투자등급 / Red Flag / 통찰 / 경영진단" 등 키워드
- 사용자가 직접 제공했더라도 다기간(3년 이상) 데이터

**산출물:** 8섹션 A+~D 투자등급 보고서 + **§7-Ind 산업 특화 진단 섹션**(11대 산업 해당 시)

## 2. Mode A 실행 절차 (Quick Scan)

1. 제공된 재무 숫자에서 **5대 축 핵심 지표** 계산
   (매출성장률 / 영업이익률 / ROE / 총자산회전율 / 부채비율 / 이자보상배율 / 유동비율)
2. **산업 식별** — 사용자 입력 또는 KSIC/GICS/제품설명으로 11대 산업 분류 시도
   (→ `references/08_industry_specific_11.md` §1 분류 의사결정 트리)
3. 업종 정보가 있으면 `references/02_ratios.md`의 해당 업종 벤치마크로 **⭐ 등급 부여**
4. **산업이 11대 분류에 매칭되면** `08_industry_specific_11.md`의 산업별 핵심 KPI 2~3개를
   추가 산출(데이터가 있는 경우만) → 출력에 "산업 특화 점검" 박스 표시
5. 업종 불명 시 **General(일반)** 기준 적용 + 출력에 명시
6. 3줄 요약(강점·약점·종합) + 주의 포인트 + 다음 단계 안내
7. 적정주가 / 분기 실적 / 해자 등 요청이 섞여 있으면 **Delegation Matrix**(§4)로 위임 안내

> ⭐ 등급 4단계 (개별 지표):
> ⭐⭐⭐⭐ 탁월 / ⭐⭐⭐ 양호 / ⭐⭐ 보통 / ⭐ 미흡

## 3. Mode B 실행 절차 (Deep Diagnosis 7+1 Steps)

| Step | 작업 | 상세 파일 |
|------|------|---------|
| 1 | 자료 수집 & 맥락 설정 (MCP 호출) | `references/07_data_sources.md` |
| **1.5** | **산업 라우팅 (11대 분류 매핑 + 산업 특화 KPI 셋업)** | **`references/08_industry_specific_11.md`** |
| 2 | 데이터 정규화 (일회성 조정·SBC·환율·M&A) | `references/01_framework.md` §4 |
| 3 | 5대 축 재무비율 시계열 계산 | `references/02_ratios.md` |
| 4 | DuPont 분해 + ROIC vs WACC + 현금흐름 패턴 | `references/03_dupont_cashflow.md` |
| 5 | Red Flag 30 + Beneish M + Altman Z **+ 산업 특화 Red Flag** | `references/04_red_flags.md` + `08` §3 |
| 6 | Peer 비교 (3~5개사, **동일 산업군 우선**) | `references/05_industries_peer.md` + `08` |
| 7 | Insight 3대 프레임 + 최종 A+~D 등급 | `references/01_framework.md` §5 |

**최종 출력:** 8섹션 구조의 심층 보고서 + **(11대 산업 해당 시)** 산업 특화 진단 섹션 1개 추가
(→ `references/06_report_templates.md` §2 템플릿 + `08_industry_specific_11.md` §5 산업별 체크리스트)

> 🎯 종합 투자등급 (기업 전체):
> **A+** 최우량 / **A** 우량 / **B** 보통 / **C** 주의 / **D** 위험
>
> ⭐(지표)과 A+~D(종합)는 **다른 추상화 레벨**입니다. 혼용 금지.

## 4. Delegation Matrix — When to Delegate

본 스킬은 **재무진단** 범위에 집중하고, 아래 영역은 타 스킬·MCP로 위임합니다.

| 영역 | 이 스킬 | 위임 대상 |
|------|-------|----------|
| 재무비율 계산·해석 | ✅ 직접 | — |
| 5대 축(성장·수익·활동·안정·유동) 진단 | ✅ 직접 | — |
| DuPont·ROIC·WACC 스프레드 | ✅ 직접 | — |
| Red Flag / Beneish / Altman | ✅ 직접 | — |
| **11대 산업 특화 KPI·체크리스트** | ✅ **직접** | — |
| 산업·Peer 비교 | ✅ 직접 | — |
| 현금흐름 **요약 패턴(A~E)** | ✅ 직접 | 심층 운전자본·FCF Bridge → `anthropic-skills:cash-flow-analysis` |
| 적정주가 (DCF / RIM / Multiple) | ❌ | `anthropic-skills:intrinsic-value-analyzer` |
| 분기 실적·EPS 서프라이즈·가이던스 | ❌ | `anthropic-skills:earnings-analysis` |

  `intrinsic-value-analyzer` 스킬로 이어가시는 것을 권고드립니다. DCF에 필요한
  FCF·WACC 추정치는 본 분석 결과를 그대로 활용할 수 있습니다."

- 사용자: "삼성전자 경제적 해자는?"

  분석은 eco-moat-ai로 연계 권고."

## 6. 에지 케이스 처리

| 케이스 | 처리 방법 |
|--------|----------|
| 업종 정보 불명 | General(일반) 기준 적용 + "업종 미상으로 General 기준 적용" 명시 |
| 11대 산업 외 업종 | 기존 8업종 벤치마크(`02_ratios.md`)만 적용 + 산업 특화 섹션 생략 |
| 복합기업(Conglomerate) | 매출 비중 ≥40% 사업부의 산업 특화 KPI를 1순위로 적용 + 부수 사업부는 보조 |
| 데이터 일부 누락 | 계산 가능한 지표만 산출, 누락 항목은 "N/A" + 대체 지표 제안 |
| 분기 데이터만 있음 | Annualize 전제 명시 후 Mode A 적용 or 4분기 합산 |
| 3년 미만 데이터 | Mode B는 Mode A로 다운그레이드 후 "시계열 부족" 경고 |
| 단위 불명 (천원/백만원/억원/원) | 단위를 사용자에게 확인하거나 합리적 추정 후 명시 |
| 금융업 | DuPont·Altman 일반 공식 부적용 명시, NIM·BIS·NPL 중심 판단 |
| 바이오 초기 (R&D 단계) | Altman Z 적용 불가 + **R&D 자산화율·임상 파이프라인·현금소진율(Cash Burn)·Runway** 중심 재구성 (→ `08` §4.9) |
| 적자 기업 | ROE·ROIC 해석 주의 명기, EV/Sales·FCF 마진 대체 지표 활용 |
| IFRS 16 이전/이후 혼재 | 리스 제외 EBITDA 기준으로 통일 비교 |
| 환율·기능통화 차이 | 기능통화 원본 우선 + USD 환산값 병기 |
| MCP 전부 실패 | 사용자에게 직접 재무제표 첨부 요청 (자료 포기 금지) |
| 수치 신뢰성 의심 | 교차 확인 (DART vs KIS, SEC vs FMP) 후 판단 유보 가능 |

## 9. 11대 산업 특화 분석 프로토콜 (v2 신규)

본 절은 산업별 비즈니스 모델 차이를 재무 진단에 즉시 반영하기 위한 **요약 라우터**입니다.
세부 KPI 공식·임계치·체크리스트는 `references/08_industry_specific_11.md`를 반드시 참조하십시오.

### 9.1 11대 산업군 4분류 (Macro Grouping)

| 그룹 | 산업 | 핵심 진단 축 | 대표 KPI |
|------|------|------------|---------|
| **A. 자본집약 장치산업** | 반도체 / 2차전지 / 석유화학 | CAPEX·감가상각·가동률·스프레드 | CAPEX/매출, 감가상각비/매출, 재고회전, 나프타-제품 스프레드 |
| **B. 수주기반 산업** | 건설 / 조선 | 수주잔고·진행률·계약자산/부채 | 수주잔고/매출, 미청구공사(계약자산)/매출, 계약부채/매출, PF 우발채무 |
| **C. B2C 소비재** | 식품 / 생활용품·화장품 / 도소매 | 원가전가력·판관비·재고회전·채널 | 매출원가율 추이, 판관비/매출, 재고회전기간, 점포당 매출 |
| **D. 특수회계·금융 기반** | 제약·바이오 / 렌탈 / 해운 | R&D 자산화·리스·운임·파이프라인 | 개발비/무형자산, 손상차손, 리스부채/자기자본, 운임지수 민감도, 선박 감가상각 |

### 9.2 산업 식별 의사결정(요약)

1. 사용자가 산업을 명시 → 그대로 사용 (단, 매출 비중 ≥40% 확인)
2. 명시 없음 → KSIC 코드 or GICS sub-industry → 매핑 테이블 적용
   (상세 매핑 → `08_industry_specific_11.md` §2)
3. 매핑 실패 → 주요 제품·서비스 설명을 키워드 매칭
4. 그래도 불명 → "산업 미식별 — General 기준 적용" 명시

### 9.3 산업 특화 출력 의무

- **Mode A**: 1페이지 보고서 하단에 "산업 특화 점검(2~3 KPI + 1줄 코멘트)" 박스 추가
- **Mode B**: 8섹션 보고서의 **§7 다음에 §7-Ind "산업 특화 진단"** 섹션 1개 삽입
  - 9.1의 핵심 KPI 시계열 표 (3~5년)
  - 산업 Red Flag 점검 (08 §3)
  - 산업 특화 체크리스트 (08 §5)
  - 산업 Peer 1~3사 비교 (가능한 경우)

### 9.4 일반 비율과 산업 KPI의 우선순위

같은 사안에 대해 일반 비율과 산업 KPI가 다른 결론을 줄 경우:
- **산업 KPI를 1순위로** 채택 (산업 맥락이 우선)
- 단, 차이의 원인을 본문에 명시 (예: "건설업은 재무비율상 부채비율 200% 미만이어도
  PF 보증 등 우발채무가 자기자본의 1.5배를 초과해 실질 레버리지는 위험 구간")

### 9.5 11대 산업 즉시 참조표 (One-Liner)

| # | 산업 | 한 줄 진단 포인트 |
|---|------|----------------|
| 1 | 반도체 | CAPEX/매출 ≥25%·감가상각비/매출 ≥15%이면서 가동률 하락기엔 영업이익 급락 위험 |
| 2 | 2차전지 | 유형자산 YoY 급증 + 전환사채/총자본 ≥10%이면 희석·평가손실 트리거 |
| 3 | 석유화학 | 나프타-에틸렌 스프레드 + 재고 평가손실(저가법 환입)이 마진의 1차 동인 |
| 4 | 건설 | 미청구공사/매출 ≥15% + PF 우발채무/자기자본 ≥50% = 고위험 |
| 5 | 조선 | 계약부채(선수금)/매출 ≥30% = 호황, 환헤지 파생 평가손익이 일회성 변동 견인 |
| 6 | 식품 제조 | 매출원가율 2년 연속 ▲ + 재고폐기손실 ▲ = 가격전가 실패 신호 |
| 7 | 생활용품·화장품 | 판관비/매출 ≥35% + 무형자산(브랜드) 손상차손 점검, 중국·면세 의존도 |
| 8 | 도소매업 | 재고회전기간(일)과 점포당 매출/현금흐름, 상품매출 vs 수수료매출 비중 |
| 9 | 제약·바이오 | 개발비 자산화율 ≥40% + 손상차손 누적 = 임상 실패 트리거 / 현금소진율·Runway |
| 10 | 렌탈업 | 리스자산/총자산 ≥50% + 감가상각비/매출 + 중고매각 원가율, 해지율 |
| 11 | 해운업 | 리스부채/자기자본 + 이자보상배수, BDI/SCFI 운임지수 민감도, 선박 감가상각 |
