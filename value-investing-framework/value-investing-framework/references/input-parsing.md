# 입력 파싱 가이드

본 스킬은 다양한 입력 형식을 받는다. `scripts/parse_ticker_list.py`가 자동 처리하지만, 본 문서는 형식별 처리 원칙을 정리한다.

## 입력 유형

### 1) 자연어 단일 종목

예: "삼성전자 가치투자 프레임워크로 분석해줘"

처리:
- 메시지에서 종목명 추출
- 한국어 vs 영어 판별 → 시장 추정
- 검색 MCP로 코드 확정
- Mode A 진입

### 2) 자연어 다중 종목

예: "삼성전자, SK하이닉스, LG화학 중에 가치투자로 적합한 거 골라줘"

처리:
- 종목명 콤마/공백/'와/과' 분리
- 각 종목 코드 확정
- Mode B 진입

### 3) 종목 코드 직접

예: "005930, 035720, 005380"

처리:
- 6자리 → 한국, 알파벳 → 미국 자동 판별
- 시장 + 회사명 보강 조회
- 입력 개수에 따라 Mode A 또는 Mode B

### 4) CSV 파일

표준 컬럼명 (대소문자 무관):
- `code`, `ticker`, `symbol`, `종목코드`, `티커` → 종목 코드
- `name`, `company`, `종목명`, `회사명` → 종목명
- `market`, `exchange`, `시장`, `거래소` → 시장 (선택)
- `currency`, `통화` → 통화 (선택)

처리 절차:
1. pandas로 읽기 (`pd.read_csv`, encoding='utf-8' 우선, 실패 시 'cp949')
2. 컬럼 정규화 (lowercase, 한글→영문 매핑)
3. 코드 또는 이름 중 최소 하나 있어야 함
4. 코드만 있으면 이름 보강 조회 (필수 아님)
5. 이름만 있으면 코드 변환 필수

### 5) Excel (xlsx)

처리:
1. `openpyxl` 또는 `pandas.read_excel` 사용
2. 첫 번째 시트 기본, 사용자가 시트명 지정 시 그것 사용
3. CSV와 동일한 컬럼 매핑 적용
4. 빈 행/빈 셀 제거

### 6) Text 파일 (.txt)

처리 패턴:
- 한 줄에 하나의 종목 (코드 또는 이름)
- 콤마/탭/세미콜론 구분
- '#' 시작 줄은 주석 무시

### 7) Markdown 표

처리:
- `|` 구분 표 인식
- 헤더 행 기준 컬럼 매핑

## 정규화 규칙

### 종목 코드

- 한국: 앞쪽 0 보존 ("005930"; "5930"이면 "005930"으로 패딩)
- 미국: 대문자 ("aapl" → "AAPL")
- 접미사 정리:
  - `.KS`, `.KQ`, `.KR` → 한국
  - `.HK` → 홍콩 (본 스킬 지원 외, cross-market-equity-router 위임)
  - `.SH`, `.SZ` → 중국 (본 스킬 지원 외)
  - `.T` → 일본 (본 스킬 지원 외)
  - `.L` → 런던 (본 스킬 지원 외)
- 접두사 정리: `$` 제거

### 종목명

- 한글 회사명: 공백 정리
- 영문: 후행 "Inc.", "Corp.", "Co.", "Ltd." 등은 검색 정확도에 도움 → 유지
- 동음이의 회사: 사용자에게 확인 요청 (예: "Class A", "Class B" 구분)

### 시장 자동 판별 우선순위

1. 명시된 시장 컬럼 우선
2. 종목 코드 패턴으로 추론
3. 모두 모호하면 사용자 확인 또는 `cross-market-equity-router` 위임

## 데이터 검증

파싱 후 검증:
- 중복 종목 제거 (코드 기준)
- 코드 유효성 (한국 6자리, 미국 1~5자리 알파벳)
- 지원 시장 외 종목은 경고 후 제외 또는 사용자 확인

## 출력 표준 형식

`scripts/parse_ticker_list.py`는 다음 JSON 배열을 반환:

```json
[
  {
    "code": "005930",
    "name": "삼성전자",
    "market": "KOSPI",
    "currency": "KRW"
  },
  {
    "code": "AAPL",
    "name": "Apple Inc.",
    "market": "NASDAQ",
    "currency": "USD"
  }
]
```

이 형식이 후속 단계의 표준 입력.

## 오류 처리

- 파일 읽기 실패 → 사용자에게 인코딩/형식 확인 요청
- 코드 변환 실패 → 그 종목은 "변환 실패"로 표기하고 다음 진행 (전체 중단 금지)
- 지원 외 시장 → 사용자에게 알리고 한국·미국만 처리
- 빈 입력 → 사용자에게 종목 명시 요청

## 사용자 경험 메모

- 파일 입력 시 첫 응답에 "파싱 결과 N개 종목 확인. 시장 분포: 한국 X개, 미국 Y개. Mode B로 진행합니다." 안내
- 1개 종목만 파싱되면 Mode A로 전환 안내 후 진행
- 50개 이상 대량 입력 시 "분석 시간이 길어질 수 있습니다. 우선순위 기준은? (기본: quick_ratio 내림차순)" 확인
