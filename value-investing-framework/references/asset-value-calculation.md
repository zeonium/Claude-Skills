# 자산 가치 (Asset Value) 계산 상세

그린월드 프레임워크에서 가장 신뢰성 있는 가치 척도. 대차대조표 기반이며 검증 가능하다.

## 산업 분류 판정 (사양 vs 존속)

### 사양 산업 신호 (Liquidation Mode)

다음 중 2개 이상 해당 → 사양 산업으로 간주:

- 산업 매출 5년 CAGR < 0
- 산업 시가총액 5년 감소
- 대체 기술/제품의 명확한 침투 (예: 신문 → 디지털, 내연기관 → EV)
- 산업 평균 ROIC < 자본비용 5년 이상
- 산업 종사자 수 추세 감소

### 존속 산업 신호 (Reproduction Mode)

- 산업 매출 안정 또는 성장
- 산업 시장점유율 분포가 안정적
- 신규 진입이 지속됨 (시장이 살아있음)

### 모호한 경우

판단이 어려우면 **보수적으로 사양 산업 가정** (청산가치가 낮으므로 보수적). 사용자에게 묻지 말고 보고서에 "사양 산업 가정 적용. 존속 가능성 있다고 판단되면 재생산비용 별도 산출 필요" 명시.

## Path 1: 청산 가치 (Liquidation Value)

`scripts/compute_av_liquidation.py` 사용.

### 자산 회수율 (Recovery Rate)

| 자산 항목 | 회수율 (Base) | 보수적 | 사양 산업 |
|---|---|---|---|
| 현금·현금성자산 | 100% | 100% | 100% |
| 단기금융자산 | 95~100% | 95% | 90% |
| 매출채권 | 80% | 75% | 65% |
| 재고자산 (원자재) | 50% | 40% | 30% |
| 재고자산 (반제품) | 40% | 30% | 20% |
| 재고자산 (완제품) | 60% | 50% | 35% |
| 유형자산 (토지) | 시가 90% | 시가 80% | 시가 70% |
| 유형자산 (건물) | 60% | 50% | 35% |
| 유형자산 (설비) | 25% | 20% | 10% |
| 무형자산 (영업권) | 0% | 0% | 0% |
| 무형자산 (브랜드·특허) | 별도 평가 | 0~20% | 0% |
| 투자자산 | 시가 | 시가 | 시가의 80% |

### 부채 차감

- 유동부채 100% 차감
- 비유동부채 100% 차감
- **우발부채** 추가 차감:
  - 퇴직급여 부족분
  - 진행중 소송 충당금
  - 환경복구의무
  - 회수보증·연대보증

### 청산비용

- 자산 총액의 5~10% 차감 (변호사, 평가사, 처분 수수료)
- 사양 산업·복잡한 자산일수록 10%

### 산출

```
청산가치 = Σ(자산 × 회수율) - 부채 - 우발부채 - 청산비용
청산가치(주당) = 청산가치 / 발행주식수
```

### 데이터 출처

- 한국: `open-dart-reader:opendart_finstate_all`, 우발부채는 사업보고서 주석 (XBRL은 잡지 못하는 경우 많음 → `opendart_extract_document_sections`로 사업보고서 본문 검색)
- 미국: `sec-edgar:get_financials`, `sec-edgar:get_filing_content`로 10-K Risk Factors와 Notes 확인

## Path 2: 재생산 비용 (Reproduction Cost)

`scripts/compute_av_reproduction.py` 사용.

### 출발점

장부가 (Book Value of Equity)

### 더할 것: 무형자산 재구축 비용

재무제표에 잡히지 않거나 과소 계상된 무형자산을 자본화한다.

#### R&D 자본화

```
R&D 자본 = Σ(최근 N년 R&D 비용) × (1 - 감모율)
N: 산업별 R&D 유효 수명 (제약 10년, IT 5년, 소재 7년 등)
감모율: 평균 0.25 (제약은 0.15, IT는 0.30)
```

기준: GAAP/IFRS는 R&D 대부분을 즉시 비용처리하므로 재무제표에는 없다. 본 항목으로 재반영.

#### 마케팅·브랜드 자본화

```
브랜드 자본 = Σ(최근 3~5년 광고선전비) × 자본화율
자본화율: B2C 0.4~0.6, B2B 0.2~0.3, 산업재 0.1~0.2
```

#### 고객관계·디스트리뷰션

```
고객관계 자본 = SG&A 중 고객 유치/유지 비용 추정 × 3년
```

추정이 어려우면 산업 평균값 사용 (`market-research` 보조 호출 가능).

#### 인적 자본

```
인적 자본 = 평균 인건비 × 1~2년 (훈련·대체 비용)
```

직원 수 데이터: 한국 DART 사업보고서, 미국 10-K Part I.

#### 조직·운영 노하우

```
조직 자본 = 산업 평균 자본 (벤치마크 필요시 market-research 위임)
```

### 차감할 것

- 매출채권 회수 불능 추가 조정 (장부보다 보수적 회수율 적용 시)
- 재고 시가 vs 장부가 차이 (장부 > 시가 시 차감)
- 유형자산 손상 가능성 (오래된 설비, 사양 라인)
- 부채는 시가 평가 (변동금리 부채는 장부값 그대로, 고정금리 + 시장금리 급변 시 조정)

### 산출

```
재생산 비용 = 조정 장부가
             + R&D 자본 + 브랜드 자본 + 고객관계 자본 + 인적 자본 + 조직 자본
             - 무형자산 손상 조정
             - 우발부채

재생산 비용(주당) = 재생산 비용 / 발행주식수
```

## 보고서 출력 시 명시 항목

- 적용 모드 (청산 / 재생산)
- 산업 분류 판정 근거
- 각 자산 항목별 회수율 또는 자본화 비율 (Base / Conservative / Applied 표)
- 무형자산 자본화 가정 (감모율, 유효수명)
- 우발부채 식별 결과
- 보수성 등급 (Conservative / Base / Aggressive)

기본은 **Base 회수율**로 산출하되, 보고서에는 Conservative와 Base 두 값을 모두 제시. Aggressive는 사용자 명시 요청 시만.

## 사양 vs 존속 모호 시 조정

판단이 어려운 경우 두 방식 모두 산출하고 **낮은 값**을 AV로 채택. 보고서에는 "두 산식 모두 적용, 보수적 채택" 명시.
