# Mode B: 종목 리스트 2-Stage 스크리닝

2개 이상 종목 또는 CSV/Excel/text 파일 입력 시 본 모드로 진입한다. 모든 종목에 풀 분석을 즉시 적용하면 시간·자원 낭비이므로, 2단계 파이프라인으로 진행한다.

## Stage 0: 입력 파싱

`scripts/parse_ticker_list.py` 사용. `references/input-parsing.md` 참조.

산출: 정규화된 종목 리스트 `[{name, code, market, currency}, ...]`

## Stage 1: Quick Screen (빠른 부적합 솎기)

목적: 풀 분석할 가치가 없는 종목을 빠르게 솎아낸다.

각 종목에 대해 다음 5개 체크를 수행한다 (각 체크는 한 번의 MCP 호출 이하로 끝나야 함).

### Check 1: 데이터 가용성

- 최소 5년 재무제표 가능 여부
- 한국: `open-dart-reader:opendart_finstate_all` 5년분 호출 확인
- 미국: `sec-edgar:get_financials` 호출 확인
- 결과: OK / 3년만 가능 / 데이터 없음

### Check 2: 자본잠식 검사

- 자본총계 < 0 → **Special** (청산가치 별도 분석 후보)
- 자본총계 > 0 → 다음 단계

### Check 3: 누적 적자

- 최근 5년 중 3년 이상 영업적자 → **Special** (수익력 산출 불가, 청산가치 또는 재생산비용으로 판단)
- 그 외 → 다음 단계

### Check 4: 극단적 고평가

- PBR > 5 AND ROE < 자본비용(예: 10%) → **Fail** (자본 파괴 중 + 고평가)
- 그 외 → 다음 단계

### Check 5: 거래 가능성

- 거래정지/상장폐지/관리종목 → **Fail** (분석 의미 없음)
- 그 외 → **Pass**

### Stage 1 분류 결과

| 분류 | 의미 | 다음 단계 |
|---|---|---|
| **Pass** | 풀 분석 적합 | Stage 2 풀 분석 |
| **Special** | 청산가치만 의미 있음 | Stage 2 청산가치 모드만 실행 |
| **Fail** | 부적합 | 분석 종료, 사유 명시 |

## Stage 1 빠른 정량 지표 (Pass 종목 우선순위용)

Pass된 종목에 한해 다음 빠른 지표를 추가 계산하여 우선순위를 매긴다 (풀 분석 전 1차 정렬용).

- 시가총액 / 장부가 비율 (P/B)
- 시가총액 / 매출 (P/S)
- 영업이익 / 시가총액 (E/P 단순화)
- 부채비율
- 5년 ROIC (간이)

빠른 EPV/Market Cap 비율 산출 (대략적):
```
quick_EPV ≈ 최근 영업이익 평균 × (1 - 세율) / 0.10  (WACC 10% 가정)
quick_ratio = quick_EPV / Market Cap
```

quick_ratio가 1보다 크면 잠재 저평가 후보. 우선순위 상위에 둔다.

## Stage 2: Pass 종목 풀 분석

- Pass 종목을 quick_ratio 내림차순(또는 P/B 오름차순)으로 정렬
- **상위 5개**부터 사용자에게 진행 의사 확인 후, Mode A 풀 분석 적용 (`references/mode-a-deep-dive.md`)
- Special 종목은 별도로 청산가치만 산출 (`scripts/compute_av_liquidation.py`)
- Fail 종목은 표에만 표시

사용자가 "전부 분석해줘" 또는 "상위 N개만" 같이 명시하면 그대로 따른다. 명시 없으면 5개 기본.

## Stage 2 진행 시 시간 절약 팁

- 같은 산업 다수 종목 → WACC 산정 시 산업 평균값 재사용
- 같은 시장 종목 → 무위험수익률, ERP 1회 조회 후 공유
- 공통 정성 분석(산업 동향 등)은 1회만 수행하고 종목별 보고서에 인용

```
| 3 | ZZ바이오 | 086520 | KOSDAQ | Fail | - | 4년 연속 적자, 데이터 부족 |
```

## Stage 2 결과 우선순위 표

```
| 순위 | 종목명 | 코드 | quick_ratio | Stage 2 분석 의사 |
|---|---|---|---|---|
| 1 | XX전자 | 005930 | 2.15 | 우선 진행 권장 |
| 2 | AA소재 | 010100 | 1.78 | 진행 권장 |
| 3 | BB정밀 | 020150 | 1.42 | 진행 권장 |
```

표 출력 후 사용자에게 "위 종목들에 대해 Mode A 풀 분석을 진행할까요? (전부/상위 N개/특정 종목 지정)" 안내.

## 데이터 결손/MCP 실패 대응

- 한 종목 데이터 실패 → 그 종목은 "데이터 결손"으로 표기하고 다음 종목 진행 (전체 중단 금지)
- 시장 라우팅 실패 → 사용자에게 시장 명시 요청
- 대량 종목(50개 이상) → 사용자에게 "처리에 시간이 소요됩니다. 우선순위 기준은?" 확인
