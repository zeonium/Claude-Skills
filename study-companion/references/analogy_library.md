# Analogy Library — 도메인별 원천 비유 카탈로그 (v2.3)

비유의 효과는 학습자가 **이미 잘 알고 있는 원천 도메인(source domain)** 에서 가져올 때 극대화된다.  
이 문서는 Study Companion이 `ANALOGY_METAPHOR_TPL` 호출 시 우선 활용할 원천 도메인 목록과,  
각 학문 분야별 권장 매핑, 그리고 비유의 한계 체크리스트를 제공한다.

이론 배경: `educational_theory.md` § 7 (Dual Coding), § 8 (Elaborative Encoding), § 11.

---

## 1. 보편 원천 도메인 카탈로그

거의 모든 학습자가 친숙한 도메인. 학습자의 `familiar_domain`이 미수집된 경우 기본값으로 사용한다.

### 1.1 컴퓨팅·디지털
- **파이프라인 (pipeline)** — 입력→처리→출력의 순차적 변환. ETL·신호처리·생산 공정에 적합
- **필터 (filter)** — 통과 기준에 따른 선별. 베이지안 추론·면역계·법률 심사에 적합
- **캐시 (cache)** — 자주 쓰는 것을 가까이 보관. 단기기억·재고관리·빈도 분석에 적합
- **스택 / 큐 (stack/queue)** — LIFO/FIFO 순서. 우선순위·콜스택·예약 시스템에 적합
- **버퍼 (buffer)** — 속도 차이 흡수. 회계의 운전자본·생체 항상성에 적합
- **API / 인터페이스** — 약속된 입출력 규약. 호르몬 신호·외교 의례·계약법에 적합

### 1.2 생태계·생물
- **포식-피식 (predator-prey)** — 개체수 균형. 시장 경쟁·금리-인플레이션·면역에 적합
- **공생 (symbiosis)** — 상호 의존. 산업 클러스터·플랫폼 생태계·미생물군에 적합
- **유전자 발현 (gene expression)** — 조건부 활성화. 정책 트리거·옵션 행사에 적합
- **호르몬 신호 (hormone signaling)** — 미량으로 큰 변화 유발. 통화정책·촉매 작용에 적합

### 1.3 건축·배관·기계
- **기초·기둥·하중 (foundation/load)** — 구조의 안정성. 자본 구조·심리 안정성·논증 구조에 적합
- **누수 (leak)** — 의도치 않은 손실. 메모리 누수·세금 회피·정보 유출에 적합
- **밸브·압력 (valve/pressure)** — 흐름 제어. 통화량 조절·감정 조절·교통 신호에 적합
- **기어비·레버 (gear ratio/lever)** — 작은 입력 → 큰 출력. 레버리지·복리·정치 캠페인에 적합

### 1.4 교통·이동
- **교차로 (intersection)** — 다중 흐름의 충돌·우선순위. 동시성·자원 경합·외교에 적합
- **병목 (bottleneck)** — 처리량의 최약점. 공정 최적화·시험 출제·심리 한계에 적합
- **우회로 (detour)** — 원래 경로 차단 시 대안. 회복탄력성·비상계획·창의성에 적합
- **신호등 (traffic light)** — 시간 분할 공유. 운영체제 스케줄러·국제회의 의사진행에 적합

### 1.5 요리·식품
- **레시피 (recipe)** — 순서·비율·시간. 알고리즘·계약·실험 프로토콜에 적합
- **숙성 (aging/fermentation)** — 시간이 만드는 변화. 학습 자체·복리·평판 형성에 적합
- **조합·간 맞추기 (seasoning)** — 미세 조정. 모형 튜닝·가격 결정·외교에 적합
- **불 조절 (heat control)** — 강·중·약. 통화정책·교육 강도·운동 페이스에 적합

### 1.6 운동·게임
- **토너먼트 (tournament)** — 단계별 탈락. 선택압·논문 심사·투자 심사에 적합
- **포지션 (position)** — 역할 분담. 조직 설계·세포 분화·팀 빌딩에 적합
- **플레이북 (playbook)** — 상황별 작전. 전략·재해 대응·협상에 적합
- **체크포인트·세이브 (save point)** — 진행 보존. 백업·계약 단계·실험 기록에 적합

### 1.7 일상생활
- **저축통장 (savings account)** — 시간 가치·복리. 학습 누적·근육·신뢰에 적합
- **달력 / 시계** — 주기·예약. 사이클 분석·생체 리듬·축제에 적합
- **거울 (mirror)** — 자기 반사. 메타인지·재귀 함수·법인격에 적합
- **그림자 (shadow)** — 본체와 다른 모습. 통계 추정치·문화 표상·심리 그림자에 적합

## 2. 학문 분야 → 권장 원천 도메인 매핑

학습자가 학문 분야를 명시했을 때 우선 시도할 원천 도메인.

| 학문 분야 | 1순위 원천 | 2순위 원천 | 비고 |
|---------|----------|----------|------|
| 통계·확률 | 도박·스포츠 통계 | 요리(비율·간) | "베이지안 = 스팸 필터" 검증된 비유 |
| 경제·금융 | 생태계·강물 | 기계(레버·기어) | "GDP = 강물 유량", "레버리지 = 지렛대" |
| 양자물리 | 물결·안개 | 도박(확률) | 입자-파동 이중성은 모든 비유가 어딘가 깨짐 |
| 화학 | 요리·블록쌓기 | 댄스(분자운동) | 결합 = 손잡기, 반응 = 안무 교체 |
| 분자생물학 | 공장 생산라인 | 도시 운영 | DNA = 청사진, 효소 = 작업자 |
| 컴퓨터과학 | 일상 도구·요리 | 우편 시스템 | 변수 = 상자, 함수 = 자판기 |
| 머신러닝 | 학생-교사·도제 | 진화·게임 | 학습 = 시험 준비, 강화학습 = 강아지 훈련 |
| 알고리즘 | 길찾기·배달 | 도서관 정리 | 그래프 = 지하철 노선도 |
| 법학 | 게임 규칙 | 교통 법규 | 판례 = 플레이북, 헌법 = 게임 룰북 |
| 역사 | 가족 드라마 | 강의 흐름 | 인과 사슬 = 도미노 |
| 문학·철학 | 거울·여행 | 무대·연극 | 메타인지 = 무대 위 자기 관찰 |
| 의학 | 자동차 정비 | 도시 인프라 | 면역계 = 경찰, 림프 = 하수도 |
| 건축·공학 | 인체·자연구조 | 음악 작곡 | 하중 분산 = 합창 화음 |
| 음악 | 건축·건축물 | 요리 | 곡 구성 = 건물 구조 |
| 정치·외교 | 가족 갈등 | 게임 이론·체스 | 균형 = 식탁 정치 |

## 3. 비유의 한계 체크리스트

비유는 **반드시 어딘가에서 깨진다**. 이 한계를 명시하지 않으면 학습자는 비유를 "정의"로 오해하여 오개념을 형성한다 (Glynn, 1991).  
모든 비유 출력 시 다음 체크리스트로 한계점을 검증하라.

### 3.1 구조적 한계
- [ ] 원천 도메인의 어떤 요소가 목표 개념에 **대응 없이 남는가**? (잉여 요소)
- [ ] 목표 개념의 어떤 요소가 원천에 **대응 없이 누락되는가**? (누락 요소)
- [ ] 원천의 인과 방향과 목표의 인과 방향이 **반대인 지점**이 있는가?

### 3.2 양적 한계
- [ ] 원천의 수치적 직관(예: 선형성)이 목표에선 **비선형**인가?
- [ ] 시간 척도가 다른가? (원천: 초 단위 / 목표: 년 단위)
- [ ] 규모가 다른가? (원천: 개인 / 목표: 사회)

### 3.3 정서·문화적 한계
- [ ] 원천이 학습자에게 **부정적 감정**을 유발하지는 않는가? (예: 전쟁 비유)
- [ ] 원천이 특정 문화·세대에서만 통하는가? (예: 9·11 사례, 80년대 TV)
- [ ] 학습자의 가치관과 충돌하는가?

### 3.4 깨지는 지점 표현 패턴 (출력 가이드)

> "이 비유는 \_\_\_ 측면에서 깨진다. 왜냐하면 원천에서는 \_\_\_이지만, 실제 \_\_\_에서는 \_\_\_이기 때문이다."

예시:
- "베이지안 추론 = 스팸 필터 비유는, 필터가 한 번에 한 메일만 처리하는 반면 실제 베이지안은 동시 다중 가설을 분포로 다룬다는 점에서 깨진다."
- "원자 = 태양계 비유는, 행성 궤도가 결정론적인 반면 전자 위치는 확률 분포라는 점에서 깨진다."

## 4. 비유 품질 평가 기준 (Glynn TWA 모델 응용)

Teaching With Analogies (TWA) 6단계 중 학습 자료에 포함되어야 할 4단계:

1. **Map**: 원천 ↔ 목표의 1:1 대응을 명시 (출력의 `mapping` 필드)
2. **Identify**: 어떤 측면이 유사하고 어떤 측면이 다른지 분리 (`breaking_point` 필드)
3. **Indicate**: 비유가 깨지는 지점을 명시 (`breaking_point` 강제)
4. **Draw**: 학습자가 결론을 스스로 끌어내도록 유도 (Socratic 차원과 결합)

**저품질 비유의 신호**:
- 매핑이 모호하다 ("어떻게 보면 비슷하다")
- 깨지는 지점이 없다 (모든 측면이 일치한다고 주장)
- 학습자에게 친숙하지 않은 원천을 사용한다
- 비유의 비유를 사용한다 (이중 추상화)

## 5. 한국어 학습자 친화 패턴

한국어 문화권 학습자에게 특히 효과적인 원천 도메인:

- **사자성어**: 4글자 압축이 두문자 효과와 결합 (예: "고진감래" → 학습 곡선)
- **속담**: 친숙한 인과 구조 (예: "구슬이 서 말이라도 꿰어야 보배" → 데이터 정제의 중요성)
- **한국 음식 조리**: 비빔밥(앙상블), 김치 발효(시계열), 국물 우리기(증류)
- **명절·세시풍속**: 추석(수확), 정월대보름(오곡밥 다양성)
- **K-드라마 클리셰**: 출생의 비밀(잠재 변수), 재벌(자본 집중), 환생(재귀)
- **분식집 메뉴**: 떡볶이(기본+옵션 = 함수 인자), 라볶이(합성)

이 패턴은 학습자의 `learning_style.preferred_language == "ko"`일 때 우선 활용한다.

## 6. 비유 도메인 사용 흔적 추적

같은 학습자에게 **같은 원천 도메인을 반복 사용하면 효과가 떨어진다** (Novelty Effect 감소).  
Memory MCP의 `Learner` 엔터티에 `analogy_domains_used: list[str]` 관계를 누적 저장하여,  
새 비유 생성 시 직전 5개 도메인을 회피하도록 프롬프트를 조정한다.

구현은 `scripts/content_generator.py`의 `_analogy()` 핸들러에서 처리.
