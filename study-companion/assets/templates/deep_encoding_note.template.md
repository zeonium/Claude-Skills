## 🔄 자가 점검 (Feynman Technique)

다음 질문에 막힘 없이 답할 수 있다면 이 챕터는 장기기억으로 전이된 것입니다.

- [ ] 이 챕터의 핵심 개념을 처음 듣는 친구에게 5분 안에 비유로 설명할 수 있는가?
- [ ] 위 사례 중 하나를 30초 안에 이야기로 풀어낼 수 있는가?
- [ ] 기억 훅을 떠올리면 즉시 외워야 할 항목 목록이 인출되는가?
- [ ] 비유의 "깨지는 지점"을 정확히 짚을 수 있는가? (오개념 방지)

미충족 항목이 있으면 해당 섹션으로 돌아가 다시 한 번 천천히 읽고,
한 달 후 이 노트를 다시 열어 자가 점검하세요.

## 📅 복습 스케줄 (Spaced Retrieval)

| 시점 | 권장 활동 |
|------|---------|
| 학습 직후 | 비유 1개를 자기 말로 다시 설명해보기 |
| 1일 후 | 사례 1개를 다른 사람에게 이야기해보기 |
| 1주 후 | 기억 훅으로 항목 목록 인출 시도 |
| 1개월 후 | 자가 점검 4문항 모두 통과 |
| 3개월 후 | 새로운 사례를 스스로 1개 만들어보기 (Generation Effect) |
