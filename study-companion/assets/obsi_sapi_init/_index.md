# Study Companion 대시보드

> 이 볼트는 **Study Companion** Claude Desktop 스킬이 자동으로 관리합니다.

## 시작하기

Claude Desktop에서 다음과 같이 말씀하세요:

- **"이 책으로 공부 시작"** — 새 교재로 학습 시작
- **"오늘 학습"** — 오늘 세션 진행
- **"복습 카드 보여줘"** — SRS 복습
- **"진도 어떻게 돼"** — 대시보드 확인
