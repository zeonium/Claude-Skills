# Joel Greenblatt - Magic Formula

출처: "The Little Book That Still Beats the Market" (2010)

---

## 핵심 철학

> "좋은 기업을 싸게 사라. 이것이 전부다."
> — Joel Greenblatt

---

## 핵심 공식

**EY (이익수익률) = EBIT / EV**
- EV = 시가총액 + 순부채 (총금융부채 - 현금)
- EY 높을수록 → 싼 주식

**ROC (투자자본수익률) = EBIT / (순고정자산 + 순운전자본)**
- 순고정자산 = 유형고정자산 순액
- 순운전자본 = MAX(0, 유동자산 - 유동부채 - 초과현금)
- ROC 높을수록 → 좋은 기업

---

## 랭킹 기반 접근법

절대값이 아닌 **상대 순위**로 평가:
1. 유니버스 전체 EY 내림차순 순위 (1위 = 최고 EY)
2. 유니버스 전체 ROC 내림차순 순위
3. 두 순위 합산 → 합산 낮을수록 최우수
4. 상위 20~30개 종목 매수

예: A(EY5위+ROC127위=132), B(EY98위+ROC38위=136), C(EY47위+ROC51위=98) → C 최우수

## 제외 종목

- 금융섹터 (은행/보험/증권/카드): EBIT 개념 불가
- 유틸리티 섹터: 규제산업
- 시총 500억원 미만 (한국 기준)

---

## Greenblatt Score 구성 (100점)

EY 랭킹 50점 + ROC 랭킹 50점 (유니버스 퍼센타일 기반)
단일종목: EY>=15%→50, ROC>=25%→50 (절대값 기준표 적용)
