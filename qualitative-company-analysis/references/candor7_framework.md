# CANDOR-7 프레임워크 (Rittenhouse 2013 통합)

> **출처**: L.J. Rittenhouse, *Investing Between the Lines* (McGraw-Hill, 2013).
> 1,000건 이상 주주 서한 분석 + 130개 채점 주제 + 1~20점 가중치 체계.
> **실증**: Candor 상위 25% 누적 59.8% vs S&P 500 36.4% vs 하위 25% 15.3% (2005-2011).

---

## 1. 핵심 가설

> "경영진의 솔직함(Candor)은 미래 재무성과의 강력한 선행 지표이며,
> 의사소통 리스크는 아직 선언되지 않은 재무 리스크다."

재무제표는 **후행 지표(lagging)**. 언어는 그 숫자가 만들어지기 _이전_의 **선행 지표(leading)**.

### 의사소통 리스크 → 재무 리스크 전이 메커니즘

```
[1] 진실의 은폐
    └ 불리한 사실을 위즐워드·복잡문장으로 가림
        ↓
[2] 자기기만 (Self-deception, Orwell)
    └ "언어가 사고를 타락시켜" 경영진 스스로 왜곡을 현실로 믿음
        ↓
[3] 구조적 결함 방치
    └ 문제 미공개 → 리스크 통제·궤도 수정 미작동
        ↓
[4] 치명적 재무위기 발현
    └ 시장 변동 시 안개에 가렸던 결함 표면화 → 구제금융·파산
```

## 2. 7-시스템 진단 격자

지속 가능한 비즈니스의 7대 시스템을 인체 비유로 배치. 각 0~5점 평가 → 레이더 프로필.

| # | 시스템 | 위치 | 평가 핵심 | 점검 질문 | 기존 D1 매핑 |
|---|--------|------|-----------|-----------|--------------|
| ① | **Capital Stewardship** | 중심축 (Hub) | 자본을 주주로부터 '수탁'받은 것으로 다루는가 | 현금흐름 투명성·재무상태표 관리·자본 규율·리스크 인식이 보이는가 | 자본배분 합리성 |
| ② | **Strategy** | 좌뇌 | 복잡한 계획을 명료하게 단순화하는가 | 기회·포지셔닝·경쟁우위가 구체적인가 | 전략적 일관성 |
| ③ | **Accountability** | 좌뇌 | 약속 목표와 실제 결과를 수치로 대조하는가 | 과거 약속의 이행 여부를 정직하게 보고하는가 | 예측 정확성 |
| ④ | **Vision** | 우뇌 | 존재 목적과 혁신적 사고가 있는가 | 상투어가 아닌 독창적 어휘로 미래를 그리는가 | (신규) |
| ⑤ | **Leadership** | 우뇌 | 투자자를 교육하려 하고 실수를 인정하는가 | 리스크·기회에 대한 세계관이 솔직한가 | Q&A 투명성 |
| ⑥ | **Stakeholder** | 척추 | 고객·직원·주주 필요를 균형 있게 충족하는가 | 공감과 현장 스토리가 있는가, 'Me First' 문화는 아닌가 | (신규) |
| ⑦ | **Candor** | 척추 | 모든 시스템을 관통하는 투명성 | FOG가 제거되어 있는가 | Net Candor Score |

### 레이더 프로필 해석

- **균형형 (모든 축 3+)**: Candor Premium 후보
- **자본수탁 함몰 (① < 2)**: 자본배분 위험 — 가치파괴 M&A·고점 자사주
- **책임감 함몰 (③ < 2)**: 가이던스 회피·목표 후퇴 패턴
- **솔직함 함몰 (⑦ < 2)**: FOG 농도 짙음, 다른 모든 축의 신호 가치 하락
- **이해관계자 함몰 (⑥ < 2)**: 'Me First' 문화, 보상-주주이익 괴리

## 3. Net Candor Score 정량 채점

### 3.1 배점표

| 구분 | 평가 항목 | 점수 |
|------|-----------|------|
| 가점 | 정성적 목표 제시 ("ROE를 높이겠다") | +5 |
| 가점 | 정량적 목표 제시 ("수익 4~6% 성장", "2027년까지 매출 X조") | +10 |
| 가점 | 우수 목표의 맥락·세부사항 추가 (지표·달성방안당) | +5 |
| 가점 | 'Cash/Cash flow' 단어 사용 (언급당) | +3 |
| 가점 | 현금흐름의 구체적 맥락·디테일 (설명당) | +3 |
| 감점 | 상투어 (Cliché) (문구당) | -3 |
| 감점 | 위즐 워드 (Weasel Word) (단어당) | -3 |
| 감점 | 오웰적 미사여구 (문장당) | -5 |
| 감점 | 전략적 부조화 (핵심가치와 모순) | -10 |

> 참고: 엔론의 2000년 서한은 **단 한 문단에서만 FOG로 -26점** 감점.

### 3.2 산식

```
Net Candor Score    = Σ(가점) - Σ(감점)
Communication Efficiency = Net Candor Score ÷ 서한 총 단어 수  (단어당 의미 밀도)
FOG 비율            = Σ(감점) ÷ (Σ(가점) + Σ(감점))
Candor Index        = (1 - FOG 비율) × 100   [0~100 정규화]
```

### 3.3 해석 기준

| Candor Index (FOG 비율) | 판정 | 의미 |
|------------------------|------|------|
| 75~100 (0~25%) | **모범 (Best Practice)** | Candor Premium 후보 |
| 50~74 (25~50%) | **경계 (Watch)** | 추세·항목 모니터링 필요 |
| < 50 (Net Score < 0) | **위험 (Red Flag)** | 경영진이 비즈니스 미파악 또는 은폐 중 — 중대 문제 임박 신호 |

### 3.4 추세 해석

- **절대값 < 전년 대비 delta**
- Net Score (+) → (-) 전환: 펀더멘털 악화 선행 신호 — 알림 발동
- Candor Index YoY -15p 이상 하락: 경영진 변화 또는 위기 은폐 의심

## 4. 5단계 포렌식 분석 절차

```
┌─────────────────────────────────────────────┐
│  STEP 1  레드펜 테스트 (Red Pen Test)         │
│   서한 인쇄 → 상투어·전문용어에 빨간 밑줄        │
│   종이가 붉어질수록 FOG 농도 ↑                  │
│   → scripts/fog_lexicon_scorer.py 실행          │
├─────────────────────────────────────────────┤
│  STEP 2  수치 교차검증                          │
│   서한의 순이익·매출 vs 감사보고서 실제 수치      │
│   불일치 시 각주의 일회성 비용·손실 추적          │
│   → 10-K/사업보고서 vs 서한 인용 수치 비교        │
├─────────────────────────────────────────────┤
│  STEP 3  잉여현금흐름 (FCF) 맥락 평가            │
│   회계이익이 아닌 FCF를 정의·설명하는가?         │
│   = 자본 수탁 책임 의식 평가                    │
│   → ceo_letter_forensics.py 'fcf_context' 지표  │
├─────────────────────────────────────────────┤
│  STEP 4  전략적 일관성·이정표 확인               │
│   매년 유행어를 갈아타는가 vs 일관 전략          │
│   "최선을 다하겠다"(X) vs "언제까지 얼마"(O)     │
│   → semantic_diff_kit.py로 서한 3년치 비교       │
├─────────────────────────────────────────────┤
│  STEP 5  실수 대처법 관찰                       │
│   환경·규제 탓(X) vs 스스로 분석·학습 공유(O)   │
│   → ceo_letter_forensics.py 'mistake_pattern'   │
└─────────────────────────────────────────────┘
        ↓
   7-시스템 레이더 + Net Candor Score + Candor Index 산출
```

## 5. Red Flags / Green Flags (CANDOR-7 한정)

### 5.1 즉각적 위험신호 (Red Flags)

- [ ] **CEO가 서한을 직접 쓰지 않음 / IR 대행 집필** — 버핏 "중대한 감점(black mark)". 비즈니스 미장악 또는 진실 회피.
- [ ] **오웰적 자기모순 문장** — 손실을 "중요하지 않을 수도/중요할 수도" 식 (예: 2007 AIG 마틴 설리번).
- [ ] **위즐워드·상투어 남발** — 구체 전략 없는 "시너지 레버리지", "재능 있는 인재".
- [ ] **실적 지표의 잦은 변경** — 부진을 가리려 매년 유리한 지표로 갈아탐 (예: '비경상 제외 전 순이익' → '순이익').
- [ ] **책임 전가·변명** — "글로벌 규제 환경의 예측 불가능한 변화" 등 외부 탓.
- [ ] **본질보다 외형 과시** — 과거 랭킹·시장점유율·주가 홍보에 치중 (예: 2007 리먼, WaMu '파워하우스').
- [ ] **'Me First' 문화 노출** — 고객 가치 대신 자사 수수료를 성과로 제시 (예: 리먼의 'sales credits 40% 증가').

### 5.2 신뢰의 긍정신호 (Green Flags / Candor Premium)

- [ ] **변명 없는 잘못의 인정** — "사실 우리가 늑장 부리는 나쁜 습관에 빠졌다" (Expeditors International).
- [ ] **구체적 성과 이정표** — "2008년까지 50억 달러 비용 절감, 2009년 수익성 달성" (Ford, Alan Mulally의 One Team/One Plan/One Goal).
- [ ] **자본 수탁을 보여주는 FCF 맥락** — FCF를 "성장 자본지출 제외 후 남은 현금"으로 정의하고 5년 전과 대조 (J&J, Ralph Larsen, 2001).
- [ ] **박수받는 나쁜 소식 (문화적 엑소시즘)** — 출시 지연 '빨간불' 보고에 화내지 않고 박수 (Ford, Mulally-Mark Fields).
- [ ] **가치를 증명하는 현장 스토리** — "헌신" 상투어 대신 혹한 속 직원에게 주민이 건넨 '크리스마스 쿠키' 일화 (Dominion Resources, Tom Capps, 1998).

## 6. 적용 한계 (반증 가능성)

1. **언어는 보조 변수** — 밸류에이션·재무건전성을 대체하지 않고 보강.
2. **채점의 주관성** — 위즐워드·오웰 문장 판정에 평가자 편차. 동일 룰북·복수 평가자 권장.
3. **표본 편의** — 2005~2011 실증, 미래 보증 아님.
4. **언어 능숙 ≠ 정직** — 세련된 화법이 정교한 은폐일 수 있어 **STEP 2 수치 교차검증 필수**.
5. **문화·언어권 차이** — 한국 사업보고서 사장 인사말은 영어권 서한 대비 짧고 형식적. KR 기준 별도 조정 필요 (`kr_market_specifics.md`).
