# 점수화 시스템 & 6케이스 행동지침

## QualScore 산식

```
QualScore = D1×0.30 + D2×0.30 + D3×0.15 + D4×0.15 + D5×0.10
```

각 차원은 0~100점. 총합 0~100.

## 경영진 신뢰도 스코어카드 (D1 세부 — CANDOR-7 통합)

### Quick Scorecard (5항목, 50% 가중)

| 항목 | 0점 | 1점 | 2점 |
|------|-----|-----|-----|
| 전략적 일관성 | 분기마다 전략 변경 | 일부 변동 | 3년+ 일관된 방향 |
| 자본배분 합리성 | 고점 자사주 매입, 가치 파괴 M&A | 보통 | 저점 매입, 고수익 M&A |
| Q&A 투명성 | 회피·모호 답변 다수 | 일부 회피 | 수치 기반 직접 답변 |
| 내부자 거래 | 대규모 비계획 매도 | 혼재 | 10b5-1 계획 매도만 |
| 예측 정확성 | 가이던스 하회 반복 | 일부 하회 | 4분기+ 상회 |

최고 점수: 10점 → Quick Scorecard = 점수 × 10 (0~100)

### Candor Index (CANDOR-7, 30% 가중)

```
Net Candor Score = Σ가점 - Σ감점
FOG 비율         = Σ감점 / (Σ가점 + Σ감점)
Candor Index    = (1 - FOG 비율) × 100   [0~100]
```

| Candor Index | 판정 | D1 자동 보정 |
|--------------|------|--------------|
| 75~100 | 모범 (FOG ≤ 25%) | Quick Scorecard +5 보너스 가능 |
| 50~74 | 경계 (FOG 25~50%) | 보정 없음 |
| < 50 (Net Score < 0) | 위험 | **자동 C등급 후보 (D1 캡 50점)** |

### D1 종합 산식

```
D1 = Quick Scorecard × 0.50
   + Candor Index × 0.30
   + Moving Targets 패턴 × 0.10
   + 내부자 거래 패턴 × 0.10
```

### Candor Premium 보너스 (선택적)

다음 모두 충족 시 D1에 추가 +5 보너스:
- Candor Index ≥ 80
- 전년 대비 Net Candor Score 상승
- CEO 자기 집필 확인 (1인칭 빈도 ≥ 평균)
- FCF 정의 + 5년 전 대조 (J&J Larsen 패턴)

### Candor Crash 페널티 (강제)

다음 중 1개 충족 시 D1에 -10 페널티 강제:
- 오웰적 자기모순 문장 발견 (AIG 2007 패턴)
- 엔론 '독성 6종 세트' 한 문단 집중 (`fog_lexicon_scorer.py --detect-enron-pattern` Y)
- Net Candor Score (+) → (-) 전환 (전년 대비)
- 서한 인용 수치 vs 감사보고서 수치 불일치 (STEP 3A-2)

## 정량×정성 2D 매트릭스 (6케이스)

```
         정량 점수
         높음(≥70)     낮음(<70)
정성  높음(≥70)  Strong Buy    Watch
점수  낮음(<70)  Hold          Strong Avoid
```

### 6케이스 상세 행동지침

**Case 1: Strong Buy** (정량 ≥ 70, QualScore ≥ 80)
- 포지션 크기: 포트폴리오 3~5%
- 모니터링: 분기별 재평가
- 재평가 트리거: QualScore 10p 이상 하락, 경영진 교체

**Case 2: Buy** (정량 ≥ 70, QualScore 70~79)
- 포지션 크기: 포트폴리오 1~3%
- 모니터링: 분기별
- 재평가 트리거: QualScore 하락 또는 Moving Target 적신호 증가

**Case 3: Watch** (정량 < 70, QualScore ≥ 70)
- 포지션 크기: 관망 (매수 보류)
- 모니터링: 월별 정량 지표 확인
- 재평가 트리거: 정량 개선 확인 후 매수 검토

**Case 4: Hold** (정량 ≥ 70, QualScore 60~69)
- 포지션 크기: 기존 보유자 유지, 신규 진입 보류
- 모니터링: 월별
- 재평가 트리거: QualScore 70 이상 개선 시 추가 매수

**Case 5: Avoid** (정량 < 70, QualScore 50~69)
- 포지션 크기: 보유 시 감소 고려
- 모니터링: 분기별 트리거 확인
- 재평가 트리거: 양쪽 모두 개선 시 재검토

**Case 6: Strong Avoid** (정량 < 70, QualScore < 60)
- 포지션 크기: 매도 또는 회피
- 모니터링: 6개월 후 재평가
- 재평가 트리거: 경영진 교체 + 전략 방향 전환 확인 후

## Conviction Score (1~5)

| 점수 | 의미 | 근거 충분도 |
|------|------|-----------|
| 5 | 매우 높음 | T1 데이터 풍부 + RAG 검증 완료 + 편향 점검 완료 |
| 4 | 높음 | T1+T2 데이터, RAG 부분 검증 |
| 3 | 보통 | T1 기본 확인, T3 교차검증 필요 |
| 2 | 낮음 | T3~T4 위주, T1 미확인 주장 있음 |
| 1 | 매우 낮음 | 데이터 부족, 추가 리서치 필요 |
