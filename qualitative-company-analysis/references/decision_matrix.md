# 점수화 시스템 & 6케이스 행동지침

## QualScore 산식

```
QualScore = D1×0.30 + D2×0.30 + D3×0.15 + D4×0.15 + D5×0.10
```

각 차원은 0~100점. 총합 0~100.

## 경영진 신뢰도 스코어카드 (D1 세부)

| 항목 | 0점 | 1점 | 2점 |
|------|-----|-----|-----|
| 전략적 일관성 | 분기마다 전략 변경 | 일부 변동 | 3년+ 일관된 방향 |
| 자본배분 합리성 | 고점 자사주 매입, 가치 파괴 M&A | 보통 | 저점 매입, 고수익 M&A |
| Q&A 투명성 | 회피·모호 답변 다수 | 일부 회피 | 수치 기반 직접 답변 |
| 내부자 거래 | 대규모 비계획 매도 | 혼재 | 10b5-1 계획 매도만 |
| 예측 정확성 | 가이던스 하회 반복 | 일부 하회 | 4분기+ 상회 |

최고 점수: 10점 → D1 점수 변환: 점수 × 10 = D1 (0~100)

## 등급 매핑

| 등급 | QualScore | 의미 |
|------|-----------|------|
| A+ | 90~100 | 탁월한 정성적 품질 |
| A | 80~89 | 우수 |
| B+ | 70~79 | 양호 (주의 구간) |
| B | 60~69 | 보통 (추가 검증 필요) |
| C | 50~59 | 미흡 |
| D | 0~49 | 부적격 |

## 정량×정성 2D 매트릭스 (6케이스)

```
         정량 점수
         높음(≥70)     낮음(<70)
정성  높음(≥70)  Strong Buy    Watch
점수  낮음(<70)  Hold          Strong Avoid
```

### 6케이스 상세 행동지침

**Case 1: Strong Buy** (정량 ≥ 70, QualScore ≥ 80)
- 포지션 크기: 포트폴리오 3~5%
- 모니터링: 분기별 재평가
- 재평가 트리거: QualScore 10p 이상 하락, 경영진 교체

**Case 2: Buy** (정량 ≥ 70, QualScore 70~79)
- 포지션 크기: 포트폴리오 1~3%
- 모니터링: 분기별
- 재평가 트리거: QualScore 하락 또는 Moving Target 적신호 증가

**Case 3: Watch** (정량 < 70, QualScore ≥ 70)
- 포지션 크기: 관망 (매수 보류)
- 모니터링: 월별 정량 지표 확인
- 재평가 트리거: 정량 개선 확인 후 매수 검토

**Case 4: Hold** (정량 ≥ 70, QualScore 60~69)
- 포지션 크기: 기존 보유자 유지, 신규 진입 보류
- 모니터링: 월별
- 재평가 트리거: QualScore 70 이상 개선 시 추가 매수

**Case 5: Avoid** (정량 < 70, QualScore 50~69)
- 포지션 크기: 보유 시 감소 고려
- 모니터링: 분기별 트리거 확인
- 재평가 트리거: 양쪽 모두 개선 시 재검토

**Case 6: Strong Avoid** (정량 < 70, QualScore < 60)
- 포지션 크기: 매도 또는 회피
- 모니터링: 6개월 후 재평가
- 재평가 트리거: 경영진 교체 + 전략 방향 전환 확인 후

## Conviction Score (1~5)

| 점수 | 의미 | 근거 충분도 |
|------|------|-----------|
| 5 | 매우 높음 | T1 데이터 풍부 + RAG 검증 완료 + 편향 점검 완료 |
| 4 | 높음 | T1+T2 데이터, RAG 부분 검증 |
| 3 | 보통 | T1 기본 확인, T3 교차검증 필요 |
| 2 | 낮음 | T3~T4 위주, T1 미확인 주장 있음 |
| 1 | 매우 낮음 | 데이터 부족, 추가 리서치 필요 |
