# 섹터별 방법론 플레이북 (Industry-Specific Valuation Playbook)

## 기업 유형 분류 트리

```
기업 입력
  ├─ 금융(은행/보험/증권)? → [A] 금융주 플레이북
  ├─ REIT/부동산? → [B] REIT 플레이북
  ├─ 에너지/원자재/사이클? → [C] 사이클 플레이북
  ├─ 지주/복합기업(사업다각화)? → [D] 지주 플레이북
  ├─ 적자기업/턴어라운드? → [E] 적자 플레이북
  ├─ 고성장(매출 YoY > 20%)? → [F] 성장주 플레이북
  ├─ 배당주(배당성향 > 50%)? → [G] 배당주 플레이북
  ├─ 바이오/제약(R&D집약·파이프라인)? → [I] 바이오 플레이북 ★ Real Options 의무
  ├─ 하이테크/플랫폼(고변동성·옵션성)? → [J] 하이테크 플레이북 ★ Real Options 의무
  ├─ 수주산업(건설/조선/플랜트/방산)? → [K] 수주산업 플레이북 ★ Backlog-DCF + Growth Option 의무
  └─ 그 외(성숙 제조/서비스)? → [H] 성숙기업 플레이북 (기본값)
```

## [A] 금융주 플레이북 (은행/보험/증권)

### 핵심 제약
- **FCFF/WACC 기반 EV 계산 금지** — 부채가 '원재료'라 기업가치 개념 적용 불가
- **자기자본 직접 평가** — P/B, P/E, RIM, DDM 사용

### 권장 방법
| 방법 | 가중치 | 근거 |
|---|---|---|
| RIM (잔여이익) | 50% | 규제자본/장부가치가 경제적 실체와 연결됨 |
| DDM / FCFE | 25% | 배당 및 자사주 환원 직접 반영 |
| P/TBV 상대가치 | 25% | 업종 표준 멀티플 |

### 핵심 지표
- **ROE vs Ke**: ROE > Ke → P/B > 1 정당, ROE < Ke → P/B < 1
- **NIM (순이자마진)**: 금리 환경 변화 민감도
- **BIS 자기자본비율**: 규제자본 여력 (성장/배당 여력)
- **NPL 비율 / 대손충당금**: 자산 건전성

### 민감도 핵심 변수
- ROE ±2pp → 내재가치 변화
- Ke ±1pp → 내재가치 변화
- NIM ±10bp → ROE 영향

### OCI(기타포괄손익) 주의
- 금리 변동 시 채권평가손익 OCI 발생
- Clean surplus 훼손 여부 점검 → RIM 조정 필요

## [B] REIT / 부동산 플레이북

### 핵심 특이사항
- **GAAP 감가상각의 인위성**: 부동산은 실제로 가치 하락하지 않는 경우 많음
- GAAP 순이익은 감가상각으로 낮게 나옴 → **FFO/AFFO** 사용

### FFO 계산
```
FFO = GAAP 순이익 + 부동산 감가상각 − 자산매각손익
AFFO = FFO − 자본적 유지보수 지출(Capex for maintenance)
```

### 권장 방법
| 방법 | 가중치 | 설명 |
|---|---|---|
| P/FFO, P/AFFO | 35% | 섹터 표준 — Nareit 권고 |
| NAVPS (순자산가치/주) | 35% | 부동산 공정가치 기반 |
| DCF (AFFO 기반) | 30% | 장기 현금창출력 |

### NAVPS 계산
```
NAVPS = (부동산 공정가치 − 부채 − 기타부채) / 발행주식수
부동산 공정가치 = 임대NOI / Cap Rate (업종 캡레이트)
```

### 주요 지표
- Cap Rate: 시장 캡레이트 vs 포트폴리오 캡레이트
- 점유율: 임대율 변화
- FFO 성장률, AFFO 배당성향

## [C] 에너지/원자재/사이클 플레이북

### 핵심 문제
- 최근 실적이 사이클 위치에 종속됨 → 단순 외삽 = 심각한 오평가
- 원자재 가격 사이클 정규화 필수

### 정규화 방법
```
정규화 EBITDA = 사이클 전체(최소 7~10년) 평균 마진 × 현재 매출 규모
정규화 FCF = 정규화 EBITDA × (1 − 재투자율) × (1 − t)
```

### 권장 방법
| 방법 | 가중치 |
|---|---|
| 정규화 FCF DCF | 50% |
| EV/EBITDA (사이클 평균 배수) | 30% |
| 자산가치(자원 매장량) | 20% |

### 시나리오 필수 설정
- 원자재 가격 시나리오: Low / Base / High
- 각 시나리오별 EBITDA, FCF, 내재가치 계산

### 실물옵션 관점 (미개발 매장량) — Real Options 의무
- 행사 시점 선택 권리 보유 → 콜옵션
- **Black-Scholes + 이항 격자 둘 다 산출 후 교차검증** → [advanced-valuation.md §1.4~§1.6]
- 입력값: S=매장량×현재 원자재가 PV, K=개발 CAPEX, T=매장권 잔여, σ=원자재가 변동성
- Strategic NPV = 정규화 DCF + Σ Real Option (매장량별)

## [D] 지주/복합기업 플레이북

### SOTP 프로세스

1. **사업부 목록화** + 각 사업부 속성 파악
2. **사업부별 개별 평가**:
   - 상장 자회사 → 시가 × 지분율
   - 비상장 자회사 → 해당 업종 멀티플 DCF
3. **공통비(본사) PV 차감**
4. **순부채 차감** (연결 기준 일원화)
5. **홀딩 디스카운트 적용**: 10~30%

### 홀딩 디스카운트 판단 기준
| 상황 | 디스카운트 |
|---|---|
| 지배주주 사익편취 이슈 없음 | 10~15% |
| 일부 거버넌스 우려 | 15~25% |
| 오너 일가 지분/내부거래 복잡 | 25~35% |

### 주의사항
- 공통비 (본사 SG&A 중 사업부 미배분분) 별도 차감
- 이중계상 제거: 자회사 순자산 vs 지주 장부가 혼용 금지
- 비상장 자회사는 최근 1~2년 실적 기준 멀티플 적용

## [E] 적자기업/턴어라운드 플레이북

### 접근 순서
1. **구조적 문제 vs 일시적 문제** 진단
   - 구조적: 사업모델 붕괴, 기술 대체 → 매우 높은 위험
   - 일시적: 초기 투자기, 사이클 저점, 비용 선행 → 전환 경로 분석
2. **청산가치 하방** 계산 (하한선)
3. **전환 경로 DCF** (FCF 양수 전환 가정)

### 권장 방법
| 방법 | 가중치 |
|---|---|
| 전환경로 DCF (예: Y+3 흑자 가정) | 40% |
| EV/Sales (스케일 기반) | 40% |
| RIM / 장부가치 | 20% |

### 적자기업 FCF 예측 구조
```
매출: 현재 → 성장률 가정 → 정상화 단계
마진: 현재 음수 → 단계적 개선 → 업종 평균 목표 마진
전환 시점: 흑자 전환 예상 연도 명시
```

### 주식의 옵션적 성격
- 기업가치 < 부채 액면가여도 주식 ≠ 0
- 주식 ≈ 기업자산에 대한 콜옵션 (행사가: 부채)
- 변동성 높을수록 OTM 옵션 가치 증가

## [F] 고성장주 플레이북 (YoY > 20%)

### 핵심 도전
- 장기 성장·마진 정상화·재투자 효율의 불확실성 집중
- 터미널 밸류 비중이 매우 높아짐 (>80%)
- DCF가 이론적으로 맞지만 가정 오차가 커짐

### 권장 방법
| 방법 | 가중치 |
|---|---|
| 멀티스테이지 DCF (3단계) | 40% |
| 역DCF + 성장 달성 가능성 | 30% |
| EV/Sales or EV/ARR (SaaS) | 30% |

### 3단계 DCF 구조
```
1단계 (1~5년): 현재 고성장 유지 (매출 성장률: 현재)
2단계 (6~10년): 점진적 성장 둔화 (선형 감소)
3단계 (11년~): 안정성장 (g = Rf)
```

### SaaS/구독형 특수 지표
- ARR (연간반복매출), NRR (순매출유지율)
- CAC/LTV 비율: LTV/CAC > 3 = 건전한 유닛 이코노미
- Rule of 40: 성장률% + EBITDA마진% ≥ 40

### 역DCF로 현실성 테스트
```
현재 주가 → 역산 성장률 도출
→ "이 성장률이 향후 10년 유지 가능한가?"
→ 업종 최상위 기업 역사적 성장률과 비교
```

## [G] 배당주/고배당 플레이북

### 권장 방법
| 방법 | 가중치 |
|---|---|
| 다단계 DDM | 50% |
| FCFE DCF | 30% |
| P/E 상대가치 | 20% |

### 다단계 DDM 구조
```
1단계 (1~5년): 실제 배당 예측
2단계 (6~10년): 배당 성장 둔화
터미널: 고든성장 = D_n+1 / (Ke − g)
```

### 주주환원 총액 기반 확장
- 배당 + 자사주 매입을 합산한 총 주주환원 사용
- 잉여현금흐름 중 주주환원 비율(payout efficiency) 점검

## [H] 성숙기업 플레이북 (기본값)

### 권장 방법
| 방법 | 가중치 |
|---|---|
| FCFF DCF | 50% |
| EV/EBITDA 상대가치 | 30% |
| RIM | 10% |
| 자산가치 | 10% |

### 성숙기업 특징
- 성장률 GDP 수준 (2~5%)
- 마진 안정화
- FCF 안정적 창출
- DCF 예측기간: 5~7년

### 주요 체크사항
- 사업 성숙도: 시장 점유율 안정 여부
- 재투자 필요성: 유지보수 CAPEX vs 성장 CAPEX 구분
- 배당/자사주 정책: 잉여현금흐름 배분 효율성

## [I] 바이오/제약 플레이북 (R&D집약·파이프라인) — Real Options 의무

### 핵심 도전

- 매출이 1~2개 핵심 후보물질에 집중, 임상 실패 시 가치 급락
- 임상 단계별 의사결정 = compound option 구조
- **정적 DCF는 음(-)의 NPV로 잘못 판정할 위험이 큼** → Real Options 의무 적용

### 권장 방법

| 방법 | 가중치 | 비고 |
|---|---|---|
| rNPV + Real Options (Strategic NPV) | 40% | 파이프라인별 성공확률 가중 + compound option 가치 |
| 멀티스테이지 DCF (승인·상용화 시나리오) | 30% | 매출 정상화 가정 |
| EV/Sales (피어 멀티플) | 30% | 후기 파이프라인 보유 시 |

### rNPV 산출 절차

→ **[advanced-valuation.md §1.6]** 참조

```
1. 파이프라인 목록화 (각 후보물질 + 적응증)
2. 단계별 성공확률 적용:
   Pre-clinical: 10% / Phase I: 63% / Phase II: 31% / Phase III: 58% / 승인: 85%
3. Peak Sales 추정:
   타겟 환자수 × 점유율 × 연간 약가 × 마진
4. 잔여 특허기간 동안 매출 곡선 (Bass diffusion)
5. 각 단계 R&D 비용 차감
6. rNPV = Σ [성공확률 × 현금흐름 PV] − Σ [R&D 비용 PV]
```

### Real Options 추가 가치 (Compound Option)

```
- 적응형 임상 디자인: 중간 결과 따라 코호트 추가 = Switch Option
- 동시 적응증 확장: 1차 적응증 성공 시 2차 진입 = Growth Option
- 라이선스 아웃 권리: 마일스톤 지급 시점 선택 = Deferral Option
- 임상 중단권: 손실 한정 = Abandonment Option
```

→ Black-Scholes + 이항 격자 둘 다 산출 후 합산.

### WACC 조정 — 임상실패 프리미엄

| 단계 | 추가 프리미엄 |
|---|---|
| Pre-clinical | +6.0~8.0pp |
| Phase I | +4.0~6.0pp |
| Phase II | +3.0~5.0pp |
| Phase III | +1.0~3.0pp |
| 승인 후 (상용화 전) | +0.5~1.5pp |
| 상용화·블록버스터 | +0.0pp (일반 ERP) |

→ 가중평균 WACC = 기본 WACC + (단계별 매출 비중 × 단계별 프리미엄)

### 핵심 데이터 출처

```
- ClinicalTrials.gov 임상 단계 확인
- 회사 IR 자료 "Pipeline" 슬라이드
- mcp__sec-edgar__get_filing_sections (10-K Item 1 "Pipeline")
- mcp__open-dart-reader__opendart_extract_document_sections (사업보고서)
- mcp__valyu_bio_search (질환별 시장규모)
```

### 핵심 리스크

- 단일 후보물질 실패 (Phase III 실패 시 시총 −60~80%)
- 경쟁사 First-in-class 출시
- 약가 인하 압력 (메디케어·건강보험심사평가원)
- 특허 절벽 (Patent Cliff)

## [J] 하이테크/플랫폼 플레이북 (고변동성·옵션성) — Real Options 의무

### 핵심 특징

- 현재 제품의 매출은 작지만 **플랫폼·생태계 가치**가 잠재
- 후속 제품·시장 확장 가능성이 가치의 핵심
- σ가 매우 큼 (40~70%) → Real Options 가치가 정적 NPV를 압도할 수 있음

### 권장 방법

| 방법 | 가중치 | 비고 |
|---|---|---|
| 멀티스테이지 DCF + Growth Option | 40% | 정적 DCF + 후속 제품 옵션 |
| 역DCF (시장 임플라이드 성장률) | 30% | 현실성 점검 |
| EV/Sales · EV/ARR (SaaS) | 30% | 피어 멀티플 |

### Growth Option 적용

→ **[advanced-valuation.md §1.6]** 참조

```
1세대 제품 = Static NPV (가시적 캐시플로우)
2세대·3세대·인접시장 = Growth Option

입력값:
- S = 후속 제품군 시장규모 × 점유율 가정 PV
- K = 후속 개발·마케팅 비용
- T = 기술 윈도우 (3~7년)
- σ = 자산 변동성 (피어 환산, 40~70%)
```

### R&D 자본화 옵션

GAAP은 R&D 즉시 비용 인식하나, 가치평가 시 다음 조정 가능:
- 비용처리된 R&D 중 매출과 매칭되는 부분을 자본화 (5~7년 상각)
- 누적 R&D 자본 = 무형자산처럼 처리 → ROIC 정정
- 정정된 ROIC > 보고 ROIC인 경우 가치 재평가

### 핵심 지표

- ARR (연간반복매출), NRR (순매출유지율) > 120% = 매우 우수
- CAC/LTV: LTV/CAC > 3 = 건전한 유닛 이코노미
- Rule of 40: 성장률% + EBITDA마진% ≥ 40
- 플랫폼 잠금 효과: NPS, MAU/DAU, 전환비용

### 핵심 메시지 (사용자 명시)

**정적 NPV가 음수여도 Strategic NPV는 양수일 수 있음** → 음수 NPV 단독으로 투자 기각 금지.
바이오와 마찬가지로 단계적 의사결정 권리·플랫폼 확장 권리 = 콜옵션을 가치에 반영.

## [K] 수주산업 플레이북 (건설/조선/플랜트/방산) — Backlog-DCF 의무

### 핵심 특징

- 수주잔량(Backlog)이 향후 1~4년 매출의 결정변수
- 진행기준 회계 → 매출·이익 인식 시차
- 사이클 변동성 큼 → 정적 매출 CAGR 예측 부적합

### 권장 방법

| 방법 | 가중치 | 비고 |
|---|---|---|
| Backlog-DCF | 50% | 확정수주 + 보수적 신규수주 |
| 수주 Growth Option | 20% | 사이클 상승 시 추가 입찰 능력 |
| 상대가치 (EV/EBITDA, P/B, EV/Backlog) | 20% | 피어 비교 |
| NAVPS (방산·플랜트 일부) | 10% | 자산 백업 |

→ **상세 절차는 [order-backlog-valuation.md] 전체 참조**

### 핵심 입력 데이터

- 기말 Backlog (사업부별)
- Backlog별 GP rate (가이던스 또는 역사적)
- 평균 진행기간 (조선 24~36M / 건설 12~24M / 플랜트 24~48M)
- Book-to-Bill 비율 (역사적 5년)
- 미청구공사 / 매출 비율 (회계 위험 신호)

### WACC 조정

| 사업 | 추가 사이클 프리미엄 |
|---|---|
| 조선 LNG·해양 | +1.5pp |
| 조선 상선 | +1.0pp |
| 해외 플랜트 | +1.0pp |
| 국내 토목·건축 | +0.5pp |
| 방산 | +0.0pp |

### 핵심 리스크

- 손실프로젝트 (미청구공사 급증)
- 환율 (USD/KRW)
- 원자재가 (철강·구리·시멘트)
- 발주처 신용·집중도
- 지연배상금 (LD)

### 회계 분식 신호 점검 (의무)

```
[ ] 미청구공사 / 매출 > 20%
[ ] 미청구공사 YoY 증가율 > 매출 YoY
[ ] 진행률 분기 변동 큼
[ ] 연말 일괄 손실 인식 패턴
[ ] CFO와 영업이익 괴리
```
→ 1개 이상 해당 시 GP rate 시나리오에 하향 케이스 의무 포함.
