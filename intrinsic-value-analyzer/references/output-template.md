## 📦 가치평가 방법론별 한계 명시 (의무 표기)

> **단일 모델 만능 아님**. 본 평가에 사용된 각 방법의 강점과 약점을 명시하여, 결과 해석 시 균형 잡힌 판단을 돕는다.

| 방법 | 강점 | 약점·민감 가정 |
|---|---|---|
| FCFF DCF | 이론적으로 견고, 가치 결정변수 명시 | 가정 다수, TV 비중 70~80%, WACC 0.5pp 변동에 큰 영향 |
| 멀티플 (EV/EBITDA, P/E) | 시장 매기는 가치 즉시 반영, 직관적 | 피어 선정 자의성, 일시적 시장 왜곡 흡수 |
| RIM / DAE | BV 닻으로 변동성 낮음, 회계 우회 | Clean Surplus 위반 시 왜곡, 단기 ROE 외삽 위험 |
| EVA | 자본 재투자 효율 직관 표현 | WACC 민감, 회계 조정 다수 필요 |
| CFROI | 인플레이션·자산노후 보정 | 계산 복잡, 자산 내용연수 추정 어려움 |
| Real Options | 의사결정 유연성을 가치화, 정적 NPV 음수 보정 | σ 추정 자의성, 만기·행사가 정의 어려움, 변동성에 매우 민감 |
| ESO 부채 | 자본구조 정확성 확보 | 미래 부여수량 예측 어려움, forfeiture rate 추정 어려움 |
| DLOM | 유동성 부족 현실 반영 | 모델 간 결과 격차, 실증 데이터 한정 |
| Backlog-DCF (수주산업) | 매출 가시성 직접 반영 | GP rate 가정 자의성, 미청구공사 회계 위험 |
| Growth Option (수주산업) | 미실현 입찰능력 가치화 | Backlog-DCF와 중복 계상 위험 |
| rNPV (바이오) | 단계별 성공확률 명시 | 성공확률·Peak Sales 추정 자의성 |

**종합 판단 원칙**:
- 각 방법의 결과가 ±30% 이내로 수렴하면 신뢰도 높음
- 격차가 큰 경우 가장 보수적 추정치를 안전마진의 닻으로 사용
- Real Options 가치 비중이 30%를 초과하면 변동성 σ에 대한 추가 시나리오 검증 의무
- EVA·CFROI 진단이 부정적(자본 파괴)이면 성장 가정을 하향 조정
