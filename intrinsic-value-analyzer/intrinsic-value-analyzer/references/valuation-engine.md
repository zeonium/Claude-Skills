# 가치평가 계산 공식 참조 (Valuation Engine Reference)

## 1. WACC 계산

### 자기자본비용 (Cost of Equity) — CAPM
```
Ke = Rf + β × ERP + 추가프리미엄(소형주/국가위험)
```

| 파라미터 | 설명 | 한국 기준값 | 미국 기준값 |
|---|---|---|---|
| Rf | 무위험이자율 | KTB 10Y 현재값 | UST 10Y 현재값 |
| β | 체계적 위험 | Bloomberg/FMP 5Y 월별 | 동일 |
| ERP | 주식 위험프리미엄 | ~5.5% (Damodaran 한국) | ~5.0% (Damodaran 미국) |
| 소형주 프리미엄 | 시가총액 < 1조원 | +1.0~2.0% | +1.0~1.5% |

> **주의**: ERP는 Damodaran의 연간 업데이트 값 사용. FRED `mcp__fred__fred_get_series`로 Rf 확인.

### 타인자본비용 (Cost of Debt)
```
Kd(세후) = (장기차입금 이자비용 / 총차입금) × (1 − 실효세율)
```
- 실효세율 = 법인세비용 / 세전이익 (최근 3년 평균)

### WACC
```
WACC = Ke × (E/V) + Kd(세후) × (D/V)
```
- E = 시가총액 (시장가치 기준, 장부가 아님)
- D = 이자부부채 (금융부채: 차입금 + 사채, 매입채무 제외)
- V = E + D

## 2. FCFF 계산

### 방법 1: EBIT 기반 (권장)
```
FCFF = EBIT × (1 − t) + D&A − ΔCapEx − ΔNWC
```

### 방법 2: 영업현금흐름 기반
```
FCFF = CFO + 이자비용 × (1 − t) − CapEx
```

| 항목 | 설명 |
|---|---|
| EBIT | 영업이익 (이자·세금 전) |
| t | 실효 법인세율 |
| D&A | 감가상각비 (비현금) |
| ΔCapEx | 자본적지출 − 감가상각 (순투자) |
| ΔNWC | 운전자본 증감 (매출채권+재고−매입채무) |

### Reinvestment Rate & ROIC
```
재투자율(RR) = (ΔCapEx − D&A + ΔNWC) / NOPAT
성장률(g) = ROIC × RR
ROIC = NOPAT / 투하자본
```
→ g와 ROIC가 일관성을 가져야 함. 성장하는데 RR=0이면 모순.

## 3. Terminal Value (터미널 밸류)

### 안정성장 모형 (권장)
```
TV = FCFn × (1 + g) / (WACC − g)
```

**g 상한 제약 (반드시 준수)**:
- g ≤ Rf (명목 무위험이자율)
- 일반적으로 2~3% (선진국), 3~4% (한국/신흥국)
- g > WACC 시 모형 붕괴 → 절대 금지

### 멀티플 방식 (교차검증용)
```
TV = EBITDAn × EV/EBITDA_exit
```
→ exit multiple은 현재 피어 중앙값 기준

### 터미널 밸류 비중 점검
- TV/전체EV > 80%: 예측기간 너무 짧거나 FCF가 음수 → 주의
- 예측기간 5년 시 TV 비중 70~80% 정상 범위

## 4. DCF 단계별 계산 템플릿

```
연도:          1    2    3    4    5   Terminal
매출 성장률:   g1   g2   g3   g4   g5    gTV
EBIT 마진:    m1   m2   m3   m4   m5    mTV
NOPAT:        N1   N2   N3   N4   N5
ΔCapEx:       C1   C2   C3   C4   C5
ΔNWC:         W1   W2   W3   W4   W5
FCFF:         F1   F2   F3   F4   F5    TV
할인계수:     d1   d2   d3   d4   d5    dTV
PV:           P1   P2   P3   P4   P5    PTV

EV = Σ PV + PTV
Equity Value = EV - 순부채 + 비영업자산
주당 내재가치 = Equity Value / 발행주식수
```

---

## 5. 역DCF (Reverse DCF)

**목적**: 현재 주가가 내포하는 성장 기대 역산

```
현재 시가총액 = Σ FCFt/(1+WACC)^t + TV/(1+WACC)^N
→ 성장률(g*)를 역산하여 수치화
```

**해석 기준**:
- g* > 업종 역사적 성장률 × 1.5 → 시장이 과도한 기대를 반영 → 고평가 신호
- g* < 현재 실적 성장률 → 시장이 과도하게 비관 → 저평가 신호

---

## 6. 잔여이익모형 (RIM — Residual Income Model)

### 기본 공식
```
내재가치(P₀) = BV₀ + Σ [(ROEt − Ke) × BVt−1] / (1+Ke)^t + TV_RI
```

| 항목 | 설명 |
|---|---|
| BV₀ | 현재 장부가치 (자기자본) |
| ROEt | t기 자기자본이익률 |
| Ke | 자기자본비용 |
| (ROE−Ke)×BV | 잔여이익 (경제적 이익) |

### Clean Surplus 조건 점검
```
BVt = BVt-1 + 순이익t − 배당t
```
→ 이 관계가 크게 훼손되면 OCI 등 조정 필요 (은행주 특히 주의)

### 적정 P/B 도출
```
P/B = 1 + Σ (ROE-Ke)/(1+Ke)^t × 조정
```
→ ROE > Ke: P/B > 1 (프리미엄)
→ ROE < Ke: P/B < 1 (디스카운트)

## 7. 상대가치 멀티플

### 피어 선정 원칙
1. 동일 업종/서브업종
2. 유사 비즈니스 모델 (성장 단계, 마진 구조)
3. 유사 지역/규제 환경
4. 최소 3개 피어, 가능하면 5~7개

### 대표값 선택
- 극단치 있을 때: **중앙값** 사용 (산술평균 왜곡 방지)
- 고른 분포: 산술평균 가능

### 주요 멀티플별 적용 기업 유형

| 멀티플 | 적합 업종 | 분자 | 분모 | 주의사항 |
|---|---|---|---|---|
| EV/EBITDA | 성숙 제조/서비스 | 기업가치 | EBITDA | D&A 정책 차이 주의 |
| EV/EBIT | CAPEX 수준 유사 업종 | 기업가치 | EBIT | 감가상각 구조 비슷할 때 |
| P/E | 성숙·안정 이익 기업 | 주가 | EPS | 비경상 항목 조정 필수 |
| P/B | 금융주, 자산집약 | 주가 | BPS | 무형자산 왜곡 주의 |
| EV/Sales | 적자·고성장 | 기업가치 | 매출 | 마진 개선 가정 필요 |
| P/FFO | REIT | 주가 | FFO/주 | GAAP 감가상각 보정 |
| PEG | 성장주 | P/E | 성장률% | 단기 PEG 과신 금지 |

### 멀티플 → 가치 계산
```
기업가치(EV) = 피어 중앙값 EV/EBITDA × 대상기업 EBITDA
주가 = 피어 중앙값 P/E × 대상기업 EPS
```

### 피어 대비 할인/프리미엄 정당화 체크리스트
- [ ] 성장률 차이 (더 높으면 프리미엄 정당)
- [ ] 마진/ROIC 차이 (더 높으면 프리미엄)
- [ ] 위험(β, 부채비율) 차이 (더 낮으면 프리미엄)
- [ ] 경쟁우위/해자 차이
- [ ] 거버넌스/지배구조 디스카운트 (한국 지주사 등)

## 8. DDM (배당할인모형)

### 다단계 DDM
```
P₀ = Σ [Dt / (1+Ke)^t] + Pn / (1+Ke)^n
Pn = Dn+1 / (Ke − g_stable)
```
→ 배당이 명확하고 지속적일 때 (금융주, 배당성장주, 인프라)

### 주요 적용 조건
- 배당성향 30%+ 유지 기업
- 배당 vs 자사주매입 혼합 시: 주주환원총액(배당+자사주) 기반 확장 DDM 사용

---

## 9. SOTP (Sum of the Parts)

```
그룹 EV = Σ (각 사업부 EV) − 공통비 PV + 비영업자산 − 순부채
지주 디스카운트 = 그룹 EV × (0.1 ~ 0.3)
```

**사업부별 평가 방법 선택**:
- 상장 자회사: 시가 × 지분율 (유동성/지배력 디스카운트 5~20%)
- 비상장 자회사: 유사업종 EV/EBITDA 적용
- 금융 계열사: P/B 기반

**주의사항**:
- 공통비(본사비용) PV 반드시 차감
- 내부거래/이중계상 제거
- 순부채는 연결 기준으로 일원화

## 10. 민감도 분석 계산 방법

### WACC × g 매트릭스 자동화 로직

```
기본 WACC = W₀, 기본 g = g₀
for WACC in [W₀-1%, W₀-0.5%, W₀, W₀+0.5%, W₀+1%]:
  for g in [0.5%, 1.0%, 1.5%, 2.0%, 2.5%]:
    TV_ij = FCFn × (1+g) / (WACC−g)
    EV_ij = Σ PV(FCF) + PV(TV_ij)
    P_ij = (EV_ij − 순부채) / 발행주식수
    乖離율_ij = (P_ij − 현재가) / 현재가
```

### 셀 색상 기준
- 🟢 green: 乖離율 > +20% (매수 가능권)
- 🟡 yellow: 乖離율 −20%~+20% (관망)
- 🔴 red: 乖離율 < −20% (고평가)

### Tornado 계산
각 변수를 ±범위로 변동시켜 내재가치 변화폭 계산:
```
민감도(변수 X) = |P(X+δ) − P(X−δ)| / (2 × P₀)
```
→ 값이 클수록 해당 변수에 민감 = Tornado 차트 상단 배치

## 11. EVA (Economic Value Added) — 경제적 부가가치

### 핵심 공식

```
Economic Profit (EVA) = NOPAT − (WACC × Capital)
                     = (ROIC − WACC) × Capital
```

| 항목 | 정의 |
|---|---|
| NOPAT | 세후영업이익 (Net Operating Profit After Tax) |
| WACC | 가중평균자본비용 (§1 참조) |
| Capital | 투하자본 (Invested Capital) |
| ROIC | NOPAT / Capital (투하자본수익률) |

### NOPAT 산출 (조정 필수)

```
NOPAT = EBIT × (1 − 실효세율)
     + LIFO 준비금 증가분        ← 인플레이션 왜곡 보정
     + 영업리스 내재이자          ← 부외부채 조정
     + 영업권 상각비              ← 비현금 비용 가산
     − 비경상 항목 (일회성 손익)
```

> **주의**: 한국 K-IFRS는 LIFO 금지(가중평균/FIFO)이므로 LIFO 조정 불필요. 미국 GAAP만 적용.

### Capital 산출 (조정 필수)

```
Capital = 순영업자산 (Net Operating Assets)
       + LIFO 준비금
       + 누적 영업권 상각액       ← 인수 후 자본 복원
       + 영업리스 PV              ← 부외부채 자본화
       − 비영업자산 (현금성자산 일부, 단기금융자산)
```

### EVA 해석 기준

| EVA 부호 | 해석 | 시사점 |
|---|---|---|
| EVA > 0 | 자본비용 초과 이익 창출 | 자본 재투자 가치 창출, 성장이 가치 증가 |
| EVA ≈ 0 | 자본비용 정확 회수 | 가치 중립 (성장에 따른 가치 변화 미미) |
| EVA < 0 | 자본비용 미달 | **자본 파괴** — 성장이 오히려 가치를 파괴할 수 있음 |

### MVA (Market Value Added)

```
MVA = 시가총액 + 부채시장가치 − 투하자본
    = Σ PV(EVA_t) for t=1 to ∞
```

→ 이론적으로 MVA는 미래 EVA의 현재가치 합과 같다.
→ 현재 MVA를 EVA 영구가치로 역산하면 시장 임플라이드 EVA 도출 가능.

### WACC 민감도 경고

EVA는 WACC에 매우 민감하다:
- WACC 8.0% → 9.0% 변동 시 EVA가 음수 전환할 수 있음
- 따라서 WACC 추정에서 베타·ERP·세율의 작은 오차도 EVA 결론을 뒤집을 수 있음
- **반드시 WACC ±0.5pp / ±1pp 민감도 표 동반 제시**

### 데이터 수집 가이드

```
NOPAT 계산용:
- mcp__25aad980-...__income-statement (EBIT, 세금)
- mcp__open-dart-reader__opendart_finstate_all (한국)
- 주석에서 영업리스 약정 PV 추출 → 내재이자 산출

Capital 계산용:
- balance-sheet-statement (순영업자산, 영업권 누적, 무형자산)
- key-metrics-ttm (참고 ROIC, Invested Capital)
```

## 12. CFROI (Cash Flow Return on Investment) — 현금흐름 투자수익률

### 핵심 개념

전통적인 ROI는 회계적 이익에 의존하므로 감가상각 정책·인플레이션·자산 노후도에 왜곡된다.
CFROI는 **인플레이션 조정된 실질 현금흐름 기반 IRR**로 이 한계를 극복한다.

### 핵심 공식 (IRR 산출)

총현금투자(Gross Cash Investment)의 현재가치를 자산 내용연수 동안 기대되는 총현금흐름의 현재가치와 비상각자산 잔존가치 현재가치의 합과 일치시키는 할인율을 구한다.

```
Gross Cash Investment_0
  = Σ [Gross Cash Flow_t / (1 + CFROI)^t]  for t=1 to N
  + 비상각자산_N / (1 + CFROI)^N
```

| 항목 | 정의 |
|---|---|
| Gross Cash Investment | 감가상각 차감 전 총투자액 (인플레이션 조정) |
| Gross Cash Flow | 감가상각·상각비 가산한 영업현금흐름 (실질) |
| 비상각자산 | 토지·재고·운전자본 등 잔존가치 |
| N | 평균 자산 내용연수 (감가상각비/총감가성자산 역산) |

### Gross Cash Flow 산출

```
Gross Cash Flow = 순이익 + 감가상각비 + 상각비 + 비현금성 비용
                = EBITDA × (1 − t) + 감세효과 + 비경상 조정
```

### 인플레이션 조정 (실질 베이스 변환)

```
실질 Gross Cash Investment = 명목 GCI / (1 + 인플레이션)^t (자산 취득시점 기준)
실질 Gross Cash Flow = 명목 GCF / (1 + 인플레이션)^t
실질 자본비용 = (1 + WACC) / (1 + 인플레이션) − 1
```

→ CPI 또는 GDP deflator 사용 (FRED CPIAUCSL / 한국 ECOS)

### CFROI 해석 기준

| CFROI vs 실질 자본비용 | 해석 |
|---|---|
| CFROI > 실질 자본비용 | 가치 창출 (현금 기준) |
| CFROI ≈ 실질 자본비용 | 가치 중립 |
| CFROI < 실질 자본비용 | 가치 파괴 |

### 자산 내용연수(N) 추정

```
평균 내용연수 N ≈ 총 감가성자산(취득원가) / 연간 감가상각비
```
- 일반 제조업: 10~15년
- 통신·인프라: 15~20년
- IT 장비: 3~7년
- 부동산: 30~50년

### CFROI vs EVA 비교

| 지표 | 측정 단위 | 강점 | 약점 |
|---|---|---|---|
| EVA | 금액 (절대값) | 자본 비용 차감 직관적 | WACC 민감, 회계 왜곡 |
| CFROI | % (IRR) | 인플레이션 조정, 자산 노후도 반영 | 계산 복잡, 가정 다수 |

→ **두 지표를 함께 사용**하여 교차검증 권장.

## 13. DAE (Discounted Abnormal Earnings) — RIM 보강

### 핵심 공식 (RIM 재표현)

```
P₀ = BV₀ + Σ [Abnormal Earnings_t / (1+Ke)^t] + TV_AE
   = BV₀ + Σ [(ROEt − Ke) × BVt−1 / (1+Ke)^t] + TV_AE
```

여기서 비정상이익(Abnormal Earnings) = 순이익 − Ke × BVt−1

### Clean Surplus 회계 조건

```
BVt = BVt-1 + 순이익t − 배당t      ← Clean Surplus 등식
```

이 등식이 성립하지 않으면 DAE 결과가 왜곡된다. 다음 항목이 OCI(기타포괄손익)로 우회되면 위반:
- 매도가능증권 평가손익 (AFS)
- 외환환산손익 (CTA)
- 파생상품 위험회피 평가손익
- 재평가잉여금
- 확정급여제도 재측정요소

### Clean Surplus 점검 절차

```
1. 직전 3년 연결재무제표에서 다음 확인:
   - 기말 자기자본
   - 당기순이익
   - 배당 + 자기주식 거래
   - OCI 누적 변동액
2. Δ자기자본 vs (순이익 − 배당 + OCI) 비교
3. 차이 / 자기자본 < 3%: Clean Surplus 만족 → DAE 그대로 사용
4. 3~10%: 경고 표시 후 OCI 정상화 조정
5. > 10%: DAE 부적합 → FCFF DCF로 대체
```

### OCI 정상화 조정 (3~10% 구간)

```
조정 비정상이익 = 보고 순이익 + 지속가능 OCI − Ke × BVt−1
```
- 지속가능 OCI: 환산손익 중 추세적 부분, 재측정 일부
- 일회성 OCI(위험회피 만료 등) 제외

### 일시적 회계비용 vs 지속가능 이익 분리

DAE의 핵심은 지속가능한 비정상이익만 자본화하는 것이다.

| 항목 | 처리 |
|---|---|
| 구조조정비용 (일회성) | 정상화에서 제외 |
| 영업권 손상차손 | 일회성 → 제외, 단 반복 시 사업 가치 의문 |
| 무형자산 상각 (인수 PPA) | 비현금 → EVA처럼 가산 처리 |
| 비경상 영업외손익 | 평균 4~5년 추세 사용 |
| 환율·원자재 영향 | 정규화 (3~5년 평균) |

### DAE vs FCFF DCF 선택 기준

| 상황 | 권장 모델 |
|---|---|
| 클린 회계, FCF 안정 | FCFF DCF |
| 클린 회계, FCF 변동성 큼 | DAE |
| 금융주 (자본 자체가 영업자산) | DAE / RIM 필수 |
| Clean Surplus 위반 심함 | FCFF DCF (회계 우회) |
| 적자기업 (BV는 양수) | DAE 보조, EV/Sales 주력 |
