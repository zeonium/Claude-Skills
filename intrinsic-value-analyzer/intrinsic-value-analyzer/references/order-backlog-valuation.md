# 수주산업 가치평가 가이드 (Order Backlog Valuation)

건설·조선·플랜트·방산 등 **수주잔량(Backlog)이 미래 매출의 1차 결정변수**인 산업의 전용 가이드.
Backlog-DCF로 확정수주의 진행률 기반 매출·FCF를 산출하고, 신규수주 능력을 별도 Growth Option으로 가치화한다.

---

## §1. 수주산업의 특수성

### 1.1 일반 제조업과의 차이

| 측면 | 일반 제조 | 수주산업 |
|---|---|---|
| 매출 인식 | 출하 시점 | 진행기준 (Percentage-of-Completion) |
| 매출 가시성 | 1~3개월 | 12~48개월 (Backlog 만큼) |
| 사이클 변동성 | 중간 | 매우 큼 (자본재 수요 사이클) |
| FCF 패턴 | 비교적 안정 | 선수금·기성 패턴으로 변동 |
| 회계 위험 | 일반 | 매우 큼 (총계약원가 추정) |

### 1.2 핵심 회계 처리 — 진행기준

```
누적 매출 인식액 = 총 계약금액 × 누적 진행률
누적 진행률 = 누적 발생원가 / 총 추정원가
당기 매출 = 누적 매출 인식액 − 직전 누적 인식액
```

**위험요소**:
- 총 추정원가 변동 (원자재가, 인건비, 환율) → 손실충당금
- 미청구공사 누적 → 회수 위험 (대표적 회계분식 신호)
- 발주처 변경·취소 → 받은 기성 환급

### 1.3 평가 시 우선순위

```
1순위: Backlog-DCF (확정수주 + 진행기준 매출/FCF)
2순위: 수주 Growth Option (미실현 수주능력)
3순위: 상대가치 (EV/EBITDA, P/B, EV/Backlog)
4순위: NAVPS (방산·플랜트 일부)
```

전통적 5년 매출 CAGR 예측은 부적합 — Backlog가 곧 향후 매출이다.

## §2. Backlog-DCF 모델

### 2.1 입력 데이터

| 데이터 | 출처 | 비고 |
|---|---|---|
| 기말 Backlog | 사업보고서·IR자료 "수주잔고" | 분기별 갱신 |
| 신규수주 | IR자료 "신규수주" | YTD 누계 + 분기 |
| 매출 | 손익계산서 | TTM |
| Backlog별 GP rate | 가이던스, 역사적 평균 | 프로젝트별 명시 어려우면 사업부별 평균 |
| 평균 진행기간 | 사업부별 | 조선 24~36M / 건설 12~24M / 플랜트 24~48M |
| 신규수주 CAGR | 역사적 5년 + 시장 가이던스 | Book-to-Bill 기반 |

```
  → 대형 단일계약 공시 (단일판매·공급계약 체결)
```

### 2.2 매출 인식 변환 공식

기말 Backlog가 향후 N년에 걸쳐 어떻게 매출로 전환되는지 모델링.

```
연도 t 매출 = Σ_s [Backlog_s × 진행률_t,s]
```

여기서:
- Backlog_s = 사업부 s의 기말 수주잔량
- 진행률_t,s = 사업부 s에서 t년차에 인식하는 비중 (총합 = 100%)

#### 표준 진행률 패턴 (선형 가정)

| 사업부 | 평균 진행기간 | 진행률 분포 (Y1/Y2/Y3/Y4) |
|---|---|---|
| 건축 | 18M | 50% / 50% / 0% / 0% |
| 토목 | 24M | 35% / 45% / 20% / 0% |
| 플랜트 | 36M | 20% / 40% / 30% / 10% |
| 조선 (상선) | 24M | 30% / 50% / 20% / 0% |
| 조선 (LNG·해양) | 36M | 20% / 35% / 30% / 15% |
| 방산 | 48M | 15% / 25% / 30% / 30% |

> S-curve(앞에서 천천히 시작 후 가속) 적용 시: 0.15/0.40/0.35/0.10 등으로 보정 가능.

### 2.3 GP rate 적용

```
연도 t 매출총이익 = 연도 t 매출 × 가중 GP rate_s

가중 GP rate_s = Σ [Backlog_프로젝트_i × GP_프로젝트_i] / Backlog_s
```

GP rate 출처 우선순위:
1. **회사 가이던스** (분기별 컨퍼런스콜)
2. **프로젝트별 공시** (단일판매 공시의 마진율)
3. **사업부 역사적 평균** (직전 3년)
4. **업종 평균** (피어 중앙값)

### 2.4 신규수주 가정

기존 Backlog 소진 이후 매출은 향후 신규수주에 의존한다.

#### Book-to-Bill 비율 기반 추정

```
Book-to-Bill = 신규수주 / 매출

> 1.0: 성장 모드 (Backlog 증가)
= 1.0: 정상 상태 (Backlog 유지)
< 1.0: 축소 모드 (Backlog 감소)
```

#### 향후 5년 신규수주 추정

```
연도 t 신규수주 = 연도 t-1 매출 × Book-to-Bill 가정 × 사이클 조정

가정 패턴 (사이클 위치별):
- 사이클 상승기: 1.1~1.3
- 사이클 정점: 1.0~1.1
- 사이클 하강기: 0.7~0.9
- 사이클 저점: 0.5~0.7
```

### 2.5 FCF 산출

```
연도 t 매출 (Backlog + 신규수주 진행률)
  − 매출원가 (= 매출 × (1 − GP rate))
  = 매출총이익
  − SG&A
  − R&D
  = 영업이익
  × (1 − 세율)
  = NOPAT
  + 감가상각
  − CAPEX
  − Δ운전자본 (수주산업 특수: 미청구공사·선수금 변동)
  = FCF
```

### 2.6 운전자본 모델링 (수주산업 특이사항)

```
운전자본 = 매출채권 + 미청구공사 + 재고 − 매입채무 − 초과청구공사 − 선수금

핵심 모니터링:
- 미청구공사 / 매출 > 15%: 회수 위험 경고
- 선수금 / Backlog ↑ : 현금흐름 유리 (조선업 특히 중요)
- (매출채권 + 미청구공사) / 매출 추이: DSO 악화 점검
```

### 2.7 WACC 조정 (사이클 리스크 프리미엄)

수주산업은 일반 산업 대비 사이클 변동성이 크므로 ERP에 추가 프리미엄:

```
조정 ERP = 기본 ERP + 사이클 프리미엄
- 조선 (LNG·해양): +1.5pp
- 조선 (상선): +1.0pp
- 해외건설·플랜트: +1.0pp
- 토목·건축 (국내): +0.5pp
- 방산: +0.0pp (안정)
```

## §3. 수주 Growth Option — 신규수주 능력 가치화

### 3.1 개념

Backlog-DCF는 **현재 시점 확정 수주**에 한정한 가치다. 그러나 기업이 보유한 **반복적 입찰·수주 능력**은 미래에 새로운 Backlog를 창출하는 일종의 콜옵션이다.

```
수주 Growth Option = 향후 입찰 능력의 옵션 가치
- 기초자산 S = 향후 5년 신규수주의 PV
- 행사가 K = 신규수주 이행에 필요한 추가 CAPEX·운전자본
- 만기 T = 사이클 길이 (3~5년)
- 변동성 σ = 과거 5년 수주잔량 변동성
```

### 3.2 변동성(σ) 추정

수주산업 변동성 산출:
```
1. 과거 5년 분기말 Backlog 시계열
2. 분기별 변화율 = (Backlog_q − Backlog_{q-1}) / Backlog_{q-1}
3. 변화율의 표준편차 → 분기 σ
4. 연환산 σ = 분기 σ × √4
```

전형적 범위:
- 조선 (LNG): 40~60%
- 조선 (상선): 30~45%
- 플랜트 (해외): 35~50%
- 토목 (국내): 15~25%
- 건축 (국내): 12~20%
- 방산: 8~15%

### 3.3 산출 방식

→ **[advanced-valuation.md §1.4~§1.5]** Black-Scholes + 이항 격자 둘 다 산출

#### 입력값 예시 (조선)

```
S = 향후 5년 신규수주 PV
  = Σ [예상 신규수주_t × 가중 GP × (1−t) ÷ (1+WACC)^t]
K = 향후 5년 추가 CAPEX + 운전자본
  = 신규수주 PV × (1 − GP rate) × 운전자본 회수기간 가정
T = 5년 (1 사이클)
σ = 45% (자산 변동성, 피어 환산)
r = 3.5% (KTB 10Y)
```

#### 산출 결과 형식

```
Black-Scholes:    XX조원
Binomial (5-step): XX조원
교차검증 차이:    X.X% (✓ 5% 이내)
```

### 3.4 종합 합산

```
수주산업 Equity Value =
    Backlog-DCF EV (§2.7)
  − 순부채
  + 수주 Growth Option Value (§3.3)
  − 세후 ESO 부채 (해당 시)

조정 주당가치 = Equity Value / 발행주식수
```

### 3.5 중복 계상 방지 주의

- Backlog-DCF에 이미 신규수주 가정을 포함했다면 → Growth Option은 **추가** 수주 능력만 가치화 (예: 사이클 상승기 베이스 가정 초과분)
- 또는 Backlog-DCF는 확정수주 소진까지만, 그 이후 매출은 0 가정 → Growth Option이 향후 신규수주 전체 가치 흡수

→ **권장 방법**: Backlog-DCF는 확정수주 + 보수적 신규수주(Book-to-Bill=0.9), Growth Option은 상승 시나리오 초과분.

## §4. 핵심 보조 지표

| 지표 | 산식 | 정상 범위 | 해석 |
|---|---|---|---|
| Backlog/매출 배수 | Backlog / TTM 매출 | 1.5~3.0배 | <1.0 위험 / >3.0 가시성 우수 |
| Book-to-Bill | 신규수주 / 매출 | 0.8~1.2 | >1.0 성장 / <0.8 축소 |
| Backlog GP rate 추이 | YoY 변화 | ±1.0pp | 마진 사이클 선행지표 |
| 수주 취소율 | 취소액 / 평균 Backlog | <3% | >5% 경고 |
| 미청구공사 / Backlog | 미청구공사 / Backlog | <10% | >15% 회계 위험 |
| 선수금 / Backlog | 선수금 / Backlog | 10~30% | 조선업 핵심 지표 |
| 대형 발주처 집중도 | 상위 5개 비중 | <50% | >70% 집중 위험 |
| 해외 비중 | 해외 수주 / 총 수주 | 산업별 | 환율·국가위험 노출 |

### 4.1 사이클 위치 판단 체크리스트

```
[ ] 글로벌 신조선가 (Clarkson) 추이 — 조선업
[ ] 정부 SOC 예산 추이 — 토목
[ ] 주택 분양 실적 — 건축
[ ] 국제유가·LNG 가격 — 해양플랜트
[ ] 화공·정유 가동률 — 화학플랜트

```

## §5. 리스크 항목

### 5.1 거시·산업 리스크

| 리스크 | 영향 경로 | 모니터링 지표 |
|---|---|---|
| 환율 | 해외 수주 매출 환산, 원자재 수입 | USD/KRW |
| 원자재가 | 매출원가 (철강·시멘트·구리) | LME, POSCO 후판가 |
| 금리 | 발주처 자금조달 비용, 자사 WACC | 정책금리 |
| 발주처 신용 | 대금 회수 위험 | CDS 스프레드, 신용등급 |

### 5.2 회사 고유 리스크

| 리스크 | 신호 | 대응 |
|---|---|---|
| 손실프로젝트 | 미청구공사 급증, 충당금 인식 | DCF GP rate 하향 조정 |
| 발주처 집중 | 상위 5개 발주처 비중 > 70% | 발주처 1개 이탈 시나리오 |
| 지연배상금 (LD) | 인도지연 공시 | 영업외손익 충당 |
| 환헷지 실패 | 환율 급변 분기 | OCI 변동 점검 |

### 5.3 회계 분식 신호 (Red Flags)

```
[ ] 미청구공사 / 매출 > 20%: 회수 위험 가속
[ ] 미청구공사 YoY 증가 > 매출 증가: 인식 과대
[ ] 동일 프로젝트 진행률이 분기마다 크게 변동: 추정원가 조작 가능성
[ ] 연말 일괄 손실 인식: 평소 진행률 과소 신호
[ ] CFO 패턴 vs 영업이익 괴리: 현금흐름 미동반 이익
```
