# 고급 가치평가 가이드 (Advanced Valuation Reference)

Real Options · ESO · DLOM 통합 가이드. 전통적 DCF로 포착되지 않는 옵션성·자본구조 부채·유동성 할인을 정량화한다.

---

## §1. Real Options Valuation — 실물옵션 평가

### 1.1 왜 Real Options가 필요한가

전통적 NPV/DCF는 다음 한계를 가진다:
- **정적(static)** 의사결정 가정: 미래에 추가 정보를 얻어도 계획을 변경하지 않는다고 가정
- 단계적 의사결정·연기·확장·폐기 권리의 가치를 0으로 가정
- 변동성이 클수록 가치를 과소평가 (변동성이 옵션의 친구라는 사실 무시)

특히 다음 산업에서 Real Options 적용이 필수:
- **바이오·제약**: 임상 단계 진입권 = compound option
- **자원·광업**: 미개발 매장량 = 가격 옵션
- **하이테크·플랫폼**: 후속 제품 확장권 = Growth Option
- **건설·조선·수주산업**: 신규수주 입찰능력 = 반복 Growth Option
- **인프라·에너지**: 전력원료 전환 옵션 = Switch Option

### 1.2 핵심 등식

```
Strategic NPV = Static NPV + Σ Real Option Value
```

**중요**: Static NPV가 음수여도 Strategic NPV는 양수일 수 있다 → 정적 NPV 단독으로 투자 기각 금지.

### 1.3 옵션 식별 가이드

| 옵션 유형 | 영문 | 정의 | 산업 예시 |
|---|---|---|---|
| 확장 옵션 | Growth Option | 성공 시 후속 투자권 | 플랫폼·SaaS, 광물 추가개발 |
| 연기 옵션 | Deferral Option | 가격·기술 확정 후 투자 결정 | 광업, 부동산 개발 |
| 폐기 옵션 | Abandonment Option | 손실 한정 후 청산 | R&D, 한계광산 |
| 전환 옵션 | Switch Option | 산출물/투입물 전환 | 발전소(가스↔석탄), 정유 |
| 단계적 투자 | Staged Investment | 단계별 진행/중단 | 임상 1·2·3상, 메가프로젝트 |
| 학습 옵션 | Learning Option | 정보 획득 후 결정 | 시범 사업, 베타 출시 |

옵션 식별 체크리스트:
```
[ ] 향후 의사결정 분기점이 명시적으로 존재하는가?
[ ] 그 분기점에서 새 정보 (가격·성공률·기술)가 갱신되는가?
[ ] 분기점에서 진행·중단·확장 중 선택권을 보유하는가?
[ ] 변동성(σ)이 의미있게 0보다 큰가? (σ < 10% 이면 옵션가치 미미)
```

### 1.4 Black-Scholes 적용

#### 핵심 공식

```
C = S·N(d1) − K·e^(−rT)·N(d2)

d1 = [ln(S/K) + (r + σ²/2)·T] / (σ·√T)
d2 = d1 − σ·√T
```

#### 입력값 매핑 (실물옵션 → BS 파라미터)

| BS 파라미터 | 실물옵션 의미 | 추정 방법 |
|---|---|---|
| S | 기초자산 현재가치 = 프로젝트 PV (FCF의 PV) | DCF로 베이스 PV 산출 |
| K | 행사가격 = 후속 투자비용 | CAPEX 추정치 |
| T | 만기 = 의사결정 시한 | 인허가·특허만료·시장 진입 윈도우 |
| σ | 변동성 = 프로젝트 가치 변동성 | 피어 주가 변동성 → 자산 변동성 환산 |
| r | 무위험율 | FRED 10Y 또는 ECOS 국고채 10Y |

#### 변동성(σ) 추정

```
1. 피어그룹 5사 선정 (동일 산업·규모)
2. 각사 일별 주가수익률 5년치 → 연환산 σ_equity 계산
3. 자산 변동성 환산:
   σ_asset = σ_equity × E/(E+D) × (Bloomberg 또는 직접 계산)
4. 피어 σ_asset 중앙값 사용
```

전형적인 σ 범위:
- 안정산업 (유틸·인프라): 15~25%
- 일반제조: 25~35%
- 바이오·하이테크: 40~70%
- 자원·원자재: 30~50%

### 1.5 이항 격자(Binomial Lattice) — 5-step 표준

#### 노드 매개변수

```
Δt = T / N             (N=5)
u = e^(σ·√Δt)         (상승률)
d = 1 / u             (하락률)
p = (e^(r·Δt) − d) / (u − d)   (위험중립 확률)
```

#### 5-step 가치 트리 (S₀ = 프로젝트 PV)

```
              t=0       t=1       t=2       t=3       t=4       t=5
S₀·u⁵
S₀·u⁴
S₀·u³                        ...
S₀·u²
S₀·u
S₀                                              ← 트리 노드별 자산가치
S₀·d
S₀·d²
S₀·d³                        ...
S₀·d⁴
S₀·d⁵
```

#### 백워드 인덕션 (옵션가치 산출)

```
[t=5 (만기)]
  Option Value_5,i = max(S_5,i − K, 0)         ← 콜옵션 페이오프

[t=4, 3, 2, 1]
  Continuation Value_t,i = e^(−r·Δt) · [p · OV_(t+1, up) + (1−p) · OV_(t+1, down)]

  미국형 (중도 행사 허용 시):
  Option Value_t,i = max(S_t,i − K, Continuation Value)

  유럽형 (만기만 행사):
  Option Value_t,i = Continuation Value

[t=0]
  Real Option Value = OV_0
```

#### BS vs 이항 격자 비교

| 측면 | Black-Scholes | 이항 격자 |
|---|---|---|
| 행사 시점 | 유럽형 (만기만) | 미국형·중도 행사 가능 |
| 단계적 의사결정 | 불가 | 가능 (compound option) |
| 계산 속도 | 매우 빠름 | 5-step도 1초 미만 |
| 직관성 | 공식 한 줄 | 시각화 가능 |
| 정확도 (단순옵션) | 매우 정확 | N↑일수록 BS 수렴 |

→ **반드시 둘 다 산출**하고 차이 < 5% 이면 BS 사용, > 5% 이면 격자가 더 정확(조기행사·단계 결정 반영).

### 1.6 산업별 적용 가이드

#### 바이오 — Compound Option (다단계 임상)

```
Phase I → Phase II → Phase III → 승인 → 상용화
각 단계 = 다음 단계 진입권 (compound call)
```

- 단계별 성공확률:
  - Pre-clinical: ~10%
  - Phase I: ~63%
  - Phase II: ~31%
  - Phase III: ~58%
  - NDA/BLA: ~85%
  - 누적 (Phase I → 승인): ~10%
- rNPV (Risk-Adjusted NPV):
  ```
  rNPV = Σ [성공확률_단계 × 단계별 현금흐름 PV]
       − Σ [단계별 R&D 비용 PV]
  ```
- 추가 옵션가치: 적응형 임상 디자인·동시 적응증 확장 = Growth Option

#### 자원·광업 — Price Option (가격 옵션)

```
미개발 매장량 = 가격이 손익분기 이상일 때만 행사하는 콜옵션
- S = 매장량 × 현재 원자재가
- K = 개발 CAPEX
- T = 매장권 잔여기간
- σ = 원자재가 변동성 (역사적 5년)
```

#### 하이테크 — Growth Option (플랫폼 확장)

```
1세대 제품 = Static NPV (가시적 캐시플로우)
2세대·3세대 제품 = Growth Option (성공 시 진입권)
- S = 후속 제품군 시장규모 × 점유율 가정 PV
- K = 후속 개발·마케팅 비용
- T = 기술 윈도우 (보통 3~7년)
- σ = 기술 변동성 (50~70%)
```

#### 수주산업 — Repeated Growth Option

```
미실현 수주능력 = 반복 입찰 옵션
→ §order-backlog-valuation.md §3 참조
```

### 1.7 주의점과 함정

- **σ 과대추정**: 피어 σ를 그대로 쓰면 변동성 과대 → 옵션가치 부풀림. 자산 변동성 환산 필수.
- **만기 T 자의성**: 의사결정 시한을 명확히. "영원히 보유" 가정은 무한대 옵션가치 함정.
- **K 정합성**: 행사가는 명목값이 아니라 의사결정 시점 PV로 정규화.
- **중복 계상 방지**: Static NPV에 이미 반영된 시나리오를 옵션으로 재계상 금지.
- **세금**: 옵션 행사 시 세금공제 효과 별도 처리 (보통 옵션 가치의 5~15%).

## §2. ESO (Employee Stock Options) — 직원 스톡옵션 부채화

### 2.1 왜 ESO를 부채로 처리하는가

직원 스톡옵션은 기존 주주의 청구권을 희석하므로 **자본가치에서 차감해야** 한다.
미국 SEC는 10-K 주석에서 옵션 부여내역 공시 의무 부과, 한국도 사업보고서에 공시.

기존 회계처리(FAS 123R / K-IFRS 1102)는 부여시점 BS 추정으로 비용 인식하나, 실제 부채 가치는 다음 이유로 다를 수 있다:
- 조기 행사로 인한 시간가치 손실
- forfeiture로 인한 부채 감소
- 시장가 상승 시 부채 급증 (비선형)

### 2.2 단순 BS의 한계

단순 Black-Scholes는 다음 ESO 특성을 반영하지 못한다:

1. **조기 행사 (Early Exercise)**: 직원은 공매도 헷지가 불가능하므로 위험회피 동기로 만기 전 행사 빈번
2. **퇴사로 인한 상실 (Forfeiture)**: vest 전 퇴사 시 무효
3. **비유동성**: 직원은 옵션 자체를 매도 불가 → 자체 할인 필요
4. **귀속(Vesting) 일정**: 통상 4년 cliff 1년 / 25% 매년

### 2.3 효용기반 Lattice 모형 (Hull-White / FAS 123R 권고)

#### 격자 구성

```
- 격자 단계: 100~250 step (월간/주간)
- 자산: 주가 (시장가)
- 매 노드에서 직원의 행사 결정:
   행사 조건: M/K ≥ Trigger 비율 (보통 2.0~3.0)
   행사 가치: max(S − K, 0)
- 매 단계 forfeiture rate λ 차감
- 비귀속 기간: 행사 불가
```

#### 조기 행사 경계 (Exercise Boundary)

```
Trigger_t = K × (다단계 함수)
- M/K = S/K (Moneyness)
- M/K ≥ 1.5: 일부 행사 시작
- M/K ≥ 2.5: 대다수 행사
- 시간 경과: 만기 임박 시 Trigger 낮아짐
```

#### Forfeiture rate

| 산업 | 연간 forfeiture rate |
|---|---|
| 빅테크 (저이직) | 3~5% |
| 일반 IT | 5~8% |
| 스타트업·고이직 | 8~15% |
| 한국 대기업 | 2~5% |

> 10-K Note의 "Pre-vest forfeiture rate" 또는 "Expected forfeiture rate" 표 참조.

### 2.4 세후 ESO 부채 산출

```
총 ESO 부채 = Σ [부여내역별 Lattice 가치]
             × (1 − 누적 forfeiture)

세금공제 효과:
  옵션 행사 시 회사는 (시장가 − 행사가) × 발행주식 × 법인세율 만큼 세금공제 가능
  PV(세금공제) = Σ E[행사이익_t × 세율 × (1+r)^(−t)]

세후 ESO 부채 = 총 ESO 부채 − PV(세금공제)
```

### 2.5 자본가치 차감

```
조정 Equity Value = Raw Equity Value (DCF 산출치) − 세후 ESO 부채
조정 주당가치 = 조정 Equity Value / 발행주식수
```

**중요**: 발행주식수는 옵션 행사 가정 희석주식수가 아닌 **현재 보통주 발행주식수** 사용.
ESO 가치 차감 후 별도 희석 처리 금지 (이중 차감 방지).

### 2.6 향후 부여 예정 옵션 처리

기업이 연간 정기 옵션 부여 정책을 가지면, 향후 5년치 예상 부여를 추가 부채로 산입한다:

```
미래 부여 부채 = Σ [t년 부여 예상수량 × 부여시점 BS 가치] × 할인
- 예상수량: 최근 3년 평균 부여수량
- 자기주식 매입으로 희석 상쇄 정책 있으면 차감
```

## §3. Illiquid Asset Valuation / DLOM — 비유동성 자산 평가

### 3.1 적용 대상

- 비상장 주식 (사모펀드, 스타트업)
- 락업(lock-up) 주식 (IPO 후 6개월 미만, 재무적 투자자 보유)
- 소수지분 (10% 미만, 지배력 없음)
- 거래량 극소 종목 (일평균 거래대금 < 시총의 0.05%)
- 거래정지·관리종목

### 3.2 Guideline Multiples / Transactions 적용 한계

비공개 기업 데이터의 문제:
- 수익성 데이터 누락 (감독 보고 의무 없음)
- 회계 표준 차이 (K-GAAP·세무회계)
- 정산 시점 차이

**보정 가이드**:
- 매출 기반 멀티플(EV/Sales) 우선 — 가장 신뢰 가능
- EBITDA 멀티플 사용 시 비반복 항목 조정 의무
- 거래 멀티플(M&A 가격): 지배지분 프리미엄(20~30%) 차감 후 적용

### 3.3 DLOM (Discount for Lack of Marketability)

#### 옵션 기반 DLOM (Longstaff / Finnerty 모델)

자산을 즉시 매도할 수 없는 손실 = 매도 옵션을 보유한 효과의 부재.

**Longstaff 모델 (1995)** — 룩백 옵션 기반:
```
DLOM = (2/σ√T) · [σ²T/2 · N(σ√T/2) − 1 + N(σ√T/2) − 2σ√T · n(σ√T/2)/√T]
```
간단 추정: `DLOM ≈ σ · √T × 보정계수`

**Finnerty 모델 (2012)** — 평균행사 옵션 기반:
```
DLOM = N(v/2) − N(−v/2)
v² = σ²·T + ln[(2 · (e^(σ²T) − σ²T − 1)) / (σ²T)²]
```

> 두 모델 결과를 비교하고 평균값 사용 권장.

#### 실증 데이터 기반 DLOM 범위

| 상황 | DLOM 범위 | 비고 |
|---|---|---|
| 완전 비상장 (사모펀드) | 30~45% | Pratt's Stats, Mergerstat |
| 락업 보유 (6개월~1년) | 15~25% | Silber 1991, Hertzel-Smith |
| Restricted Stock (SEC 144) | 13~21% | 평균 ~17% |
| 거래량 극소 상장주 | 5~15% | 일별 거래 / 시총 비율 함수 |
| 소수지분 (의결권 부재) | 10~25% | 통제권 디스카운트 |
| 의약품 임상중 자산 | 25~40% | 변동성·시간 함수 |

#### DLOM 결정 시 고려 인자

```
σ (자산 변동성) ↑ → DLOM ↑
T (예상 보유기간) ↑ → DLOM ↑
회사 규모 ↓ → DLOM ↑ (5%p)
배당수익률 ↑ → DLOM ↓ (현금흐름 보상)
시장 활성도 ↓ → DLOM ↑
```

### 3.4 적용 절차

```
1. 1차 가치 산출 (DCF/멀티플/RIM)
2. 유동성 점검:
   - 상장 여부
   - 일평균 거래대금 / 시총
   - 락업 잔여기간
   - 보유 지분 규모
3. DLOM 결정:
   - 옵션모델 1차 산정
   - 실증범위 교차검증
4. 자산가치 × (1 − DLOM) = 조정 가치
```

## §4. 종합 가치 합성 공식

### 4.1 최종 합성

```
조정 Equity Value =
    (기본 가중평균 내재가치 × 발행주식수)        ← STEP 3 A~D
  + Σ Real Option Value                          ← STEP 3 F
  − 세후 ESO 부채                                ← STEP 3 G
  − (비유동성 자산 비중 × DLOM%)                 ← STEP 3 H

조정 주당 내재가치 = 조정 Equity Value / 발행주식수
```

### 4.2 의사결정 흐름

```
Static NPV / DCF 산출
        │
        ▼
+ Real Options 보유 산업? ───YES──→ Strategic NPV = Static + Option
        │ NO
        ▼
+ ESO 미결제 존재? ───────────YES──→ 자본 차감
        │ NO
        ▼
+ 비유동성 자산? ─────────────YES──→ DLOM 차감
        │ NO
        ▼
EVA / CFROI 진단 점검 (모든 케이스)
        │
        ▼
조정 주당 내재가치 → 안전마진 → 투자등급
```

### 4.3 각 모듈의 강점·약점 (리포트 명시 의무)

| 방법 | 강점 | 약점 |
|---|---|---|
| FCFF DCF | 이론적으로 견고, 가치 결정변수 명시 | 가정 다수, TV 비중 큼, 회계 왜곡 |
| 멀티플 | 시장이 매기는 가치 즉시 반영 | 피어 선정 자의성, 일시적 시장 왜곡 |
| RIM/DAE | BV 닻으로 변동성 낮음 | Clean Surplus 위반 시 왜곡 |
| EVA | 자본 재투자 효율 직관 | WACC 민감, 회계 조정 다수 |
| CFROI | 인플레이션·자산노후 보정 | 계산 복잡, 자산 내용연수 추정 어려움 |
| Real Options | 의사결정 유연성 가치화 | σ 추정 자의성, 만기·행사가 정의 어려움 |
| ESO 부채 | 자본구조 정확성 | 부여수량 예측 어려움, forfeiture 추정 |
| DLOM | 유동성 현실 반영 | 모델 간 결과 격차, 데이터 부족 |

→ 리포트 결론 직전 위 표를 "방법론 한계 명시 박스"로 표기 의무.
