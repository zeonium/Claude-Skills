# TRM — Technical Requirement Map (특허의 기본 형태)

특허 청구항의 유형을 분류하고 이중청구 구조를 탐지한다.

## 기본 4분류

| TRM 유형 | 설명 | 예시 도메인 |
|---------|------|-----------|
| `Composition` | 물질·조성물·균주·화합물 | 배터리 전해질, 제과 조성물, 재조합균주 |
| `Apparatus` | 장치·기구·시스템·소자 | VCR 엔진, OLED 소자, 반도체 회로, 분리막 |
| `Method` | 공정·제조방법·분석방법·치료방법 | HLA 분석 워크플로우, 식품 제조공정 |
| `Use` | 용도·사용방법·적용 | GLP-1 경구투여 용도, 단백질 생산 용도 |

판정 기준:
- 독립항 1항의 **카테고리 표현**을 확인한다 ("A composition comprising...", "A method of...", "An apparatus for...", "Use of...")
- 복수 독립항이 있을 때 각각 판정한다

---

## 이중청구 TRM (확인된 5유형)

하나의 특허가 두 개의 TRM을 동시에 청구하는 전략적 구조.

| 유형 | 포섭 전략 | 귀납 레퍼런스 |
|------|---------|------------|
| `Apparatus + Method` | 장치제조사 + 공정사용자 동시 포섭 | US9653142 DRAM |
| `Composition + Use` | 물질제조사 + 사용자 동시 포섭 | US12594326 GLP-1, US8293516 재조합미생물 |
| `Method + Use` | 진단자 + 치료자 동시 포섭 | US12589142 HLA |
| `Composition + Method` | 물질특허 + 제조공정 동시 보호 | US10135093 배터리음극재, US12295383 마카다미아넛 |
| `Composition + Apparatus` | 화합물 + 소자 동시 포섭 | US11916193 배터리분리막, US11716898 OLED |

### 이중청구 탐지 방법

1. 독립항이 2개 이상인 경우, 각 독립항의 TRM 유형을 판정한다
2. 서로 다른 TRM 유형이 공존하면 이중청구다
3. 기존 5유형 중 해당 조합이 없는 경우 → **신규 이중청구 가설** 등록

---

## TRM 분석 출력 형식
> **TRM = 특허의 기본 형태** — 이 특허가 "물질/장치/방법/용도" 중 어떤 유형을 청구하는지 판정한다.

```
TRM: [유형1] + [유형2] (이중청구)   또는   [유형] (단일)
포섭 전략: [누구를 동시에 포섭하는가 — 제조사/사용자/연구자/의료인 등]
귀납 레퍼런스: [동일 유형의 기존 분석 특허번호]
```

예시:
```
TRM: Composition + Use (이중청구)
포섭 전략: 약물 제조사 + 의약 사용자(의사/환자) 동시 포섭
귀납 레퍼런스: US12594326 GLP-1, US8293516 재조합미생물
```
