# QET — Quantitative Effect Table (수치 근거)

> **QET = 수치 근거** — 청구항에 포함된 숫자·비율·비교 수치를 추출해 "왜 이 발명이 기존보다 우수한가"를 정량적으로 보여준다.

## QET 3종

### 기본 QET (수치 근거 — 성분·측정값·비교기준)
화학·소재·바이오 청구항에서 성분/수치/비교가 있는 경우

형식:
```
(성분/구성 | 측정특성 | 값 | 단위 | 비교기준)
```

예시:
```
(Li₆PS₅Cl | 이온전도도 | 1.2×10⁻³ | S/cm | 종래 황화물 전해질 대비 10배)
(마카다미아넛 분말 ≤1mm | 체 통과율 | 95 | % | 일반 분쇄 대비)
```

### R-QET (수치 근거 — 두 성분 간 시간적·비율 관계)
복합제형·시계열·면역활성화 순서에서 두 성분 간 상대적 관계를 수치화

형식:
```
(CompA | vs | CompB | RelProperty | Direction | Condition)
```

예시:
```
(SNAC용출속도 | vs | GLP-1용출속도 | 시간적선행 | SNAC≥GLP-1 | pH 2.5, 30분 이내)
(ClassI HLA펩타이드 활성화 | vs | ClassII 활성화 | 순서의존성 | ClassI 先 | 복강주사 환경)
```

### R-QET-D (수치 근거 — 복잡도 감소를 정량화)
기계기구·공정에서 부품수·공정수·합성단계 감소를 수치로 표현

형식:
```
(기구/시스템 | 복잡도지표 | 감소량 | 단위 | 종래대비)
```

예시:
```
(정현파홈직접전달 | 부품수 | 3→1 | 개 | 크랭크+연결봉+피스톤핀 대비)
(청색OLED발굴프로세스 | 합성단계수 | N건→M건(M<<N) | 건 | in silico DFT 도입 전 대비)
(HLA allele 타이핑 | 실험단계수 | 3단계→1단계 | 단계 | 기존 PCR 기반 대비)
```

---

## QET 도출 방법

1. 청구항과 발명의 설명에서 **수치(숫자, 배율, %, 범위)**를 모두 추출한다
2. 수치가 **성분·구성**과 연결되면 기본 QET 사용
3. 수치가 **두 성분 간의 시간적 또는 비율 관계**를 표현하면 R-QET 사용
4. 수치가 **부품수·공정수·합성단계 감소**를 나타내면 R-QET-D 사용
5. 수치가 없더라도 "prior to", "before", "선행" 등 순서 표현이 있으면 R-QET 탐색

---

## QET 출력 형식

```
[QET 유형] 도출:
(성분/구성 | 특성 | 값 | 단위 | 기준)
해석: [이 수치가 왜 기술적으로 중요한지 1문장]
```
