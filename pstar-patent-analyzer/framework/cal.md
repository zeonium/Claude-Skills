# CAL — Claim Abstraction Level (구체성 수준)

청구범위의 추상도를 6단계로 분류하고, IP 전략과 회피 난이도를 해석한다.

## CAL 6종 분류
> **CAL = 구체성 수준** — 청구항이 얼마나 구체적(좁음)인지 추상적(광범위)인지를 6단계로 나타낸다. 낮을수록 좁고 명확, 높을수록 넓고 강력하다.

| CAL 유형 | 설명 | 보호범위 | 주요 도메인 |
|---------|------|---------|-----------|
| **CAL-1** 특정구체형 | 원소·수치·서열 명시 | 좁음 | 전 도메인 종속항 |
| **CAL-2** 치환변수형 | 수치범위·군으로 정의 | 중간 | 화학·소재 독립항 |
| **CAL-3** 구조패밀리형 | 기능·형태 원리 청구 | 광범위 | 표준특허 전략 |
| **CAL-2N** 음성정의형 | `does not comprise X` 배제로 정의 | CAL-3급 | 약학·바이오·Method |
| **FunctionalCAL** | 구조 미명시, 기능만 청구 | 광범위 | 소프트웨어·공정·워크플로우 |
| **CAL-3E** 열거기반선점 | Table로 모든 조합 열거 | 극광범위 | 기계·화학·유전체 |

### 판정 가이드

- **CAL-1**: 청구항에 구체적 수치, 화학식, 서열번호가 명시됨
- **CAL-2**: "X 내지 Y wt%", "A, B, C로 구성된 군에서 선택"처럼 범위/군으로 정의
- **CAL-3**: "기능적 특성을 갖는 구조"처럼 구조 원리를 추상화
- **CAL-2N**: "X를 포함하지 않는" 배제 표현으로 범위를 역방향 정의
- **FunctionalCAL**: "~하는 단계를 포함하는 방법"처럼 기능만 청구, 구체 구조 없음
- **CAL-3E**: 종속항에 Table 형식으로 가능한 조합을 모두 열거

## 복합 CAL 패턴 (귀납으로 발견된 3종)

### 패턴 1 — CAL 3중 레이어 (Method 특허 특유)
```
독립항 = FunctionalCAL (워크플로우 골격)
         + CAL-2N (배제 행위 정의)
         + CAL-3E (서열/조합 열거)
귀납: US12589142 HLA 종양항원펩타이드
```

### 패턴 2 — CAL-3+CAL-3E 계층화 (대형 화학·소재)
```
독립항 = CAL-3 (구조원리 추상화 — 광범위 방어)
종속항 = CAL-3E (포뮬라 내 모든 조합 Table 열거 — 설계공간 전체 선점)
귀납: US9388695 VCR 엔진, US11716898 OLED 청색인광소재
```

### 패턴 3 — FunctionalCAL + CAL-2N 이중 레이어 (바이오·미생물)
```
독립항 = FunctionalCAL (기능 청구)
         + CAL-2N (유전자 결실/불활성화 음성정의)
귀납: US8293516 재조합미생물
```

## CAL-IP 인터프리터

각 CAL 유형별 IP 전략과 회피 전략을 해석한다.

| CAL | IP 전략 | 회피 전략 | 회피 난이도 |
|-----|--------|---------|----------|
| CAL-1 | 인접 조성 포위 전략 | 수치 범위 외 조성 사용 | 낮음 |
| CAL-2 | 3중 청구 구조 (독립+종속 계층) | 범위 외 수치·군 사용 | 중간 |
| CAL-3 | 표준특허화, 구조원리 선점 | 다른 구조 원리 필요 | 높음 |
| CAL-2N | 배제 대상 외 물질 청구 | 배제된 물질 사용 | 중간 |
| FunctionalCAL | 동일 기능 구현 전체 포섭 | 다른 메커니즘으로 동일 기능 구현 | 높음 |
| CAL-3E | Table 외 완전 새 구성 필요 | 사실상 회피 불가 | 극높음 |

```
복합 패턴: [패턴명 또는 없음]
CAL-IP: [IP 전략] / 회피 난이도: [낮음/중간/높음/극높음]
회피 설계 방향: [구체적 회피 포인트]
```
