# 관계 분석 + NP — Negative Pathway (기존 방식의 한계)

특허 기술 요소들 간의 인과·의존·경쟁 관계를 매핑하고, 종래 기술의 실패 경로를 명시한다.

## 관계 타입 8종

### 공통 4종 (단건·다건 모두 적용)

| 관계 | 표기 | 의미 |
|------|------|------|
| `indirectly_enables` | A → B | A의 변화가 B 기능을 간접적으로 가능하게 함 |
| `fails_to` | A → B | 종래 구성 A가 기능 B를 달성하지 못함 (NP의 핵심) |
| `quantifies_at` | A → B | 메커니즘 A의 효과를 수치 B로 표현 |
| `claims_space_of` | A → B | 청구항 A가 기술공간 B 전체를 선점 |

### 다건 전용 3종

| 관계 | 표기 | 의미 |
|------|------|------|
| `competes_with` | A ↔ B | 동일 기능·시장에서 경쟁하는 특허 |
| `subsumes` | A → B | A 청구범위가 B의 기술공간을 포함 (A가 상위) |
| `fails_unless` | A → B | 선행 구성 A 없이는 후행 기능 B 달성 불가 |

### v2.1+ 신규 관계 (귀납 발견)

| 관계 | 표기 | 의미 |
|------|------|------|
| `requires_prior_to` | A →先→ B | A가 완료된 후에만 B 달성 가능 — 시간적 선행 의존성 |

---

## requires_prior_to 귀납 현황 (6건 — 도메인 무관 보편 관계)

| # | 도메인 | 선행 조건 A | 후행 달성 B |
|---|--------|-----------|-----------|
| 1 | 의약/GLP-1 | SNAC 위투과→혈중농도 확보 | GLP-1 흡수 |
| 2 | 기계/VCR | 조정부재 축방향위치 설정 | 정확한 압축비 달성 |
| 3 | 의약/HLA | HLA allele 하플로타입 확정 | 펩타이드 합성/투여 |
| 4 | 의약/HLA | Cyclophosphamide 전처치 | HLA 펩타이드 투여 |
| 5 | 식품/제과 | 체질(≤1mm) 완료 | 가루+감미료+물 혼합 |
| 6 | 미생물 | prsA 전사조절영역 삽입 완료 | 목적단백질 고분비 달성 |

귀납 결론: `requires_prior_to`는 "하위 인프라 구조를 선행 확립해야 상위 기능이 발현된다"는 도메인 무관 보편 법칙이다.

## NP — Negative Pathway (기존 방식의 한계) — 필수 도출

모든 분석에서 NP를 최소 1개 도출해야 한다.
> **NP = 기존 방식의 한계** — 이 발명이 등장하기 전, 종래 기술이 왜 실패했는지 인과 경로로 명시한다.

### NP 형식
```
[종래구성X] -fails_to-> [기능Y]
  :: 이유: [실패 메커니즘 — 왜 X가 Y를 달성하지 못하는가]
```

### NP 예시
```
[원래 prsA 프로모터 유지] -fails_to-> [고수준 단백질 분비]
  :: 이유: 기본 prsA 발현 약함 → 샤페론 부족 → 폴딩 불량·응집

[SNAC 없는 GLP-1 단독 경구투여] -fails_to-> [위장 흡수]
  :: 이유: 위산 환경에서 GLP-1 단백질 분해 → 흡수 전 소실

[크랭크-연결봉-피스톤핀 구조] -fails_to-> [가변압축비 정밀 제어]
  :: 이유: 부품 수 과다 → 마찰 손실 + 응답 지연
```

## 관계 맵 출력 형식

```
관계 맵:
  [구성A] indirectly_enables [기능B]
  [종래구성X] fails_to [기능Y]  → NP 참조
  [메커니즘C] quantifies_at [수치D mg/dL]
  [청구범위E] claims_space_of [기술공간F]
  [선행조건G] requires_prior_to [후행기능H]  (해당 시)

NP:
  [종래구성X] -fails_to-> [기능Y]
    :: 이유: [메커니즘]
```
