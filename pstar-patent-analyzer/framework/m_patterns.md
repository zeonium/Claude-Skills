# M-패턴 — TRIZ 모순 분석 패턴 10종 (핵심 기술 충돌)

> **M-패턴 = 핵심 기술 충돌** — 발명이 해결하는 핵심 기술적 트레이드오프(A를 개선하면 B가 나빠지는 구조)를 TRIZ 관점에서 유형화한 패턴이다.

10종의 M-패턴을 Level A → B → C 순으로 탐색한다. 복수 레벨 공존 가능.

## M-패턴 탐색 절차

1. Level A (M-1, M-2, M-3)를 먼저 탐색 — 어떤 도메인이든 적용 가능
2. Level B (M-4, M-5, M-8) 순서로 탐색
3. Level C (M-6, M-7, M-9, M-10) 탐색
4. 해당 M-패턴의 TRIZ 원리 번호가 특정되면 triz_matrix_solver.py로 검증 (tools/triz_matrix_ref.md 참조)
5. 복수 M-패턴 공존 허용 — 주패턴 + 보조패턴으로 기록

---

## M-패턴 출력 형식
> 출력 시 **"핵심 기술 충돌"** 을 함께 표기해 비전문가도 이해할 수 있도록 한다.

```
M-패턴: [주패턴] Level[X] + [보조패턴] Level[Y] (해당 시)
모순: [개선하려는 것] vs [악화되는 것]
TRIZ 원리: #원리1(이름) + #원리2(이름) + ...
도메인 기여: [이 특허가 해당 M-패턴의 몇 번째 귀납인지]
```
