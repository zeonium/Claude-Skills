# 08. 11대 산업 맞춤형 재무분석 프로토콜

> 본 문서는 SKILL.md §9 산업 특화 분석 프로토콜의 **상세 구현 매뉴얼**입니다.
> Mode B Step 1.5(산업 라우팅)와 Mode A의 산업 특화 박스 산출 시 반드시 참조하십시오.
> 모든 임계치는 한국 상장사 기준이며, 글로벌 기업에는 GICS sub-industry 매핑 후 차등 적용합니다.

## 1. 산업 식별 의사결정 트리

```
[입력] 기업명·티커·제품설명·KSIC 코드 중 1개 이상
   │
   ▼
① 사용자가 산업을 명시했는가?
   YES → 명시된 산업으로 진행 (단, 매출 비중 ≥40% 확인 — DART 사업의 내용)
   NO  → ②
   │
   ▼
② KSIC 표준산업분류 코드가 있는가?  →  §2.1 매핑 테이블
   YES → 11대 산업 매칭 → 매칭 성공 시 종료, 실패 시 ③
   NO  → ③
   │
   ▼
③ GICS sub-industry / NAICS / 사업 보고서 "사업의 내용"이 있는가?
   YES → §2.2 키워드 매칭 → 매칭 성공 시 종료, 실패 시 ④
   NO  → ④
   │
   ▼
④ 주요 제품·서비스 설명 키워드 매칭 (§2.3)
   매칭 성공 → 산업 확정
   매칭 실패 → "General 일반 기준 적용" 표기 후 산업 특화 섹션 생략
```

### 복합기업(Conglomerate) 처리

- 매출 비중이 가장 큰 사업부가 ≥40%이면 → 그 사업부의 산업 적용
- 30~40%이면 → "지배적 사업부 + 부수 사업부 보조" 듀얼 적용
- 30% 미만으로 분산되어 있으면 → General 기준 + 사업부별 별도 박스 안내

## 3. 산업별 핵심 KPI · 임계치 · Red Flag

> 각 산업 절은 동일 구조: (a) 비즈니스 모델 요지 — (b) 핵심 KPI 5~7개 + 공식 — (c) 4단계 임계치 — (d) 산업 특화 Red Flag — (e) 점검 주석 항목.

### 3.1 반도체 (그룹 A · 자본집약 장치산업)

**(a) 비즈니스 모델 요지**
대규모 CAPEX → 감가상각비 부담 → 가동률·판가가 마진을 좌우하는 고정비 레버리지 모델.
공급 사이클(2~3년)과 수요 사이클(소비 IT/AI 서버)이 어긋날 때 손익이 급변.

**(b) 핵심 KPI · 공식**

| KPI | 공식 |
|-----|------|
| CAPEX 비중 | CAPEX / 매출 |
| 감가상각비 비중 | 감가상각비 / 매출 |
| 재고자산 회전율 | 매출원가 / 평균 재고자산 |
| 재고자산 회전기간 | 365 / 회전율 |
| 재고/매출 비율 | 기말 재고 / 분기·연 매출 |
| 가동률(주석) | 사업의 내용 §생산능력·실적 |
| 유형자산 증가율 | (당기 유형자산 − 전기) / 전기 |
| 영업이익 민감도 | (영업이익 ÷ 매출) 의 분기 표준편차 |

**(c) 4단계 임계치 (한국 상장사 기준)**

| KPI | ⭐⭐⭐⭐ 탁월 | ⭐⭐⭐ 양호 | ⭐⭐ 보통 | ⭐ 미흡 |
|-----|-----------|---------|--------|------|
| CAPEX/매출 | 15~25% | 25~35% | 35~45% | ≥45% 또는 ≤10% (재투자 부족) |
| 감가상각비/매출 | ≤15% | 15~20% | 20~25% | ≥25% |
| 재고회전기간(일) | ≤60 | 60~90 | 90~120 | ≥120 |
| 유형자산 증가율(YoY) | 5~15% | 0~5% or 15~25% | 25~40% | ≥40% 또는 ≤−5% |

**(d) 산업 Red Flag**
- 재고/매출 비율이 2분기 연속 급등 + 판가 하락 → 재고 평가손실(저가법) 임박
- 가동률 70% 미만 장기화 → 고정비 레버리지로 영업적자 전환 위험
- CAPEX/OCF 비율 ≥100% 지속 → 차입 의존 심화

**(e) 점검 주석 항목 (DART 사업보고서)**
- "사업의 내용 > 생산능력 및 가동률"
- "재고자산 평가손실 환입/추가"
- "유형자산 손상차손"
- "차입원가 자본화 금액"

---

### 3.2 2차 전지 (그룹 A)

**(a) 비즈니스 모델 요지**
양극재·음극재 원재료 가격에 연동된 판가(메탈가 연동 계약), 대규모 신증설 CAPEX, 전환사채(CB)·교환사채 등 메자닌 자금조달 의존도 높음.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 유형자산 증가율 | YoY |
| CAPEX/매출 | 동일 |
| 메탈가 연동 마진(판가-원재료) | 판매단가 − 핵심원재료(리튬·니켈) 원가 |
| 전환사채 비중 | 전환사채(파생상품 포함) / 총자본 |
| 파생상품 평가손익 | 손익계산서 영업외 |
| 수주잔고(있는 경우) | LG에너지솔루션 등 셀 메이커는 수주잔고 공시 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| CAPEX/매출 | 10~20% | 20~30% | 30~45% | ≥45% |
| 유형자산 증가율 | 10~25% | 25~40% or 0~10% | 40~60% | ≥60% (과잉투자 위험) |
| 전환사채/총자본 | ≤5% | 5~10% | 10~20% | ≥20% |
| 메탈가 연동 마진 시계열 | 3년 안정·확대 | 변동성 보통 | 변동성 큼 | 마진 압축 추세 |

**(d) Red Flag**
- 메탈가 급락 시점에 재고평가손실 미인식 (회계 처리 일관성 의심)
- 전환사채 평가손실(영업외)이 영업이익을 상회 → 일회성 변동 큼
- 수주잔고 발표 대비 매출 인식 지연 → 가동률·고객 리스크

**(e) 주석**
- "재고자산 평가손실"
- "파생상품 평가손익", "전환사채 공정가치"
- "특수관계자 거래 — 핵심 원재료 조달"

---

### 3.3 석유 화학 (그룹 A)

**(a) 비즈니스 모델 요지**
원재료(나프타·LPG) 가격과 제품(에틸렌·BTX·합성수지) 가격의 **스프레드**가 마진의 1차 동인.
유가가 급락하면 보유 재고의 평가손실로 일시 적자, 회복기에는 환입 이익.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 스프레드 마진 | 제품가 − 원재료가 (외부지표: ICIS, Platts) |
| 매출원가율 | 매출원가 / 매출 |
| 재고자산 평가손실/환입 | 손익계산서 / 주석 |
| 유가 민감도 | 영업이익 변동 ÷ 두바이유 변동 |
| 가동률 | 사업의 내용 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 매출원가율 | ≤80% | 80~85% | 85~90% | ≥90% |
| 평가손실/매출원가 | 0~0.5% | 0.5~1.5% | 1.5~3% | ≥3% |
| 가동률 | ≥90% | 80~90% | 70~80% | <70% |

**(d) Red Flag**
- 스프레드 마이너스 진입 (역마진) → 가동률 자발 축소·정기보수 회피
- 재고 평가손실 4분기 누적 → 추가 손상 가능성
- 유가 헤지 회계 부적용 → 영업외 손익 변동성 폭증

**(e) 주석**
- "재고자산 평가손실/평가환입"
- "원재료 매입 — 특수관계자 거래"
- "유형자산 손상차손 — 노후 설비"

### 3.4 건설 (그룹 B · 수주 기반)

**(a) 비즈니스 모델 요지**
장기 도급계약 + 진행률에 따른 수익 인식. 발주처 부도·공기 지연·원가 상승 시
**미청구공사(계약자산)** 누적 → 대손 위험. **PF(프로젝트 파이낸싱) 보증**이 우발채무.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 수주잔고/매출 | 수주잔고 / 직전 1년 매출 |
| 미청구공사(계약자산)/매출 | 계약자산 / 매출 |
| 초과청구(계약부채)/매출 | 계약부채 / 매출 |
| PF 우발채무/자기자본 | 채무보증·자금보충 약정 / 자기자본 |
| 진행률 추정 변동 | 누적 진행률 변경 횟수·금액 |
| 자체사업(분양) 비중 | 자체사업 매출 / 총매출 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 수주잔고/매출 (Book-to-Bill) | ≥2.5배 | 1.5~2.5 | 1.0~1.5 | <1.0 |
| 미청구공사/매출 | ≤10% | 10~15% | 15~25% | ≥25% |
| PF 우발채무/자기자본 | ≤30% | 30~50% | 50~100% | ≥100% |
| 자체사업 비중 | 20~40% (균형) | 40~60% | 60~80% | ≥80% (분양 리스크 집중) |

**(d) Red Flag**
- 미청구공사가 2년 연속 ≥15% + 대손충당금 미증액 → 회수 지연 은폐 의심
- PF 우발채무가 자기자본 100% 초과 → 부동산 경기 하강 시 즉시 손실 전환
- 진행률 변경으로 매출 인식 시점 이동 → 이익의 질 저하

**(e) 주석**
- "수익 — 진행률 변경 효과"
- "계약자산 / 계약부채 / 미청구공사 변동"
- "채무보증 / 자금보충 약정 / PF 우발채무"
- "특수관계자 — 시행사·SPC 거래"

### 3.5 조선 (그룹 B)

**(a) 비즈니스 모델 요지**
선박 건조 2~3년 장기 계약. 발주 시점 선수금(계약부채) 수령 → 향후 매출 선행지표.
달러 결제 비중 높아 환위험 → 통화선도·옵션 등 **파생상품 환헤지**.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 수주잔고/매출 | 동일 (건설과 동일) |
| 계약부채(선수금)/매출 | 계약부채 / 매출 |
| 파생상품 자산-부채 순포지션 | 파생 자산 − 부채 |
| 환헤지 비율 | 헤지 통화 노출 / 총 통화 노출 |
| 강재(후판) 원가 비중 | 강재비 / 매출원가 |
| 척당 건조 마진 | 매출 − 직접원가 (선종별) |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 수주잔고/매출 | ≥3.0배 | 2.0~3.0 | 1.0~2.0 | <1.0 |
| 계약부채/매출 | ≥40% | 30~40% | 20~30% | <20% |
| 환헤지 비율 | 70~90% | 50~70% | 30~50% | <30% or 과대헤지(>100%) |

**(d) Red Flag**
- 후판가 급등 + 헤지 미설정 → 직접원가 잠식
- 파생상품 평가손실이 영업이익 대비 ≥50% → 환율 충격에 회계 변동성 증가
- 저가 수주 잔고가 ≥30% → 향후 2년 마진 압박 예고

**(e) 주석**
- "파생상품 평가손익 / 위험관리 정책"
- "계약부채 변동표"
- "주요 수주 — 선종·발주처·인도 시점"

---

### 3.6 식품 제조 (그룹 C)

**(a) 비즈니스 모델 요지**
원재료(곡물·유지·설탕)와 판매가의 격차가 마진. 유통기한 짧아 재고 회전·폐기 손실 관리 핵심.
B2C 브랜드 의존도 높아 판관비(광고비) 비중 큼.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 매출원가율 | 매출원가 / 매출 |
| 판관비/매출 | 판관비 / 매출 |
| 광고선전비/매출 | 광고선전비 / 매출 |
| 재고폐기손실 | 주석 (재고자산 평가손실) |
| 원가 전가력 지수 | (판매단가 변동률 − 원재료 단가 변동률) 시계열 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 매출원가율 | 65~70% | 70~75% | 75~80% | ≥80% |
| 판관비/매출 | 15~20% | 20~25% | 25~30% | ≥30% |
| 광고선전비/매출 | 2~4% | 4~6% or 1~2% | 6~10% | ≥10% |

**(d) Red Flag**
- 매출원가율 2년 연속 ▲ + 영업이익률 ▼ → 가격 전가 실패
- 재고폐기손실 급증 + 재고회전 둔화 → 수요 둔화 / 브랜드 노쇠
- 판관비 비중 ▲인데 매출 정체 → 마케팅 효율성 저하

**(e) 주석**
- "재고자산 평가손실 / 폐기 손실"
- "판매비와관리비 — 광고선전비·판매촉진비"
- "주요 원재료 매입 가격 변동"

---

### 3.7 생활용품 및 화장품 (그룹 C)

**(a) 비즈니스 모델 요지**
제조원가율 낮고 광고·판촉비·브랜드 투자가 큼. 면세·중국 의존도가 외환·정책 리스크.
무형자산(브랜드, 라이선스)이 자산의 핵심.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 매출총이익률(GP) | (매출 − 매출원가) / 매출 |
| 판관비/매출 | 동일 |
| 광고·판촉비/매출 | 광고선전비+판매촉진비 / 매출 |
| 무형자산(브랜드)/총자산 | 무형자산 / 총자산 |
| 무형자산 손상차손 | 주석 |
| 채널 매출 비중 | 면세·중국·국내·온라인 |
| 해외 매출 비중 | 해외 매출 / 총매출 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 매출총이익률 | ≥65% | 55~65% | 45~55% | <45% |
| 판관비/매출 | 30~40% | 40~50% | 50~60% | ≥60% |
| 광고판촉비/매출 | 7~12% | 5~7% or 12~18% | 18~25% | ≥25% |
| 단일국가 의존도(중국 등) | <30% | 30~40% | 40~55% | ≥55% |

**(d) Red Flag**
- 면세 매출 급감 + 따이공 채널 의존도 ▲ → 정책 리스크 노출
- 무형자산 손상차손 누적 → 브랜드 가치 훼손
- 광고비 ▲인데 매출 정체 → 마케팅 ROI 악화

**(e) 주석**
- "무형자산 — 손상차손, 라이선스"
- "지역별·채널별 매출 — 사업부문 정보"
- "특수관계자 — 모회사 마케팅 비용 배분"

---

### 3.8 도소매업 (그룹 C)

**(a) 비즈니스 모델 요지**
상품매출(매입-판매 마진) vs 수수료매출(중개) 구조 차이가 마진·재고 리스크를 결정.
점포·물류 인프라 투자가 CAPEX, 온라인 전환이 구조적 추세.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 상품매출 vs 수수료매출 비중 | 분리 공시 |
| 재고자산 회전기간 | 365 / 회전율 |
| 점포당 매출 | 매출 / 점포 수 |
| 점포당 영업이익 | 영업이익 / 점포 수 |
| 동일점 매출 성장률(SSSG) | 기존 점포만 |
| 임차료/매출 | 임차료(또는 사용권자산 상각) / 매출 |
| 온라인 매출 비중 | 온라인 매출 / 총매출 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 재고회전기간(일) | ≤30 (편의점) / ≤60 (마트) | 30~50 / 60~80 | 50~70 / 80~100 | ≥70 / ≥100 |
| 동일점 성장률(SSSG) | ≥3% | 0~3% | -3~0% | <-3% |
| 임차료/매출 | ≤4% | 4~7% | 7~10% | ≥10% |

**(d) Red Flag**
- 재고회전기간 ▲ + 평가손실 ▲ → 수요 약세, 진부화
- 신규출점에도 동일점 ▼ → 카니발리제이션, 성숙기 진입
- IFRS 16 리스부채 급증 + 영업이익 ▼ → 리스 비용 압박

**(e) 주석**
- "사업부문 정보 — 점포 수, 면적, 매출"
- "리스 — 사용권자산·리스부채"
- "재고자산 평가손실"

---

### 3.9 제약·바이오 (그룹 D · 특수회계)

**(a) 비즈니스 모델 요지**
R&D를 **개발비(자산)** 또는 **경상연구개발비(비용)** 처리하는 회계 정책에 따라 영업이익이 크게 달라짐.
임상 단계가 자산의 회수가능액을 결정 → **손상차손** 리스크가 핵심.
초기 바이오는 매출 미미, **현금소진율(Burn Rate)·Runway**가 생존 지표.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| R&D 자산화율 | 개발비(자산) / (개발비 + 경상연구개발비) |
| 개발비/무형자산 | 개발비 / 무형자산 |
| 개발비 손상차손 (누적) | 주석 |
| 임상 단계(파이프라인) | 사업의 내용 — 단계별 후보물질 |
| 현금소진율 (Burn Rate) | −영업활동현금흐름 / 12 (월평균) |
| Runway (개월) | 현금성자산 / 월평균 Burn |
| 마일스톤 수익 비중 | (라이선스 수익) / 총매출 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| R&D 자산화율 | <20% (보수적) | 20~40% | 40~60% | ≥60% (공격적·손상 리스크↑) |
| Runway (개월, 무수익 바이오) | ≥36 | 24~36 | 12~24 | <12 |
| 누적 손상차손/누적 개발비 | 0~5% | 5~15% | 15~30% | ≥30% |

**(d) Red Flag**
- 임상 실패 발표 직후 손상차손 미인식 → 다음 결산 시 대규모 손실 예고
- 자산화율을 매년 ▲ 조정 → 이익 과대계상 의심 (Beneish M-Score와 교차 점검)
- 마일스톤 수익 일회성에도 영업이익에 반영 → 일회성 vs 경상 분리 필요
- Runway < 12개월 + 차입 한도 소진 → 증자·CB 발행 임박

**(e) 주석**
- "무형자산 — 개발비 정책, 자산화 기준"
- "개발비 손상차손"
- "연구개발비 — 경상 vs 자산화"
- "특수관계자 거래 — CRO·CDMO·라이선스 in/out"

> ⚠️ Altman Z-Score는 초기 바이오에 부적용. 대신 **Runway · Burn Rate · 차입한도 잔여**로 생존성 판단.

---

### 3.10 렌탈업 (그룹 D)

**(a) 비즈니스 모델 요지**
정수기·차량·산업장비 등 자산을 보유하고 장기 계약으로 임대료 수익을 인식.
초기 CAPEX → 감가상각비 (고정비), **해지율(연체율)**과 **중고매각 원가율**이 마진 결정.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 리스자산(또는 렌탈자산)/총자산 | 동일 |
| 감가상각비/매출 | 동일 |
| 중고자산 매각손익 | 매각가 − 잔존가액 |
| 중고매각 원가율 | 매각원가 / 매각가 |
| 해지율 / 연체율 | 주석 — 고객 수 기준 |
| 코디(방판)·CS 비용/매출 | 판관비 세부 |
| ARPU (계정당 평균 매출) | 매출 / 계정 수 |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 렌탈자산/총자산 | 40~55% | 30~40% or 55~65% | 65~75% | ≥75% (자산 편중) |
| 감가상각비/매출 | 15~25% | 25~30% | 30~40% | ≥40% |
| 해지율(연 기준) | ≤6% | 6~10% | 10~15% | ≥15% |
| 중고매각 원가율 | ≤30% | 30~50% | 50~70% | ≥70% (수익화 실패) |

**(d) Red Flag**
- 신규 계정 둔화 + 해지율 ▲ → 성장-수익 동시 악화
- 잔존가액 추정 변경(상향) → 감가상각비 과소·이익 부풀리기 가능
- 중고매각 원가율 ▲ → 자산 가치 추정 오류

**(e) 주석**
- "유형자산 — 렌탈자산 잔존가액 가정"
- "감가상각 정책 변경 효과"
- "고객 수·해지율·연체율"

---

### 3.11 해운업 (그룹 D)

**(a) 비즈니스 모델 요지**
선박(자가/용선) 운용으로 운임 수익을 인식. 운임지수(BDI·SCFI·BCTI 등) 변동성이 매출에 직결.
대규모 선박 도입에 따른 **리스부채**와 **선박 감가상각비**가 고정비, 이자비용도 큼.

**(b) 핵심 KPI**

| KPI | 공식 |
|-----|------|
| 리스부채/자기자본 | 동일 |
| 이자보상배수 | EBIT / 이자비용 |
| 선박 감가상각비/매출 | 동일 |
| 운임지수(BDI/SCFI/BCTI) 민감도 | 영업이익 변동 ÷ 지수 변동 |
| 용선료 비중 | 용선료 / 매출원가 |
| 자가선/용선 비중 | 척수·DWT 기준 |
| 부채상환배수(DSCR) | OCF / (이자 + 원금상환) |

**(c) 임계치**

| KPI | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|-----|------|-----|----|---|
| 리스부채/자기자본 | ≤80% | 80~150% | 150~250% | ≥250% |
| 이자보상배수 | ≥6배 | 3~6 | 1.5~3 | <1.5 |
| 선박 감가상각비/매출 | ≤15% | 15~20% | 20~30% | ≥30% |
| DSCR | ≥1.5 | 1.2~1.5 | 1.0~1.2 | <1.0 |

**(d) Red Flag**
- 운임 지수 급락 + 장기 용선료 고정 → 역마진 즉시 발생
- 이자보상배수 <1.5 지속 → 부채 차환 리스크
- 선박 손상차손 누적 → 시장 가치 하락 반영

**(e) 주석**
- "리스 — 사용권자산·리스부채, 용선 계약"
- "유형자산 — 선박 감가상각·손상"
- "파생상품 — 연료유·환율 헤지"

| 그룹 | 우선 점검 회계 정책 |
|------|-----------------|
| A. 자본집약 | 유형자산 내용연수·잔존가액, 감가상각방법, 손상검토, 차입원가 자본화 |

## 5. 산업별 체크리스트 템플릿 (보고서 §7-Ind에 삽입)

### 공통 4단계 체크리스트 (모든 11대 산업 공통)

```markdown
# [기업명] 산업 특성 기반 재무 점검 — [산업명]

## 1. 영업 부문 및 수익 구조
- [ ] 주요 제품/서비스별 매출 비중 (사업의 내용)
- [ ] 가격(P) vs 수량(Q) 분리 (P↑Q→, P→Q↑ 구분)
- [ ] 산업별 특수 지표: (선택 적용)

## 2. 비용 구조 및 민감도
- [ ] 고정비 vs 변동비 비중 (비용의 성격별 분류 주석)
- [ ] 영업레버리지 (매출 ±10% 시 영업이익 변동 시뮬레이션)
- [ ] 원가 전가력 (판가-원재료 스프레드 시계열)

## 3. 핵심 재무비율 및 리스크 지표
- [ ] 운전자본 효율성 (매출채권·재고 회전)
- [ ] 회계 추정 리스크 (산업별 — 진행률·자산화율·잔존가액)
- [ ] 숨은 부채 (리스부채, 우발채무, CB 평가손실)

## 4. 계속기업가치 및 현금흐름
- [ ] 이익의 질 (영업이익 vs 영업활동현금흐름 괴리율)
- [ ] CAPEX 부담 (CAPEX vs OCF, FCF 추세)
- [ ] 자금조달 구조 (이자보상배수, 차입원가 자본화 포함)
```

```markdown
## §7-Ind 산업 특화 진단 — [반도체]

### 7-Ind.1 산업 KPI 5개년 시계열

| 재고회전기간(일) | 65 | 72 | 95 | 110 | 88 | → | ⭐⭐ |
| 가동률(주석) | 95% | 92% | 78% | 70% | 85% | → | ⭐⭐ |

### 7-Ind.2 산업 Red Flag 점검
- ✅ 재고 평가손실 환입(20Y5) — 정상 사이클 회복 신호
- ⚠️ 가동률 70% 저점 통과 시 영업적자 1회 발생 — 고정비 레버리지 확인
- ✅ CAPEX/OCF 비율 70% — 차입 부담 통제 양호

### 7-Ind.3 산업 특화 체크리스트 (요약)

|------|------|

### 7-Ind.4 산업 Peer 비교 (vs SK하이닉스, Micron)
[표 생략 — 매출·이익률·CAPEX 비중·재고일수 비교]
```

## 8. 사용 순서 요약 (Quick Reference)

1. **Step 1.5 진입** → §1 의사결정 트리로 산업 식별
2. 식별 성공 → §3의 해당 산업 절 펼침 → KPI 공식·임계치 확인
3. Mode A이면 §3 (b)에서 핵심 2~3개 KPI만 산출 → §6 산업 박스 출력
4. Mode B이면 §3 전체 + §4 회계 정책 + §5 체크리스트 + §6 Peer까지 풀 적용
5. §7-Ind 출력 예시 양식대로 보고서에 삽입
6. 모든 임계치는 **참고치**이며, Peer·시계열·매크로 사이클 함께 해석
