# 04. Red Flag 30항목 + Beneish M-Score + Altman Z-Score

> **언제 이 파일을 읽을까?**
> - Mode B의 STEP 5 진입 시
> - 회계조작·부실 의심 정황을 체계적으로 스캔해야 할 때
> - 투자등급 산정 전 최종 위험 필터링

> **기본 원칙:** Red Flag는 **단일 증거로 결론 내리지 않습니다**. 여러 항목이 동시에
> 발견될 때 가중치를 두고, 업종 특성을 반영하여 해석합니다.

## 2. Red Flag 발생 건수별 처리 원칙

```
0~2건   : 정상 범위                    → Mode B 진행, 참고 메모만
3~5건   : 주의 필요                    → 원인 확인 후 판단, B 등급 이하
6~9건   : 고위험                       → 투자의견 보수적 조정, C 등급 강력
10건 이상: 심각한 부실 위험            → 투자 재고 강력 권고, D 등급
```

> **가중치 원칙:** 카테고리별로 2항목 이상 동시 발견 시 해당 카테고리 **집중 리스크**로 간주합니다.
> 예: 수익인식 카테고리에서 4~5항목 동시 발견 → Beneish M-Score 실행 필수.

## 3. Beneish M-Score — 회계조작 확률 정량화

### 3.1 정의

Daniel Beneish(1999) 모델. 8개 재무비율을 종합하여 **이익 조작 확률**을 추정합니다.

```
M-Score = −4.84 + 0.92·DSRI + 0.528·GMI + 0.404·AQI + 0.892·SGI
          + 0.115·DEPI − 0.172·SGAI + 4.679·TATA − 0.327·LVGI

판정:
  M-Score < −2.22 : 조작 확률 낮음 (정상)
  M-Score > −2.22 : 조작 가능성 있음 → 심층 조사 권고
```

### 3.2 8개 변수 공식 (전년 대비 비율)

| 변수 | 의미 | 공식 |
|------|------|------|
| **DSRI** | 매출채권 지수 | (매출채권ₜ/매출ₜ) / (매출채권ₜ₋₁/매출ₜ₋₁) |
| **GMI** | 매출총이익률 지수 | 전년 GM% / 당년 GM% (↑이면 마진 악화) |
| **AQI** | 자산질 지수 | (1 − (유동자산+유형자산)/총자산)ₜ / 전년동일값 |
| **SGI** | 매출 성장 지수 | 매출ₜ / 매출ₜ₋₁ |
| **DEPI** | 감가상각 지수 | 전년 감가율 / 당년 감가율 (↑이면 감가 완화로 이익 부풀리기) |
| **SGAI** | 판관비 지수 | (판관비/매출)ₜ / (판관비/매출)ₜ₋₁ |
| **TATA** | 총발생액/총자산 | (순이익 − CFO) / 평균총자산 |
| **LVGI** | 레버리지 지수 | (총부채/총자산)ₜ / 전년동일값 |

### 3.3 해석 요령

```
가장 가중치 높은 변수: TATA(4.679) → 이익의 질이 핵심
두 번째: DSRI(0.92) → 매출채권 비정상 증가는 최대 경고 신호
세 번째: SGI(0.892) → 고성장 기업은 구조적으로 M-Score 상승 경향

주의: 성장기 기업은 SGI·AQI가 자연스럽게 높아져
     false positive(거짓 경고) 가능 → 업종·생애주기 맥락에서 해석.
```

### 3.4 Mode B 실무 적용

1. Red Flag 30항목 중 수익인식·자산질 카테고리에서 **3항목 이상** 감지되면 M-Score 실행 권고.
2. M-Score > −2.22 이면 투자등급 자동 2단계 하향 (예: A → C).
3. M-Score와 Red Flag 건수가 모두 높으면 **데이터 검증 수준을 상향**(여러 데이터 소스 교차 확인).

## 4. Altman Z-Score — 부도 예측 지표

### 4.1 제조업 상장기업 공식 (원형)

```
Z = 1.2·X₁ + 1.4·X₂ + 3.3·X₃ + 0.6·X₄ + 1.0·X₅

  X₁ = 운전자본 / 총자산
  X₂ = 이익잉여금 / 총자산
  X₃ = EBIT / 총자산
  X₄ = 자기자본 시가총액 / 총부채 장부가
  X₅ = 매출 / 총자산

판정:
  Z > 2.99   : 안전 구역 (Safe Zone)
  1.81~2.99  : 회색 구역 (Gray Zone) — 주의
  Z < 1.81   : 위험 구역 (Distress Zone) — 2년 내 부도 가능성 ↑
```

### 4.2 Z′-Score (비상장 / 비제조업 변형)

```
비상장 제조업:
  Z′ = 0.717·X₁ + 0.847·X₂ + 3.107·X₃ + 0.420·X₄′ + 0.998·X₅
       (X₄′ = 자기자본 장부가 / 총부채)
  안전 > 2.90, 위험 < 1.23

비제조업 · 신흥시장:
  Z″ = 6.56·X₁ + 3.26·X₂ + 6.72·X₃ + 1.05·X₄′
       (X₅ 제외 — 업종별 자산회전율 차이 제거)
  안전 > 2.60, 위험 < 1.10
```

### 4.3 적용 가이드

```
① 업종 적합성 확인:
   제조업 상장사 → 원형 Z-Score
   상장 서비스·IT → Z″ (X₅ 제외형) 사용 권장
   금융업 → 적용 불가 (별도 CAMELS 프레임워크 활용)

② 시계열 추세가 중요:
   Z-Score 단일값보다 5년 추세의 방향성(우하향 vs 우상향)이 부도 예측에 강력

③ 타 지표와 교차 확인:
   Z-Score 악화 + Red Flag 5건 이상 + Beneish > −2.22 → 명백한 회피 신호
```

### 4.4 Mode B 실무 적용

1. 모든 Mode B 분석에서 Z-Score 산출 후 5년 추세 테이블 작성:
   ```
   연도  | Z-Score | 구역       | 추세
   ------|--------|-----------|------
   2020  |  X.XX  | Safe/Gray | →
   2021  |  X.XX  | Safe/Gray | ▲/▼
   ...
   ```
2. Z-Score가 Gray/Distress 구역이면 최종 투자등급 C 이하 자동 조정.
3. Altman + Beneish + Red Flag 3-Way 통합 판정표를 Mode B 보고서 말미에 첨부.
