# 06. 보고서 템플릿 — Quick(Mode A) + Deep(Mode B) 듀얼 구조

> **언제 이 파일을 읽을까?**
> - 최종 리포트 출력 단계 직전
> - Mode A 또는 Mode B 중 어떤 포맷을 쓸지 확정되었을 때
>
> **원칙:**
> - 사용자 언어에 맞추어 출력 (한국어 요청이면 한국어로, 영어 요청이면 영어로)
> - 한국어 출력 시 용어 표기는 `한국어명 (영문약어)` 형식 — 예: 자기자본이익률 (ROE)
> - 표는 일관된 너비로 정렬, 숫자는 업종 관행에 맞춘 단위로 (한국 기업: 억원 / 미국 기업: USD Mil / % 소수점 1자리)

---

## 1. Mode A — Quick Scan 1페이지 대시보드

사용자가 재무 숫자를 직접 제공한 **단일 기간 빠른 판정**. 출력 길이는 **1페이지 내외 (1,000~1,500자)**.

### 1.1 포맷 템플릿

```markdown
# [기업명] 재무분석 요약 — Mode A Quick Scan
분석 기준일: 20XX년 XX월 (단일 기간)

## 📊 5대 축 핵심 지표 대시보드

| 구분 | 핵심 지표 | 수치 | 업종 벤치마크 | 판정 |
|------|---------|------|-------------|------|
| 성장성 | 매출성장률 (Revenue Growth) | XX% | XX% 이상 우량 | ⭐⭐⭐⭐ 탁월 / ⭐⭐⭐ 양호 / ⭐⭐ 보통 / ⭐ 미흡 |
| 수익성 | 영업이익률 (OPM) | XX% | XX% 이상 우량 | ⭐⭐⭐ 양호 |
| 수익성 | 자기자본이익률 (ROE) | XX% | XX% 이상 우량 | ⭐⭐⭐⭐ 탁월 |
| 활동성 | 총자산회전율 (Asset Turn) | X.X배 | X.X배 이상 우량 | ⭐⭐⭐ 양호 |
| 안정성 | 부채비율 (Debt Ratio) | XX% | XX% 이하 우량 | ⭐⭐⭐ 양호 |
| 안정성 | 이자보상배율 (ICR) | X.X배 | X배 이상 우량 | ⭐⭐⭐⭐ 탁월 |
| 유동성 | 유동비율 (CR) | XX% | 200% 이상 우량 | ⭐⭐⭐ 양호 |

## 🎯 핵심 진단 (3줄 요약)
1. [강점] ___________________________
2. [약점] ___________________________
3. [종합] ___________________________

## ⚡ 주의 포인트
- ___________________________
- ___________________________

## 💡 추천 다음 단계
- 시계열 3~5년 데이터로 Mode B 심층분석 권고 여부: [예 / 아니오]
- 특정 비율 심화 해석 필요 시: 질의 요청
- 적정주가 산출 필요 시: `intrinsic-value-analyzer` 스킬 활용
```

### 1.2 Mode A 작성 원칙

- **⭐ 등급은 업종 벤치마크(`02_ratios.md`)에 기초**해 자동 판정
- 업종 정보가 불명확하면 **General(일반)** 기준 적용하되 표 하단에 명시
- 숫자가 빠진 지표는 "N/A" 표기 + 계산 가능한 다른 지표로 대체
- "3줄 요약"은 **강점·약점·종합** 순서로 고정

## 2. Mode B — Deep Diagnosis 8섹션 심층 보고서

시계열(3~5년) 기반 종합 투자등급 보고서. 분량은 **3,000~6,000자** 수준.

### 2.1 전체 구조

```
섹션 1. 기업 개요 & 분석 범위
섹션 2. 5대 축 재무비율 시계열 진단
섹션 3. DuPont + ROIC 분석
섹션 4. 현금흐름 구조 분석
섹션 5. Red Flag + Beneish + Altman 통합 위험 스캔
섹션 6. Peer 비교 (선택)
섹션 7. 경영실적 통찰 3대 프레임
섹션 8. 종합 투자등급 (A+~D) 및 Action 포인트
```

## 4. 출력 품질 원칙

1. **숫자 무오류** — 재무제표에서 추출한 원시 수치는 소수점 이하 1자리까지 일관 유지
2. **단위 통일** — 한 섹션 내에서 억원/백만원/USD 혼용 금지
3. **추세 표기** — ▲ (개선) / ▼ (악화) / → (유지) 통일
4. **벤치마크 출처 명시** — ⭐ 등급 부여 시 업종 기준 출처(02_ratios.md 또는 Peer 중앙값)를 표 아래에 각주
5. **위임 명시** — 본 스킬이 직접 다루지 않는 영역(DCF·해자·스크리닝 등)은 **해당 스킬 이름을 명시적으로 제시**
6. **반복 금지** — 동일 수치·해석을 섹션 간 반복하지 않음. 교차 참조 사용
