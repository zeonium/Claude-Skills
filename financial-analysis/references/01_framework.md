# 01. 분석 프레임워크 — 4계층 철학 + 7단계 워크플로우

> **언제 이 파일을 읽을까?**
> - 스킬을 처음 사용할 때
> - Mode B(심층진단) 진입 시 7단계 전체 흐름이 필요할 때
> - 분석의 깊이(계산 vs 해석 vs 통찰)에 대해 판단이 필요할 때

---

## 1. 분석 철학 — 4계층 깊이 모델

```
┌──────────────────────────────────────────────────────────┐
│  Layer 4: INSIGHT (통찰)                                  │
│  "경영진의 전략적 의도와 실행 능력을 판단한다"                │
├──────────────────────────────────────────────────────────┤
│  Layer 3: DIAGNOSIS (진단)                               │
│  "이 수치 변화는 문제인가, 기회인가?"                        │
├──────────────────────────────────────────────────────────┤
│  Layer 2: INTERPRETATION (해석)                          │
│  "이 숫자가 의미하는 바는 무엇인가?"                         │
├──────────────────────────────────────────────────────────┤
│  Layer 1: CALCULATION (계산)                             │
│  "정확한 숫자를 추출한다"                                  │
└──────────────────────────────────────────────────────────┘
```

대부분의 재무분석은 Layer 1~2에 머무르지만, 실질적 의사결정에 유효한 분석은 **Layer 3~4**에서 나옵니다. 본 스킬은 Layer 1~2의 계산·해석을 자동화하고, 분석 역량을 Diagnosis와 Insight에 집중시킵니다.

---

## 2. 5대 핵심 분석 원칙

### 원칙 1 · 비율은 홀로 말하지 않는다
단일 지표가 아닌 **지표 간 연관성(Cross-Ratio Logic)**을 통해 진단합니다.
- 예) 매출 성장 + 매출채권 급증 → "밀어내기" 의심
- 예) ROE↑ + 순이익률↓ + 레버리지 급증 → 빚으로 ROE를 부풀린 착시

### 원칙 2 · 추세가 절댓값보다 중요하다
현 시점의 수치보다 **3~5년 방향성(Trend)**과 **속도 변화(Acceleration)**를 우선 판단합니다.

### 원칙 3 · 현금흐름은 거짓말하지 않는다
발생주의 회계의 이익은 조정 가능하지만 현금흐름표의 CFO는 조작이 어렵습니다.
**이익 ≠ 현금**임을 항상 전제하고 괴리를 추적합니다.

### 원칙 4 · 주석(Note)이 본문보다 중요할 수 있다
재무제표 본문의 '화려한 숫자' 뒤에 숨겨진 리스크는 주석에 기재됩니다.
수익인식 정책 변경, 우발부채, 특수관계자 거래를 반드시 점검합니다.

### 원칙 5 · 업종 맥락 없이 비율을 판단하지 않는다
동일 비율도 산업에 따라 해석이 완전히 달라집니다.
(예: 부채비율 200% → 제조업은 위험 신호, 금융업은 정상 범위)

## 3. 듀얼 모드 자동 분기

### Mode A — Quick Scan (빠른 판정)
**트리거 조건 (모두 충족):**
- 사용자가 재무 데이터를 직접 제공 (NL/표/CSV/JSON)
- 기업명·티커 미언급 또는 데이터 수집 불필요
- "심층/Deep/Peer/투자등급" 키워드 없음

**산출물:** 1페이지 ⭐등급 대시보드 (`06_report_templates.md` Quick 섹션)

### Mode B — Deep Diagnosis (심층진단)
**트리거 조건 (하나라도 충족):**
- 기업명·티커가 명시되고 실데이터 수집 필요
- 3~5년 시계열 분석 요청
- "심층분석 / Deep / Peer 비교 / 투자등급 / Red Flag" 등 키워드
- 사용자가 직접 데이터를 제공했더라도 다기간(3년 이상)

**산출물:** 8섹션 투자등급(A+~D) 보고서 (`06_report_templates.md` Deep 섹션)

## 4. 7단계 워크플로우 (Mode B 상세)

### STEP 1 · 자료 수집 및 맥락 설정

**수집 자료 체크리스트:**
- [ ] 최근 3~5개년 연결재무제표 (손익/재무상태/현금흐름/자본변동)
- [ ] 감사보고서 (감사의견, 핵심감사사항 KAM)
- [ ] 사업보고서 주석 전체 (수익인식·금융상품·특관자)
- [ ] 분기/반기 보고서 (최근 분기 트렌드)
- [ ] 산업 분류 코드 (KSIC / SIC / GICS)

**비즈니스 모델 이해:**
- 주요 매출원 (제품/서비스 믹스, 지역 믹스)
- 고객 집중도 및 계약 구조
- 원가 구조 (변동비/고정비 비중)
- 자본 투자 사이클 (장치산업 vs 경량자산)

> MCP 호출 방법 → `07_data_sources.md`

---

### STEP 2 · 데이터 정규화

**목적:** 회계적 왜곡 없이 **경상적 이익 창출 능력(Recurring Earnings Power)**을 추출

| 구분 | 항목 | 조정 방향 |
|------|------|-----------|
| 일회성 손실 | 구조조정비용·대규모 충당금 | 이익에 가산 |
| 일회성 이익 | 자산 매각차익·보험 수령 | 이익에서 차감 |
| 비현금 항목 | 주식보상비용(SBC) | 현금이익 기준으로 재산출 |
| M&A 효과 | 인수기업 실적 분리 | 유기적 성장률 별도 산출 |
| 환율 효과 | 글로벌기업 환산손익 | 기능통화 기준 별도 확인 |
| 세금 일시효과 | 이연법인세 급변·세혜택 만료 | 유효세율 정상화 |

---

### STEP 3 · 5대 축 재무비율 계산

모든 비율을 시계열 테이블로 작성:

```
연도       | 2020 | 2021 | 2022 | 2023 | 2024 | 추세
----------|------|------|------|------|------|-----
매출성장률 |      |      |      |      |      | ▲▼→
영업이익률 |      |      |      |      |      | ▲▼→
ROE       |      |      |      |      |      | ▲▼→
...
```

**추세 판정 기준:**
- ▲ 개선: 2년 이상 연속 상승 또는 명확한 상승 방향
- ▼ 악화: 2년 이상 연속 하락 또는 명확한 하락 방향
- → 유지: 업종 평균 내 안정적 유지
- ⚠ 변동성: 급격한 등락 반복

> 공식 참조 → `02_ratios.md`

---

### STEP 4 · DuPont + 현금흐름 심층 분석

이 단계의 4대 핵심 질문:
1. ROE 변화의 진짜 원인은 무엇인가? (마진/효율/레버리지)
2. 이익이 실제 현금으로 회수되고 있는가?
3. 자본지출(CAPEX) 부담을 영업현금흐름이 커버하는가?
4. 현금흐름표 3섹션(CFO/CFI/CFF) 구조 패턴이 우량형인가?

> 상세 → `03_dupont_cashflow.md`

---

### STEP 5 · Red Flag 체크리스트

30항목 5개 카테고리 체크 → 발생 건수 기반 위험도 판정.

**발생 건수 기반 처리 원칙:**
- 0~2건: 정상 범위
- 3~5건: 주의 필요, 원인 확인 후 판단
- 6~9건: 고위험, 투자의견 보수적 조정
- 10건 이상: 심각한 부실 위험, 투자 재고 강력 권고

> 상세 → `04_red_flags.md`

---

### STEP 6 · Peer 비교 (선택)

**Peer 선정 기준 (3~5개사):**
1. 동일 산업 SIC/KSIC 코드
2. 규모 50~200% 범위 (매출 or 시총)
3. 사업 모델 유사도 > 70%
4. 상장 5년 이상, 감사의견 적정
5. 동일 회계기준 (K-IFRS / US GAAP)

**비교 출력 5대 축 표준 포맷** → `05_industries_peer.md`

---

### STEP 7 · 경영실적 통찰 도출

**통찰 도출 3대 프레임:**

#### ① 가격결정력 (Pricing Power)
- 매출 성장 분해: 가격인상분 vs 물량증가분
- 매출총이익률 추세: 원가 상승 전가 능력
- 경쟁사 대비 마진 차이 유지/확대/축소

#### ② 자본 배분 효율성 (Capital Allocation)
- ROIC vs WACC 스프레드 (양수 = 가치 창출)
- CAPEX 사이클: 유지보수 CAPEX vs 성장 CAPEX
- 주주환원(배당+자사주) 정책의 일관성

#### ③ 운영 실행력 (Operational Excellence)
- CCC 추세: 운전자본 관리 능력
- FCF 전환율: 이익 → 현금 전환 안정성
- SG&A/매출 비율 추세

## 5. 최종 종합 등급 산출 (Mode B)

| 등급 | 기준 | 의미 |
|------|------|------|
| **A+** | 5대 축 모두 양호 + Red Flag 0 + Peer 상위 25% | 최우량 |
| **A**  | 4축 이상 양호 + Red Flag 1 이하 | 우량 |
| **B**  | 3축 이상 양호 + Red Flag 2 이하 | 보통 |
| **C**  | 2축 이하 양호 또는 Red Flag 3~5 | 주의 |
| **D**  | 다수 축 악화 + Red Flag 6 이상 | 위험 |

**5대 축 "양호" 판정 기준**:
- 해당 축의 핵심 지표가 업종 벤치마크에서 ⭐⭐⭐(양호) 이상
- 시계열 추세가 ▲ 또는 → (악화 ▼ 아님)

> **이원 등급 체계 정리**:
> - ⭐~⭐⭐⭐⭐ (탁월/양호/보통/미흡) = 개별 지표 판정
> - A+~D = 기업 전체의 투자등급 (Mode B 최종)
