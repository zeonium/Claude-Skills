## 1. DuPont 분석 — ROE 변화의 진짜 원인 추적

### 1.1 3분해 (기본)

```
ROE = 순이익률 × 총자산회전율 × 재무레버리지

  ① 순이익률(Net Margin)      = 순이익 / 매출
  ② 총자산회전율(Asset Turn)  = 매출 / 평균총자산
  ③ 재무레버리지(Equity Mult) = 평균총자산 / 평균자기자본
```

### 1.2 5분해 (심화 — 세금·이자 효과 분리)

```
ROE = 세전이익률 × 세금부담율 × 이자부담율 × 총자산회전율 × 재무레버리지

  ① 세전이익률   = 세전이익(EBT) / 매출      → 영업+비영업 수익성 합산
  ② 세금부담율   = 순이익 / EBT              → 1 − 유효세율
  ③ 이자부담율   = EBT / EBIT                → 이자비용 부담 (1에 가까울수록 부담 적음)
  ④ 총자산회전율 = 매출 / 평균총자산
  ⑤ 재무레버리지 = 평균총자산 / 평균자기자본
```

> 3분해는 "왜 ROE가 바뀌었는가"의 **1차 진단**,
> 5분해는 세금·이자까지 분리하여 "진짜 영업력 변화인가"를 가려내는 **2차 진단**에 사용합니다.

### 1.3 분해 결과 해석 매트릭스

| 변화 패턴 | 원인 진단 | 투자 관점 |
|----------|----------|----------|
| 순이익률↑, 회전율→, 레버리지→ | 순수 영업력 개선 (가격결정력 or 비용효율화) | ★ 긍정적 |
| 순이익률→, 회전율↑, 레버리지→ | 자산 효율화 성공 (자본회전 개선) | ★ 긍정적 |
| 순이익률→, 회전율→, 레버리지↑ | 부채 레버리지만 증가 — 이익 체력은 그대로 | ⚠ 경고 |
| 순이익률↓, 회전율↑, 레버리지→ | 박리다매 전략 전환 (가격인하) | △ 중립, 지속성 검증 필요 |
| 순이익률↑, 회전율↓, 레버리지→ | 고마진 전략 + 자산 비대화 | △ 자산 비효율 점검 필요 |
| 순이익률↓, 회전율↓, 레버리지↑ | 전방위 악화 + 부채로 땜질 | ✗ 위험 |
| 순이익률↑, 회전율↑, 레버리지→ | 마진과 회전 동반 개선 — 최우량 패턴 | ★★ 최상 |

## 2. ROIC 분석 (DuPont 확장)

### 2.1 ROIC 공식

```
ROIC = NOPAT / 평균 투하자본

NOPAT (세후영업이익) = 영업이익 × (1 − 유효세율)

투하자본 계산 (두 가지 접근):

  방법 A (자산 기반):
    투하자본 = 총자산 − 비이자부유동부채 − 초과현금
              (비이자부유동부채 = 매입채무, 선수금, 미지급비용 등)

  방법 B (자본 기반):
    투하자본 = 자기자본 + 이자부부채 − 초과현금

  ※ 두 방법의 결과는 수식적으로 동일해야 합니다.
  ※ "초과현금"은 운영 최소 필요현금(보통 매출의 2~3%)을 초과한 부분.
```

### 2.2 WACC 간략 추정 (CAPM 기반)

```
WACC = (E/V × Re) + (D/V × Rd × (1 − T))

  E  = 자기자본 시장가치 (상장사면 시가총액)
  D  = 이자부부채 장부가 (단기·장기 차입금 + 사채)
  V  = E + D
  T  = 유효세율
  Rd = 이자비용 / 평균 이자부부채
  Re = Rf + β × ERP           ← CAPM
        Rf  = 10년 국채금리 (한국: 약 3.5% / 미국: 약 4.2% 수준, 실측 권장)
        β   = 회귀 추정치 (finnhub / FMP / yfinance 제공)
        ERP = 주식위험프리미엄 (한국 6~7% / 미국 5~6% 관례값)
```

### 2.3 ROIC − WACC 스프레드 해석

```
ROIC − WACC > 0 → 가치 창조 (Value Creation)
                   투하된 1원당 자본비용 이상의 수익 → 주주가치 증대
ROIC − WACC ≈ 0 → 가치 중립
                   자본비용만큼만 벌어 사실상 제자리
ROIC − WACC < 0 → 가치 파괴 (Value Destruction)
                   적자보다 위험한 상태 — 벌어들인 이익이 자본비용에 미달
                   → 성장할수록 가치가 감소하는 역설
```

> **핵심:** 순이익이 플러스여도 ROIC < WACC이면 경제적 이익(Economic Profit)은 음수입니다.
> 고성장 기업을 평가할 때 이 스프레드가 양수로 전환되는 시점이 **"진정한 복리 구간"**의 시작입니다.

## 3. 현금흐름 심층 분석 (요약 레벨)

### 3.1 CFO·CFI·CFF 부호 조합 패턴 (A~E)

```
+ 기호: 현금 유입,  − 기호: 현금 유출

[Pattern A] CFO(+) / CFI(−) / CFF(−)  ← 이상적 성숙 기업
  본업 현금으로 투자하고 부채·배당 모두 감당. 자기자본 조달 불필요.
  → 워런 버핏이 선호하는 "현금 기계" 패턴

[Pattern B] CFO(+) / CFI(−) / CFF(+)  ← 성장 투자 기업
  영업 현금보다 투자 규모가 크거나, 공격적 성장을 위해 외부 자금 조달.
  → 투자의 ROIC가 WACC를 상회하는지 반드시 검증

[Pattern C] CFO(−) / CFI(+) / CFF(+)  ← 위험 기업
  본업 현금 유출 + 자산 매각 + 차입으로 연명. 매우 위험한 구조.
  → 전환 계기(신사업·M&A)가 명확하지 않으면 회피

[Pattern D] CFO(+) / CFI(+) / CFF(−)  ← 구조조정 기업
  비핵심 자산 매각 + 부채 상환 중. 일시적 패턴일 수 있음.
  → 축소 전략인지, 리스트럭처링 후 재도약인지 판별

[Pattern E] CFO(−) / CFI(−) / CFF(+)  ← 초기 성장 or 위기
  영업 적자 + 공격적 투자 + 외부 자금. SaaS·바이오 초기단계 정상 패턴.
  → 성장성 지표(ARR, 매출성장률)와 Runway(현금/월소진) 병행 확인
```

### 3.2 이익의 질 (Earnings Quality)

**핵심 지표: 현금전환비율 = CFO / 당기순이익**

```
> 1.2배 : 이익의 질 매우 우량 (현금이 이익을 초과)
1.0~1.2 : 우량
0.8~1.0 : 보통
0.5~0.8 : 이익의 질 저하 — 원인 확인 필요
< 0.5배 : 심각 — 회계 조작 또는 운전자본 함정 의심
```

**총발생액(Total Accruals) 보조 분석:**
```
총발생액 = 당기순이익 − CFO
  (+) : 발생주의 이익이 현금보다 큼 → 매출채권·재고 급증 여부 점검
  (−) : 현금 이익이 발생주의 이익보다 큼 → 이익의 질 우량

발생액 비율 = 총발생액 / 평균총자산
  업종 평균 대비 +1 표준편차 이상 → 회계조작 레드플래그
  (Beneish M-Score TATA 지표와 연결됨 — 04_red_flags.md 참조)
```

### 3.3 잉여현금흐름(FCF) 분석

```
FCF = CFO − CAPEX

CAPEX 분해 (주석에서 추출 가능한 경우):
  유지보수 CAPEX : 기존 설비 유지 최소 투자 (≈ 감가상각비 수준)
  성장 CAPEX    : 미래 성장을 위한 추가 투자 (= 총CAPEX − 유지보수)

FCF 마진        = FCF / 매출
FCF 수익률(Yield) = FCF / 시가총액 (밸류에이션 지표 — 적정주가는 위임)

추세 해석:
  3년 연속 FCF↑          → 진정한 경영 개선, 복리 구간 진입
  3년 연속 FCF(−)        → 자금조달 의존, 지속가능성 레드플래그
  FCF ≈ 0 유지           → 성장 투자 균형 (성장 CAPEX 비중 점검)
  FCF > 순이익 2배 이상  → 감가상각 과대 or 자본집약도 낮은 우량 기업
```

### 3.4 간이 현금흐름 건전성 점수 (0~10점)

```
항목                                    | 점수
---------------------------------------|------
CFO > 순이익 × 0.8                     | +2점
FCF > 0 (양수)                          | +2점
CFO > 이자비용 × 3배                   | +2점
CFO 성장률 > 매출 성장률               | +2점
CFO / 총자산 > 업종 평균의 50% 이상    | +2점

판정:
  8~10점 : 우량
  5~7점  : 보통
  3~4점  : 주의
  0~2점  : 위기 — Red Flag 체크리스트 즉시 가동
```

### 3.5 운전자본 변동 간이 점검

```
순운전자본(NWC) = (매출채권 + 재고 + 선급금) − (매입채무 + 선수금 + 미지급비용)

CFO에 대한 영향:
  CFO = 순이익 + D&A − (NWC 증가분)
  → NWC↑ 이면 CFO 하락 요인 (현금이 영업 사이클에 묶임)

이상 신호:
  매출 정체인데 NWC 급증      → 재고 누적 or 매출채권 회수 지연
  매출채권 증가율 > 매출 성장률 → 밀어내기 or 회수 악화 의심
  NWC 급감                    → 공급업체 결제 지연 (DPO 연장, 관계 악화 우려)
```

> **심층 운전자본 분석** (공급업체별 DPO 세분화, 제품별 재고 회전율, 매출채권 age分 등)은
> `anthropic-skills:cash-flow-analysis`로 위임하세요.
